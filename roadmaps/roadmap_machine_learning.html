현재 위치

완료 · 데이터 이해와 분할원본 품질과 Label 분포를 확인하고 X (7043,19)·y (7043,)를 Train 5,634명·Validation 1,409명으로 나눴다. stratify=y가 두 Split의 No·Yes 비율을 유지하는 것도 검증했다.
완료 · Dummy 챕터most_frequent가 y_train의 다수 클래스 No를 선택해 Validation 1,409개를 모두 No로 예측했고, 실제 No 비율과 같은 Accuracy 73.456%가 나오는 과정을 직접 계산했다.
완료 · 전처리 통합 검증One-Hot의 고정 출력 칸과 ColumnTransformer의 작업 명세를 이해했다. 범주형 41열과 StandardScaler 숫자형 4열을 합쳐 Train (5634,45)·Validation (1409,45)를 만들었고, 마지막 숫자형 부분 (5634,4)의 평균이 사실상 0, 표준편차가 모두 1인 것도 확인했다.
완료 · Logistic Baseline 평가Logistic Regression은 Validation Accuracy 80.55%로 Dummy Baseline 73.46%보다 7.10%p 높았다. Confusion Matrix에서 Yes Recall 55.88%·Precision 65.72%·F1 60.40%을 직접 계산하고, classification_report()의 macro·weighted 평균도 실제 인원수와 연결해 읽었다.
복습 참조 · StandardScaler 수학(x − μ) / σ가 평균 0·표준편차 1이 되는 분산 전개는 작은 숫자 예제로 확인했지만, 아직 자기 말로 완전히 설명해 완료 처리하지 않았다. 모델 학습과 병렬로 복습한다.
복습 방향 · 모델과 전처리기 구분LogisticRegression은 모델이고 fit()이 X_train과 y_train의 관계에 맞게 가중치를 학습한다. OneHotEncoder·StandardScaler·ColumnTransformer는 전처리기이고 fit_transform()은 입력 X의 표현을 바꾼다. 완료 확인: 각 객체에서 fit·transform·fit_transform이 무엇을 저장하고 어떤 결과물을 내는지 구분해 설명한다.
복습 방향 · Pandas 결과표 읽기모델 평가에서 NumPy 행렬을 pd.DataFrame(..., index=..., columns=...)로 읽기 좋은 표로 바꾸는 흐름을 보강한다. 완료 확인: confusion matrix에서 labels가 No·Yes의 행·열 순서를 정하고, index·columns가 행·열 제목을 붙인다는 것을 설명한다.
다음 행동predict_proba()에서 No·Yes 확률의 열 순서를 확인하고, Threshold를 바꿔 Yes Recall과 Precision이 어떻게 서로 바뀌는지 같은 Validation 데이터에서 비교한다.

활성 데이터 관문

활성화 근거TransformerBlock.forward() 구현·Shape·전체 흐름 설명을 완료해 예약했던 데이터 기반 트랙으로 전환했다.
첫 데이터 관문원본 데이터를 바로 모델에 넣지 않고 구조, 자료형, 결측, 중복과 Label 분포를 먼저 확인한 뒤 Train/Validation으로 나눈다.
완료 증거동일한 분할과 Metric에서 Dummy와 Logistic Regression을 비교하고, 어느 모델이 왜 Baseline을 넘었거나 넘지 못했는지 설명한다.
다음 예약이 관문을 완료하면 PyTorch nn.Module·Optimizer 학습으로 이동하고, 그다음 Tiny Decoder LM으로 복귀한다.
