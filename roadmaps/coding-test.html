현재 목표에서 선택한 하위 학습 단원 (11)
  1. 기초 구현·컬렉션·기본 탐색 · 이미 통과한 기초 문제의 진도를 보존하면서 입력 해석·Python 도구 선택·후보 생성의 공통 기반을 유지한다.
  2. Stack·Queue·Heap · 기초 구현을 Stack·Queue·Heap의 처리 순서와 상태 갱신으로 확장하고 남은 우선순위·시간 처리 문제를 보강한다.
  3. DFS·BFS·그래프 탐색 · 자료구조의 상태 관리를 격자·일반 그래프의 방문·거리·경로 복원으로 확장한다.
  4. 이분탐색 · 검증한 이분탐색 진도를 유지하면서 가능 여부 판정·단조성·경계로 정답 공간을 줄이는 사고를 분리해 정리한다.
  5. 최단경로 · 그래프 탐색 뒤 가중치에 맞는 거리 갱신과 여러 경로의 결합을 다룬다.
  6. 동적계획법 · 검증한 DP 문제와 도둑질의 성과를 보존하고, 현재 Session의 N으로 표현에서 사용 개수별 상태·분할·조합을 이어간다.
  7. Hash·사용자 정의 정렬 · 기초 컬렉션 경험을 빈도와 조합·접두 관계·사용자 정의 비교로 확장하고 기존 부분 풀이와 잊은 지점을 연결한다.
  8. 그리디·백트래킹 · 기초 선택 경험에서 그리디의 정당성과 반례, 백트래킹의 선택·복원으로 문제에 맞는 전략을 구분한다.
  9. 투 포인터·Window·누적합 · 연속 구간의 경계 이동과 누적 계산 재사용을 익혀 단순 반복 탐색의 비용을 줄이는 영역을 보강한다.
  10. MST·관계·선행 제약 · 탐색·최단경로 기반 위에 최소 비용 연결·관계 전파·선행 제약을 서로 다른 그래프 목표로 구분한다.
  11. 파싱·시뮬레이션 · 알고리즘 선택과 별개로 긴 규칙·파싱·상태 갱신·예외를 정확히 구현하는 실전 역량을 보강한다.
