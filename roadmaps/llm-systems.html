PyTorch Causal LM 추론 Baseline

KV Cache·Batch

입력 Tiny Decoder LM의 Forward·학습·생성 완료 결과와 로컬에서 실행 가능한 최소 사전학습 Causal LM을 사용한다. 특정 Parameter 규모를 강제하지 않고 현재 장치에 들어가는 가장 작은 모델로 흐름을 먼저 검증한다. 같은 모델·Prompt에서 No-cache와 KV Cache 생성, Batch 1과 Batch N을 비교합니다. GPU 실험에서는 모델·Tensor의 장치와 CPU↔GPU 메모리 이동, PyTorch의 CUDA 장치 디스패치, CUDA 비동기 실행과 동기화된 측정 경계를 확인합니다. RoPE·GQA·RMSNorm·SwiGLU를 작은 Module과 Shape으로 이해하고, 조건을 고정한 Naive PyTorch 추론 기준선을 만듭니다. RMSNorm에서 확인한 정규화 차이를 바탕으로 SwiGLU의 게이트 FFN, RoPE의 Q·K 위치 회전, GQA의 KV Head 공유를 차례로 확인합니다. GQA를 모델 가중치·KV Cache 메모리 예상에 연결하고 실제 할당량과 비교합니다. 같은 모델에서 입력 길이·출력 길이·Batch를 바꾸며 Prefill과 Decode의 계산·메모리 비용을 각각 측정합니다. 장치·Cache·실행 방식 변경 전후의 Logit 오차와 생성 결과를 검증한 뒤 속도·메모리 차이를 해석합니다. Prefill·Decode의 동작과 측정은 여기서 다루고, 별도 서버로의 분리 및 KV 전송 실험은 후속 학습 범위로 둡니다.

    Transformer에서 `torch.arange(4)`는 0부터 3까지의 위치를 만들고 `unsqueeze(0)`은 Shape [4]를 [1,4]로 바꾸어 Batch·Sequence 형태의 위치 Tensor를 만든다. 위치 Tensor는 모델과 같은 Device에 두며, Token Embedding과 Position Embedding을 더해 최초 Hidden State를 만든다. RoPE에서는 Q·K만 Head 내부의 차원쌍으로 회전하고 V는 그대로 두며, 회전 전후 원소 수와 Tensor Shape은 유지된다. Causal Mask에서는 QKᵀ로 모든 Query·Key Score를 만든 뒤 `torch.tril` 하삼각 Mask로 미래 위치를 가린다. `masked_fill`로 미래 Score를 `-inf`로 바꾸면 Softmax의 `exp(-inf)=0`에 의해 미래 Attention Weight가 0이 되며 V 자체는 변경하지 않는다. Transformer Layer는 앞 Layer의 출력 Hidden State에 의존해 Layer 1→Layer 2→Layer 3 순서로 처리된다. 각 Layer는 자신의 Q·K·V Projection과 KV Cache를 따로 가지지만 한 Layer 안의 여러 Token은 병렬로 계산할 수 있다. GQA에서 Query Head 4개와 KV Head 2개를 사용하는 경우 K·V Projection부터 출력 크기를 작게 설계한다. Prompt 전체의 Q·K·V로 Prefill을 수행해 K·V를 Cache에 저장하고, 새 Token의 Q·K·V만 계산해 K·V를 Cache에 추가한 뒤 Q5와 전체 Cache로 Decode Attention을 계산한다.

  • KV Cache가 있으면 Decode에서 새 토큰 하나의 Hidden State만 Layer 사이를 이동한다. 각 Transformer Layer는 새 토큰의 Q·K·V를 계산하…

    KV Cache가 있으면 Decode에서 새 토큰 하나의 Hidden State만 Layer 사이를 이동한다. 각 Transformer Layer는 새 토큰의 Q·K·V를 계산하고, 자신의 KV Cache에 새 K·V를 추가한 뒤 새 Query와 전체 Key·Value Cache로 Attention을 계산한다. 과거 Hidden State 전체나 과거 Query를 다시 만들지 않아도 되는 이유는 과거 Hidden State에서 이미 계산한 Layer별 K·V가 Cache에 보관되어 있기 때문이다. KV Cache는 Hidden State 자체가 아니라 각 Layer의 과거 K·V를 저장하며, 일반적으로 과거 Query와 Layer별 Hidden State 전체는 저장하지 않는다. KV Cache가 없으면 과거 K·V를 만들기 위해 이전 Layer의 과거 Hidden State가 필요하므로 전체 Prefix를 다시 Forward해야 한다. 이때 각 Layer는 전체 토큰의 Hidden State를 다음 Layer로 전달하고 전체 Q·K·V와 Attention을 다시 계산한다. 따라서 Cache가 있을 때의 Attention Score Shape은 [B, H, 1, S]이고, Cache가 없을 때 전체 Prefix를 다시 계산하는 Attention Score Shape은 [B, H, S, S]가 된다. Prefill과 Decode는 서로 다른 모델이 아니라 같은 모델에서 입력 범위와 KV Cache 상태가 다른 실행 단계다.
