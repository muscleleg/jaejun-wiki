데이터베이스·데이터 파이프라인

공통 SQL·관계형/분석 데이터 모델링을 한 학습 단원에서 다룬 뒤, DB 내부 동작과 데이터 파이프라인 실습을 구분해 연결합니다. DB 영역은 Page·Index·Query Plan·Transaction·MVCC·WAL·복제·복구, 파이프라인 영역은 Batch ETL·품질 계약·파일 형식과 성능·오케스트레이션·ML/LLM 데이터 Version·Lineage를 다룹니다. 배열은 권장 순서이며 필요에 따라 Goal Route에서 해당 학습 단원을 선택할 수 있습니다. 기존 DB 정합성 검증과 파이프라인 재현성 검증을 모두 보존하고, 공통 SQL 활동은 각 기준 충족 여부를 확인해 같은 Evidence로 연결합니다.
