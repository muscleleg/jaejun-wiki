Transformer 손코딩

수식을 외우는 대신 작은 Tensor의 Shape과 숫자를 예측하고, 핵심 블록을 직접 연결해 작은 생성 모델까지 만든다.

현재 위치

완료nn.Linear로 Q·K·V를 만들고 QKᵀ / √d_k → Softmax → attention_weights @ value를 연결했다. 첫 번째 Query의 Value 가중합을 실제 숫자로 직접 계산해 PyTorch 출력과 일치함을 확인했다.
현재 질문지금 연결한 Single-head 계산을 하나의 Multi-Head Attention 모듈로 확장하려면 Tensor를 Head별로 어떻게 나누는가?
다음 행동현재 [batch, token, d_model] Tensor에 Head 축을 추가하는 view와 transpose를 작은 Shape으로 실습한다.
