현재 위치

완료 · TransformerBlockTransformerBlock.forward()의 Attention → Residual·LayerNorm → FFN → Residual·LayerNorm을 구현하고 Shape·Token 통계를 검증했으며, 이번 복습에서 전체 흐름과 각 단계의 역할을 다시 설명했다.
진행 · Target shiftToken [[3,7,2,9]]에서 입력 [[3,7,2]]과 다음 Token 정답 [[7,2,9]]을 만들고 두 Shape이 [1,3]임을 확인했다.
진행 · Causal Mask길이 3의 Boolean 하삼각 허용 표를 만들고 masked_fill(~causal_mask,-inf)로 미래 Score를 가렸다. Softmax에서 exp(-inf)=0이 되어 미래 Attention 비율이 0이고 각 행의 합이 1인 결과를 확인했다.
남은 1차 순환Vocabulary Logit과 Token Cross Entropy를 연결해 Tiny Decoder LM의 작은 학습·생성을 마친 뒤, 사전학습 텍스트 모델을 같은 Baseline·Split·Metric으로 적용한다.

교차 트랙 전환 실행

완료한 교차 트랙회원 이탈 Baseline과 PyTorch MLP의 학습·평가·저장·복원·원본 고객 한 명 추론까지 연결해 예약했던 ML·PyTorch 기반 관문을 닫았다.
현재 활성 트랙Tiny Decoder LM을 재개해 Target shift와 Causal Mask·Masked Softmax를 실제 Tensor로 검증했다.
다음 행동Logit Shape [batch,token,vocab]과 Target Shape [batch,token]을 Cross Entropy로 연결하고, 작은 데이터에 학습한 뒤 한 Token씩 생성한다.

보강 상태

완료 · Tensor 축 변환[1,2,3,1] Tensor에서 transpose(1,2) 전후 값을 먼저 주석으로 예측하고, Head별 묶음이 Token별 묶음으로 바뀌어 [1,3,2,1]이 되는 결과와 일치함을 확인했다.
후속 보강Tiny Decoder LM으로 복귀할 때 view·transpose·reshape의 반대 방향 변환을 자료 없이 다시 설명해 장기 기억을 확인한다. 이 보강은 완료한 Transformer Block 관문을 되돌리지 않는다.
예정 · 확률에서 Token Loss까지세 Token의 실제 Logit으로 Softmax 확률을 계산하고 정답 Token의 -log p가 one-hot Cross Entropy이자 Negative Log-Likelihood가 되는 것을 확인한다. 여러 학습 예제의 Log-Likelihood를 최대화하는 것과 평균 NLL을 최소화하는 것이 같은 방향임을 숫자로 검산해 MLE를 학습 목표와 연결한다.
예정 · Entropy와 KL 구분Entropy는 한 분포 자체의 불확실성, Cross Entropy는 정답 분포로 모델 분포를 평가하는 값, KL Divergence는 두 분포 차이임을 같은 세 Token 분포로 계산한다. Tiny LM 코어에서는 Cross Entropy만 구현하고, KL은 Distillation·분포 정규화처럼 실제 필요가 생길 때 사용한다.

Tiny LM 다음의 실제 적용 관문

목적손코딩으로 이해한 구조를 라이브러리 모델 사용과 분리하지 않는다. Tiny Decoder LM을 만든 뒤 작은 공개 텍스트 문제에서 단순 Baseline과 사전학습 Transformer를 같은 데이터 분할과 Metric으로 비교한다.
구현 흐름문제·Label·Metric 정의 → TF-IDF + Logistic 같은 단순 Baseline → Tokenizer의 Special token·Padding·Truncation 확인 → 사전학습 모델 Fine-tuning 또는 Head 학습 → Validation Best checkpoint → Batch 추론을 연결한다.
완료 증거입력 ID·Mask·Logit Shape을 예측하고, Baseline 대비 결과와 길이·클래스별 오류를 설명한다. 저장한 Tokenizer·Config·Label mapping·Weights를 새 프로세스에서 불러 동일한 Batch 예측을 재현한다.
