Transformer 손코딩

수식을 외우는 대신 작은 Tensor의 Shape과 숫자를 예측하고, 핵심 블록을 직접 연결해 작은 생성 모델까지 만든다.

연결 위키7개
검증된 완료 조건 기준67%

현재 위치

완료Q·K·V Projection부터 Head 분리, QKᵀ → √head_dim Scaling → Softmax → Value 가중합, Token 기준 재정렬, d_model 병합과 W_O까지 하나의 MultiHeadAttention.forward()로 구현했다. 최종 출력이 [batch, token, d_model]=[1,2,2]임을 실행 결과로 검증했다.
현재 질문Attention 출력과 원래 입력을 왜 더하며, Residual 연결 뒤 LayerNorm은 어떤 Shape을 유지하는가?
다음 행동축 변환 미니 실습으로 transpose를 보강한 뒤, x + projected_output Residual 연결을 작은 Tensor로 계산하고 Shape을 확인한다.

보강 예정

Tensor 축 변환 연습view·transpose·reshape에서 축 번호와 값의 묶임을 다시 연습한다. Token 수 3, Head 수 2처럼 축 크기가 서로 다른 작은 Tensor를 사용해 변환 전후 Shape과 값의 위치를 먼저 예측한 뒤 PyTorch 출력과 비교한다.
완료 증거[batch, token, head, head_dim]과 [batch, head, token, head_dim]을 자료 없이 서로 변환하고, 왜 Attention 전과 Head 병합 전에 서로 반대 방향의 transpose(1, 2)가 필요한지 설명한다.
