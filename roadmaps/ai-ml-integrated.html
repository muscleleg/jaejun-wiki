머신러닝 기초

알고리즘 이름을 나열하지 않고 실제 데이터를 문제 정의, Baseline, 평가, 개선과 오류 분석까지 연결한다.

완료 직접 유닛 완료 6 / 6

현재 목표에서 선택한 하위 유닛 (6)
  1. 문제와 평가 개념 · Feature·Label·Loss·Metric·Threshold를 구분해 이후 모든 모델과 추론 실험의 문제 정의와 평가 기준을 먼저 고정한다.
  2. 데이터 이해와 분할 · 문제와 평가 기준 다음에 데이터 품질·Label 분포·Train·Validation 분할을 확인해 비교 결과의 누수와 분포 왜곡을 막는다.
  3. 재현 가능한 Baseline · 동일 전처리와 Split에서 단순 모델의 재현 가능한 Baseline을 만들어 이후 신경망 개선을 판정할 기준을 확보한다.
  4. 불균형과 Threshold · 불균형 데이터에서 Accuracy만으로 생기는 오판을 피하고 Threshold에 따른 Precision·Recall과 오류 비용을 해석한다.
  5. PyTorch 모델 비교 · 같은 Split에서 PyTorch MLP와 기존 Baseline을 비교해 Loss 감소가 실제 모델 개선으로 이어졌는지 검증한다.
  6. 오류 분석과 결과 전달 · 모델 비교를 원본 오류 분석·저장 복원·단일 입력 추론과 연결해 재검토 가능한 머신러닝 평가 기준을 완성한다.

PyTorch 기초

Tensor 연산이 계산 그래프와 학습으로 이어지는 원리를 이해하고, 반복 가능한 학습·평가·저장 코드까지 확장한다.

완료 직접 유닛 완료 6 / 6

현재 목표에서 선택한 하위 유닛 (6)
  1. Loss와 계산 그래프 · 머신러닝 평가 기준을 실제 학습 코드로 옮기기 위해 Loss 연산과 Tensor 계산 그래프의 연결부터 확인한다.
  2. Autograd와 수동 SGD · 계산 그래프에서 Gradient를 구하고 수동 SGD로 가중치를 갱신해 Autograd와 Optimizer의 기반을 이해한다.
  3. Tensor Shape 실험실 · Tensor 축 변환·Broadcasting·행렬곱의 Shape과 dtype·device를 추적해 Attention과 Batch 연산의 축 오류를 예방한다.
  4. nn.Module과 Optimizer · 수동 Gradient 갱신을 nn.Module과 Optimizer의 상태·책임으로 연결해 반복 가능한 모델 학습 구조를 만든다.
  5. Dataset·DataLoader와 학습 루프 · Dataset·DataLoader를 학습과 Validation 루프에 연결해 데이터 누수 없이 모델을 학습하고 평가한다.
  6. 디버깅·저장·추론 · Tensor·학습·평가·state_dict 복원·원본 입력 추론을 재현해 Transformer 실행을 직접 통제할 PyTorch 기반을 완성한다.

Transformer 이해와 실습

수식을 외우는 대신 작은 Tensor의 Shape과 숫자를 예측하고, 핵심 블록을 직접 연결해 작은 생성 모델을 만든 뒤 사전학습 Causal LM의 추론 흐름까지 이어갔다.

완료 직접 유닛 완료 8 / 8

현재 목표에서 선택한 하위 유닛 (8)
  1. Token Embedding · 정수 Token ID를 학습 가능한 Feature 벡터로 바꾸는 Embedding과 Batch·Token·Feature 축을 확인한다.
  2. Positional Encoding · Token 표현에 위치 정보를 더해 내용과 순서를 함께 표현하고 Attention 입력의 축 의미를 고정한다.
  3. Single-head Attention · QKᵀ·Scaling·Mask·Softmax·Value 가중합을 직접 구현해 Attention 한 Head의 계산과 차단 축을 검증한다.
  4. Multi-Head Attention 본체 · Single-head 계산을 여러 Head로 분할·병합해 Multi-Head Attention의 값 계산과 Shape 변환을 연결한다.
  5. Transformer Block · Embedding·Attention·Projection·FFN·Residual·Norm을 연결해 Transformer Block의 계산과 Shape 계약을 검증한다.
  6. Tiny Decoder LM · Transformer Block을 LM Head와 결합하고 Target shift·Token Loss·Causal Mask로 작은 Decoder의 학습과 생성을 확인한다.
  7. Tokenizer·Model 로컬 저장과 오프라인 복원 · Tokenizer·Config·Weight를 함께 저장하고 오프라인 복원해 이후 추론 실험에서 사용할 Artifact와 Token 의미를 고정한다.
  8. 사전학습 Causal LM 실제 적용 · 사전학습 Causal LM의 Tokenizer·Forward·수동 생성·평가를 Tiny Decoder와 비교해 실제 모델 추론으로 연결한다.

LLM 추론 기초

LayerNorm·RMSNorm·현대 Decoder 구성요소·KV Cache·Prefill·Decode를 PyTorch Causal LM에서 계산과 Tensor Shape으로 검증하고, 재현 가능한 추론 Benchmark와 출력 검증 계약을 정의한다.

  3. 벤치마크 테스트 기초와 측정 기준 · PyTorch 기준선의 모델·입력·장치와 Timing 경계를 비교 계약으로 고정해 다음 vLLM 결과를 공정하게 비교한다.
