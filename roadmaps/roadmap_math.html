이 로드맵을 쓰는 방법

독립 선수과목이 아니다수학을 다 배운 뒤 모델로 넘어가지 않는다. ML·PyTorch·Transformer의 현재 질문을 해결하는 데 필요한 범위만 열고, 해결하면 즉시 원래 실습으로 돌아간다.
한 개념의 검증 순서현재 코드의 질문 → 작은 숫자와 Shape 예측 → 손계산 → NumPy·PyTorch 결과 비교 → 조건 하나 변경 → 원래 코드에 적용 순서로 확인한다.
완료 판단공식을 보거나 코드를 따라 실행한 것만으로 완료하지 않는다. 계산의 입력·출력과 모델에서의 역할을 자기 말로 설명하고, 작은 예제를 다시 만들거나 결과를 예측해야 증거로 남긴다.

현재 확보한 연결과 남은 확인

통계 · 부분 검증평균·분산·표준편차를 실제 숫자로 계산하고 StandardScaler 결과가 평균 0·표준편차 1이 되는 것을 실행으로 확인했다. 분산 전개를 자료 없이 자기 말로 설명하는 복습은 남아 있다.
벡터와 Scaling · 구현에 사용벡터 길이, 차원과 1 / √d가 Attention Score 및 Embedding Scaling에서 어떤 크기를 조절하는지 기존 Transformer 구현과 연결했다.
삼각함수 · 구현에 사용sin·cos의 파동과 쌍이 위치별 벡터 지문을 만드는 흐름을 Positional Encoding 코드와 연결했다.
미분과 Autograd · 부분 검증y = wx + b의 MSE, 수동 Gradient, backward()와 Optimizer를 작은 PyTorch 예제로 확인했다. 여러 변수가 이어진 계산의 편미분과 Chain Rule은 현재 MLP에서 다시 검증한다.
행렬 연산 · 구현에 사용Transpose·Matrix Multiplication과 QKᵀ의 Shape을 Attention 구현에서 사용했다. Dot Product·직교성·기저는 필요한 코드와 함께 더 명시적으로 확인한다.

가장 가까운 두 연결

회원 이탈 MLP

질문: Logit이 sigmoid와 BCE를 지나 Loss가 되고, 각 Weight의 Gradient로 돌아가는가?

필요 수학: 편미분, 다변수 Chain Rule, 평균 Loss의 Gradient, sigmoid의 기울기.

검증: 한 Batch의 일부 값을 손계산하거나 유한차분으로 구해 Autograd와 비교한다. 현재 MLP의 진행 순서는 바꾸지 않는다.

Tiny Decoder LM

질문: Logit에서 다음 Token 확률과 Token Loss가 어떻게 만들어지는가?

필요 수학: Softmax, Log Probability, Negative Log-Likelihood, Maximum Likelihood, Entropy·Cross Entropy·KL Divergence.

검증: 작은 Vocabulary의 Logit으로 확률 합과 정답 Token Loss를 계산하고 PyTorch 결과와 비교한다.

필요할 때 여는 수학 역량 지도

1 · 벡터·Tensor·행렬Scalar·Vector·Matrix·Tensor, Shape, Norm, Unit Vector, Dot Product, Transpose, Hadamard Product, Reduction, Matrix Multiplication을 실제 연산으로 확인한다. Basis·Orthogonal·Orthonormal은 Embedding·Projection·유사도 또는 차원 축소에서 필요할 때 연결한다.
2 · 미분·Gradient·Autodiff변화율과 도함수, Product·Quotient·Chain Rule, Partial Derivative, 다변수 Chain Rule, Gradient를 다룬다. 손계산·유한차분·PyTorch Autograd가 같은 방향을 가리키는지 비교한다.
3 · 확률·통계평균·분산·표준편차·기댓값에서 시작해 결합·조건부확률, Bayes Rule, 분포, Likelihood를 모델 평가와 Loss에 연결한다. Calibration과 불확실성은 실제 예측 확률을 평가할 때 확장한다.
4 · 최적화·수치 안정성Gradient Descent, Learning Rate, 최소점과 곡률의 직관, 초기화, Floating-point 오차, 안정적인 Softmax와 LogSumExp를 학습 실패와 NaN 디버깅에 연결한다.
5 · 고유값·SVD·Low RankEigenvector·Eigenvalue, Eigendecomposition, SVD와 PCA를 차원 축소 실습에서 확인한다. Low-rank 근사는 LoRA의 ΔW = BA와 모델 압축을 설명할 때 다시 사용한다.
6 · 적분과 평가 면적적분 과정을 별도로 완주하지 않는다. ROC-AUC가 Threshold에 따른 곡선 아래 면적이라는 뜻을 이해하고, 작은 좌표의 사다리꼴 수치 적분을 라이브러리 결과와 비교할 만큼만 다룬다.

보유 강의에서 취할 것과 미룰 것

우선 취한다Norm·Unit Vector, Dot Product·Matrix Multiplication, Transpose·Orthogonality, Chain Rule·Partial Derivative·Autodiff, MSE Gradient, Eigen·SVD·PCA·Low Rank, ROC-AUC의 수치 면적을 위 역량 지도의 해당 실습으로 압축한다.
필요할 때만 취한다Linear System, Gaussian Elimination, Determinant, Matrix Inverse·Pseudoinverse의 반복 계산은 회귀 해법이나 수치 문제를 설명해야 할 때만 연다. Higher-order Partial Derivative도 곡률이나 최적화를 직접 비교할 때만 다룬다.
현재 제외한다같은 개념의 TensorFlow 재구현과 API 사용법 반복, 행렬식·역행렬 계산 훈련, 적분 기법 전체 완주는 현재 Python·PyTorch 프로젝트 결과물에 직접 필요하지 않으므로 코어에서 제외한다.
