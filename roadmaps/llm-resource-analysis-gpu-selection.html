LLM 자원 요구량 분석과 GPU 선정

모델과 사용 요구를 보고 적절한 GPU를 선정하고, GPU를 보고 사용할 모델과 정밀도·문맥 길이·동시 요청 범위를 판단한다. 실제 모델의 구조와 GPU 사양으로 메모리·연산량·데이터 이동량·성능 상한을 먼저 계산한 뒤 RunPod 실측으로 검증하고 차이의 원인을 분석한다. 사용 조건 정의 → 이론 예측 → 실측 → 차이 분석 → 예측 보완을 반복하며, 메모리 수용 여부와 요구 성능 충족 여부를 함께 판단한다. Qwen3-4B·Qwen3-8B·Mistral-7B-v0.3·양자화 Qwen·Qwen3-30B-A3B·gpt-oss-20b와 여러 GPU를 대상으로 계산 노트북과 재현 가능한 실험 기록을 만든다.
