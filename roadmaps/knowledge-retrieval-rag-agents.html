RAG·Tool Calling·Agent 핵심

LLM 호출과 문맥, RAG 문서 준비·검색·근거 기반 답변·평가, Tool Calling과 Agent 행동 루프·상태·실행 경계를 단계별로 배우고 작은 서비스로 종합 검증한다. 핵심 이해는 각 단계의 입력·출력 설명, 구현·관찰, 실패 원인 분석과 동일 조건의 설계 비교로 확인한다. RAG와 Tool Calling은 공통 호출 기초 뒤 각각 학습할 수 있으며 종합 검증에서 연결한다. Knowledge Graph·GraphRAG는 별도 선택 확장으로 핵심 과정의 완료 조건에 포함하지 않는다.
