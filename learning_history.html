Transformer Layer는 앞 Layer의 출력 Hidden State에 의존해 Layer 1→Layer 2→Layer 3 순서로 처리된다. 각 Layer는 자신의 Q·K·V Projection과 KV Cache를 따로 가지지만 한 Layer 안의 여러 Token은 병렬로 계산할 수 있다. GQA에서 Query Head 4개와 KV Head 2개를 사용하는 경우 K·V Projection부터 출력 크기를 작게 설계한다. Prompt 전체의 Q·K·V로 Prefill을 수행해 K·V를 Cache에 저장하고, 새 Token의 Q·K·V만 계산해 K·V를 Cache에 추가한 뒤 Q5와 전체 Cache로 Decode Attention을 계산한다.

KV Cache가 있으면 Decode에서 새 토큰 하나의 Hidden State만 Layer 사이를 이동한다. 각 Transformer Layer는 새 토큰의 Q·K·V를 계산하고, 자신의 KV Cache에 새 K·V를 추가한 뒤 새 Query와 전체 Key·Value Cache로 Attention을 계산한다. 과거 Hidden State 전체나 과거 Query를 다시 만들지 않아도 되는 이유는 과거 Hidden State에서 이미 계산한 Layer별 K·V가 Cache에 보관되어 있기 때문이다. KV Cache는 Hidden State 자체가 아니라 각 Layer의 과거 K·V를 저장하며, 일반적으로 과거 Query와 Layer별 Hidden State 전체는 저장하지 않는다. KV Cache가 없으면 과거 K·V를 만들기 위해 이전 Layer의 과거 Hidden State가 필요하므로 전체 Prefix를 다시 Forward해야 한다. 이때 각 Layer는 전체 토큰의 Hidden State를 다음 Layer로 전달하고 전체 Q·K·V와 Attention을 다시 계산한다. 따라서 Cache가 있을 때의 Attention Score Shape은 [B, H, 1, S]이고, Cache가 없을 때 전체 Prefix를 다시 계산하는 Attention Score Shape은 [B, H, S, S]가 된다. Prefill과 Decode는 서로 다른 모델이 아니라 같은 모델에서 입력 범위와 KV Cache 상태가 다른 실행 단계다.
