Q Projection과 nn.Linear 내부 계산 확인

입력 x=[1, 2, 2]를 nn.Linear(2, 2, bias=False)에 통과시켜 Query를 만들었다. Linear가 마지막 벡터 차원만 변환하므로 Shape은 [1, 2, 2]로 유지되지만 값과 역할은 달라진다는 점을 확인했다. 또한 x @ weight.T를 직접 계산하고 torch.allclose()가 True임을 확인해 Linear의 결과와 직접 행렬곱이 같다는 것을 검증했다.

Scaled Dot-Product Attention 핵심 구현 완성

attention_weights @ value의 Shape을 예상하고, 가운데 Token 축이 곱의 합으로 처리되며 각 Query 출력이 Value의 가중합이라는 사실을 숫자로 확인했다. 현재 코드의 출력·Attention weight 반환과 Mask 동작도 검사했다.

회원 이탈 예측으로 머신러닝 실무 흐름 정리

동료와의 대화에서 발견한 질문을 Feature·Label·Loss·Threshold·Confusion Matrix·Precision·Recall·F1·데이터 분할·반복 실험의 흐름으로 정리했다. ROC/PR-AUC, Calibration과 불균형 처리는 이후 실습에서 검증할 항목으로 분리했다.

Loss와 자동미분의 개발자 관점 연결

여러 Tensor 연산 자체가 하나의 Loss 함수를 만들고, Tensor가 계산 그래프를 보존해 backward()가 변화율을 구한다는 관점을 정리했다.

한 파라미터 Autograd 핵심 검증

Loss=(wx-y)²에서 2(wx-y)x를 극한식으로 유도하고 PyTorch Gradient와 일치함을 확인했다. Gradient 누적·초기화, no_grad 안의 in-place 업데이트와 반복 학습에서 수정 전 Loss·수정 후 w의 시점 차이도 실행 결과로 확인했다.

End-to-end 로드맵 누락 감사
