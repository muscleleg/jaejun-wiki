최단거리

DFS 다음에 BFS를 처음 적용한 문제다. 같은 거리의 칸을 먼저 처리하는 Queue의 성질과, 격자에 거리를 직접 기록하는 방법을 확인한다.

이 문제에서 연습한 핵심

  • BFS(Breadth-First Search, 너비 우선 탐색)
  • collections.deque의 FIFO Queue
  • 동일 가중치 격자의 최단거리
  • 2차원 좌표의 상하좌우 탐색
  • 방문 여부와 거리를 하나의 격자에 기록

BFS는 왜 최단거리를 보장하는가?

DFS가 한 경로를 깊게 내려간다면, BFS는 현재 거리에서 갈 수 있는 칸을 먼저 모두 처리하고 다음 거리로 넘어간다.

from collections import deque

queue = deque()
queue.append((0, 0))

while queue:
    row, col = queue.popleft()

append()는 Queue 뒤에 넣고 popleft()는 앞에서 꺼낸다. 이 FIFO 순서 때문에 가까운 칸이 먼 칸보다 먼저 처리된다.

동일한 이동 비용이라는 전제
모든 칸을 한 번 이동하는 비용이 같기 때문에, 도착점에 처음 도착했을 때의 거리가 최단거리다.

상하좌우 탐색과 범위 체크

현재 좌표를 기준으로 네 방향의 다음 좌표를 계산한다.

d_row = [-1, 0, 1, 0]
d_col = [0, 1, 0, -1]

for i in range(4):
    n_row = row + d_row[i]
    n_col = col + d_col[i]

현재 row, col을 직접 수정하면 첫 번째 방향을 탐색한 뒤 바뀐 좌표를 기준으로 다음 방향을 계산하게 된다. 따라서 다음 좌표는 반드시 별도 변수에 저장한다.

# 잘못된 방식
row = row + d_row[i]
col = col + d_col[i]

# 올바른 방식
n_row = row + d_row[i]
n_col = col + d_col[i]

범위는 양쪽 방향을 모두 확인해야 한다.

if 0 <= n_row < n and 0 <= n_col < m:
Python에서는 -1이 마지막 원소를 가리키는 유효한 인덱스다. n_row < n만 검사하면 음수 좌표가 통과할 수 있으므로 하한 0도 반드시 검사한다.

방문 여부와 거리 기록을 함께 저장하기

이 문제에서는 별도 visited 배열을 만들지 않고 maps 자체에 방문 여부와 거리를 기록한다.

if maps[n_row][n_col] != 1:
    continue

maps[n_row][n_col] = maps[row][col] + 1
  • 1: 아직 방문하지 않은 길
  • 0: 벽
  • 2 이상: 방문했고 시작점에서의 거리가 기록된 칸

처음 길의 값이 1이므로 다음 칸은 현재 칸의 거리보다 1 큰 값으로 기록한다.

도착점에 처음 도달하면 BFS의 순서상 최단거리이므로 바로 반환할 수 있다.

if n_row == n - 1 and n_col == m - 1:
    return maps[n_row][n_col]

return maps[row][col] + 1도 같은 값이지만, 이미 도착점에 기록한 값을 반환하는 쪽이 읽기 쉽다.

헷갈렸던 지점과 실패한 접근

1. row, col을 직접 수정
방향을 바꿀 때 기준 좌표가 오염된다. 항상 n_row, n_col을 별도로 만든다.
2. 음수 인덱스 범위 체크 누락
n_row < n만으로는 부족하다. 0 <= n_row < n과 0 <= n_col < m을 함께 검사한다.
3. 방문 처리 누락
방문한 칸을 다시 Queue에 넣으면 같은 칸을 반복 탐색한다. 방문 시점에 거리 값을 기록해 다시 들어오지 않게 한다.
4. answer += 1로 거리 세기
같은 거리의 칸이 여러 개이면 popleft() 횟수와 이동 거리가 달라진다. Queue에서 꺼낸 횟수가 아니라 각 칸에 부모 거리 + 1을 기록해야 한다.

최종 코드

from collections import deque

def solution(maps):
    n, m = len(maps), len(maps[0])

    d_row = [-1, 0, 1, 0]
    d_col = [0, 1, 0, -1]

    queue = deque()
    queue.append((0, 0))

    while queue:
        row, col = queue.popleft()

        for i in range(4):
            n_row = row + d_row[i]
            n_col = col + d_col[i]

            if 0 <= n_row < n and 0 <= n_col < m:
                if maps[n_row][n_col] != 1:
                    continue

                maps[n_row][n_col] = maps[row][col] + 1

                if n_row == n - 1 and n_col == m - 1:
                    return maps[n_row][n_col]

                queue.append((n_row, n_col))

    return -1

DFS와 BFS 비교

DFS한 경로를 깊게 탐색한다. 재귀나 Stack으로 구현하며 타겟 넘버처럼 선택지가 갈라지는 모든 경우를 확인하는 데 적합하다.
BFS같은 깊이·거리를 먼저 탐색한다. Queue의 FIFO 순서를 이용하며 동일 가중치 그래프의 최단거리에 적합하다.
DFS: root → a → c → d → b → e → f
BFS: root → a → b → c → d → e → f

타겟 넘버에서 DFS를 배웠다면, 이번 문제에서는 “옆으로 먼저 전부 탐색한다”는 BFS 감각을 추가한 것이다.
