같은 숫자는 싫어

문제를 풀면서 실제로 사용한 개념, 풀이의 순서와 헷갈렸던 지점을 다시 풀기 좋은 형태로 보존한다.

풀이 완료list순회연속중복
프로그래머스 문제 열기 ↗
이 문제 복습핵심 개념풀이 흐름핵심 코드헷갈렸던 지점다시 풀기 체크← 전체 문제

이 문제에서 연습한 핵심

  • list
  • 순회
  • 연속중복

풀이 흐름

  1. 리스트를 앞에서부터 순회한다.
  2. 현재 값과 직전에 보관한 값을 비교한다.
  3. 값이 달라질 때만 결과 리스트에 추가한다.

기억할 코드 형태

if not answer or answer[-1] != value:
    answer.append(value)

헷갈렸던 지점

모든 중복을 제거하는 set 문제가 아니라 서로 붙어 있는 중복만 제거하는 문제다.

다시 풀 때 확인할 것

[1, 1, 3, 3, 0, 1, 1]에서 마지막 1이 남는 이유를 설명한다.
