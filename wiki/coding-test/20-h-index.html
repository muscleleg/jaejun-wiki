H-Index

문제를 풀면서 실제로 사용한 개념, 풀이의 순서와 헷갈렸던 지점을 다시 풀기 좋은 형태로 보존한다.

풀이 완료candidate완전탐색counting

이 문제에서 연습한 핵심

  • candidate
  • 완전탐색
  • counting

풀이 흐름

  1. h는 입력값이 아니라 직접 찾아야 하는 후보값이다.
  2. 0부터 논문 수 n까지 각 h를 검사한다.
  3. h번 이상 인용된 논문이 h편 이상이면 가능한 후보로 기록한다.

기억할 코드 형태

for h in range(len(citations) + 1):
    count = sum(citation >= h for citation in citations)
    if count >= h:
        answer = h

헷갈렸던 지점

h가 citations 안의 실제 값일 필요는 없다. h편 이상이라는 조건 때문에 h의 최댓값은 전체 논문 수 n이다.

다시 풀 때 확인할 것

citations에 100이 있어도 논문이 5편이면 h가 5를 넘을 수 없는 이유를 설명한다.
