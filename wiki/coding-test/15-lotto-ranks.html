로또의 최고 순위와 최저 순위

문제를 풀면서 실제로 사용한 개념, 풀이의 순서와 헷갈렸던 지점을 다시 풀기 좋은 형태로 보존한다.

풀이 완료setcountmapping
프로그래머스 문제 열기 ↗
이 문제 복습핵심 개념풀이 흐름핵심 코드헷갈렸던 지점다시 풀기 체크← 전체 문제

이 문제에서 연습한 핵심

  • set
  • count
  • mapping

풀이 흐름

  1. 알아볼 수 있는 번호 중 당첨 번호와 일치하는 개수를 센다.
  2. 0의 개수는 최고 순위에서 추가로 맞을 수 있는 수다.
  3. 맞춘 개수를 순위로 변환한다.

기억할 코드 형태

best = matches + lottos.count(0)
worst = matches
best_rank = min(7 - best, 6)
worst_rank = min(7 - worst, 6)

헷갈렸던 지점

0은 맞은 수도 틀린 수도 확정되지 않았으므로 최고·최저 경우를 나누어 계산한다. 0개와 1개 일치는 모두 6등이다.

다시 풀 때 확인할 것

확정 일치 2개와 0이 3개일 때 최고·최저 순위를 구한다.
