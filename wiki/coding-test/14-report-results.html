신고 결과 받기

문제를 풀면서 실제로 사용한 개념, 풀이의 순서와 헷갈렸던 지점을 다시 풀기 좋은 형태로 보존한다.

풀이 완료dictsetsplit
프로그래머스 문제 열기 ↗
이 문제 복습핵심 개념풀이 흐름핵심 코드헷갈렸던 지점다시 풀기 체크← 전체 문제

이 문제에서 연습한 핵심

  • dict
  • set
  • split

풀이 흐름

  1. 신고 문자열을 신고자와 대상자로 split한다.
  2. 신고자별 대상 집합을 만들어 중복 신고를 제거한다.
  3. 대상별 신고 횟수를 센 뒤 정지된 사용자를 신고한 사람에게 결과를 보낸다.

기억할 코드 형태

tmp_set = report_map.get(name, set())
tmp_set.add(target)
report_map[name] = tmp_set

헷갈렸던 지점

set.add()는 수정된 set을 반환하지 않고 None을 반환한다. 따라서 report_map[name] = tmp_set.add(target)처럼 쓰면 값이 None이 된다.

다시 풀 때 확인할 것

같은 사람이 동일 사용자를 두 번 신고해도 한 번만 계산되는 이유를 설명한다.
