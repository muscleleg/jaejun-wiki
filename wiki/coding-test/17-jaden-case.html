JadenCase 문자열 만들기

문제를 풀면서 실제로 사용한 개념, 풀이의 순서와 헷갈렸던 지점을 다시 풀기 좋은 형태로 보존한다.

풀이 완료stringsplitjoinimmutable
프로그래머스 문제 열기 ↗
이 문제 복습핵심 개념풀이 흐름핵심 코드헷갈렸던 지점다시 풀기 체크← 전체 문제

이 문제에서 연습한 핵심

  • string
  • split
  • join
  • immutable

풀이 흐름

  1. 공백 개수를 보존하기 위해 split(" ")을 사용한다.
  2. 빈 문자열은 그대로 두고 단어만 첫 글자를 대문자, 나머지를 소문자로 만든다.
  3. join으로 원래 공백 구조를 복원한다.

기억할 코드 형태

words = s.split(' ')
for i, item in enumerate(words):
    if item:
        words[i] = item[0].upper() + item[1:].lower()
answer = ' '.join(words)

헷갈렸던 지점

split()은 연속 공백을 합쳐 버리지만 split(' ')은 빈 문자열을 남긴다. 문자열은 immutable이라 item[0]에 직접 대입할 수 없다.

다시 풀 때 확인할 것

'a b'를 split()과 split(' ')으로 나눈 결과를 각각 말한다.
