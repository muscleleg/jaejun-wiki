두 개 뽑아서 더하기

문제를 풀면서 실제로 사용한 개념, 풀이의 순서와 헷갈렸던 지점을 다시 풀기 좋은 형태로 보존한다.

풀이 완료combinationsetnested-loop
프로그래머스 문제 열기 ↗
이 문제 복습핵심 개념풀이 흐름핵심 코드헷갈렸던 지점다시 풀기 체크← 전체 문제

이 문제에서 연습한 핵심

  • combination
  • set
  • nested-loop

풀이 흐름

  1. 첫 번째 인덱스 i를 순회한다.
  2. 두 번째 인덱스 j는 i+1부터 시작한다.
  3. 두 값을 더해 set에 넣고 마지막에 정렬한다.

기억할 코드 형태

for i in range(n):
    for j in range(i + 1, n):
        sums.add(numbers[i] + numbers[j])

헷갈렸던 지점

j를 0부터 돌리면 같은 원소를 다시 고르거나 (i, j)와 (j, i)를 중복 계산한다.

다시 풀 때 확인할 것

왜 i < j 조건이 같은 두 위치를 다시 뽑지 않게 하는지 설명한다.
