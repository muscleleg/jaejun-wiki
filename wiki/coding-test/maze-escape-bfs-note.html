미로 탈출
BFS 응용 메모

아직 완료 문제로 세지 않는다. 하나의 BFS가 공유하는 boolean으로 경로별 상태를 표현하려 했던 문제와, 필수 경유점을 기준으로 최단거리 탐색을 두 번 나누는 사고를 기록한다.

처음 접근

BFS 한 번 안에 lever_pull을 두고 레버에 도착하면 값을 바꾼 뒤 출구를 찾으려고 했다.

lever_pull = False

if maps[row][col] == "L":
    lever_pull = True

실수 · 모든 경로가 하나의 lever_pull을 공유했다

BFS Queue에는 서로 다른 경로에서 도착한 노드들이 동시에 들어 있다. 경로 A가 레버에 도착해 바깥 boolean을 True로 바꾸면, 레버를 지나지 않은 경로 B와 C도 레버를 당긴 상태처럼 처리된다.

경로 A ─ 레버 도착 → lever_pull = True
경로 B ─ 레버를 지나지 않음 ┐
경로 C ─ 레버를 지나지 않음 ┴ 같은 True를 읽음
하나의 전역 boolean은 “현재 경로가 레버를 거쳤는가?”라는 경로별 상태를 표현하지 못한다.

더 단순한 해결 · 필수 경유점을 기준으로 탐색을 나눈다

이 문제의 이동 순서는 반드시 S → L → E다. 그러므로 복합 상태를 한 BFS에 억지로 넣는 대신 같은 최단거리 함수를 두 번 호출한다.

to_lever = bfs(start, lever)
to_end = bfs(lever, end)

answer = to_lever + to_end

S → L 또는 L → E 중 하나라도 도달할 수 없다면 전체 결과는 실패다.

이번에 얻은 사고
필수 경유 순서가 고정되어 있다면 “상태를 더 복잡하게 넣을까?”보다 “독립된 최단거리 문제로 나눌 수 있을까?”를 먼저 확인한다.

이전 문제의 조건을 그대로 가져오지 않는다

게임 맵 최단거리에서는 도착점이 오른쪽 아래였지만, 미로 탈출의 E는 임의 위치다. 입력을 순회해 S, L, E를 각각 찾아야 한다.

if maps[row][col] == "E":
    end = (row, col)
이전 문제에서 성립했던 입력 조건을 다음 문제에도 당연히 성립한다고 가정하지 않는다.
