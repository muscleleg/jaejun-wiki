최댓값과 최솟값

문제를 풀면서 실제로 사용한 개념, 풀이의 순서와 헷갈렸던 지점을 다시 풀기 좋은 형태로 보존한다.

풀이 완료splitmapintmin-max
프로그래머스 문제 열기 ↗
이 문제 복습핵심 개념풀이 흐름핵심 코드헷갈렸던 지점다시 풀기 체크← 전체 문제

이 문제에서 연습한 핵심

  • split
  • map
  • int
  • min-max

풀이 흐름

  1. 문자열을 공백 기준으로 나눈다.
  2. 각 문자열 숫자를 int로 변환한다.
  3. min과 max를 구해 다시 문자열로 조합한다.

기억할 코드 형태

numbers = [int(ch) for ch in s.split()]
answer = f"{min(numbers)} {max(numbers)}"

헷갈렸던 지점

split 결과를 문자열 상태로 비교하면 숫자의 크기가 아니라 문자열 사전식 순서로 비교될 수 있다.

다시 풀 때 확인할 것

문자열 '2'와 '10'을 그대로 비교하면 왜 숫자 비교와 다른지 설명한다.
