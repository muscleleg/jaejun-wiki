예산

문제를 풀면서 실제로 사용한 개념, 풀이의 순서와 헷갈렸던 지점을 다시 풀기 좋은 형태로 보존한다.

풀이 완료sortgreedy누적합
프로그래머스 문제 열기 ↗
이 문제 복습핵심 개념풀이 흐름핵심 코드헷갈렸던 지점다시 풀기 체크← 전체 문제

이 문제에서 연습한 핵심

  • sort
  • greedy
  • 누적합

풀이 흐름

  1. 신청 금액을 오름차순으로 정렬한다.
  2. 가장 작은 금액부터 예산에 더한다.
  3. 다음 금액을 더하면 예산을 넘는 순간 종료한다.

기억할 코드 형태

for cost in sorted(d):
    if used + cost > budget:
        break
    used += cost
    count += 1

헷갈렸던 지점

정확히 특정 합을 만드는 문제가 아니라 지원 가능한 부서 수를 최대화하는 문제이므로 작은 비용부터 고르는 것이 유리하다.

다시 풀 때 확인할 것

왜 큰 신청부터 고르면 지원 부서 수가 줄어들 수 있는지 반례를 만든다.
