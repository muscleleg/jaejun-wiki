퍼즐 게임 챌린지

숙련도는 입력이 아니라 찾아야 할 후보라는 점부터 다시 해석하고, 후보 숙련도로 전체 퍼즐 시간을 Simulation한 뒤 제한 시간 안에 가능한 최초 경계를 찾았다.

입력과 출력

diffs[i]와 times[i]는 같은 i번째 퍼즐의 난이도와 한 번 시도하는 기본 시간이다. 퍼즐은 배열 순서대로 모두 풀며, level은 입력으로 주어지는 현재 능력이 아니라 전체 퍼즐을 limit 안에 끝내기 위해 찾아야 할 최소 숙련도다.

입력: 퍼즐별 난이도, 퍼즐별 기본 시간, 제한 시간
출력: 제한 시간 안에 끝낼 수 있는 최소 숙련도

현재 퍼즐 실패 뒤 이전 퍼즐을 다시 푼다

숙련도가 난이도보다 낮으면 mistakes = diff - level번 실패한다. 이 차이는 남은 작업량이 아니라 문제에서 직접 정한 실패 횟수다. 실패할 때마다 현재 퍼즐을 시도한 시간과 이전 퍼즐을 다시 푸는 시간이 들고, 모든 실패가 끝난 뒤 현재 퍼즐을 한 번 더 시도해 성공한다.

현재 실패 → 이전 퍼즐 재풀이
현재 실패 → 이전 퍼즐 재풀이
현재 성공

실패가 두 번이면 시간은 (현재+이전)×2+현재다. 마지막 성공 뒤에는 실패 벌칙이 없으므로 이전 퍼즐 시간이 붙지 않는다.

첫 퍼즐에 이전 시간이 필요 없는 이유

제한사항의 diffs[0] = 1과 숙련도가 양의 정수라는 조건 때문에 첫 퍼즐은 어떤 후보 숙련도에서도 실패하지 않는다. 따라서 첫 퍼즐은 times[0]만 더하고, times[i-1]은 두 번째 퍼즐부터 실패한 경우에만 사용한다.

후보 숙련도의 총시간

숙련도 후보 하나가 주어지면 모든 퍼즐을 순서대로 방문한다. 난이도가 숙련도 이하면 현재 시간만 누적하고, 더 높으면 실패 횟수만큼 실패·이전 퍼즐 재풀이 시간을 누적한 뒤 마지막 성공 시간을 더한다.

한 번의 실패 시간 = current_time + previous_time
모든 실패 시간 = 한 번의 실패 시간 × mistakes
현재 퍼즐 전체 시간 = 모든 실패 시간 + 마지막 current_time

예제에서 숙련도 1은 첫 퍼즐 2분, 두 번째 퍼즐 28분, 세 번째 퍼즐 29분으로 총 59분이어서 limit=30을 넘는다.

탐색 대상은 숙련도다

left = 1
right = max(diffs)
level = (left + right) // 2

max(diffs)만큼의 숙련도면 가장 어려운 퍼즐까지 한 번에 풀어 모든 실패가 사라진다. 그보다 높은 숙련도는 결과를 더 줄이지 않으므로 이 범위 안에서 후보 숙련도를 탐색한다.

후보 숙련도로 계산한 총시간이 제한 시간 이하면 충분하므로 더 낮은 숙련도를 찾고, 초과하면 부족하므로 더 높은 숙련도를 찾는다.

제한 시간과 같아도 성공이다

total <= limit  → 가능 → right = level - 1
total > limit   → 불가능 → left = level + 1

처음에는 limit <= total을 실패 조건으로 써서 total == limit까지 실패로 처리했다. 실패부터 검사하려면 등호 없이 total > limit 또는 같은 뜻인 limit < total이어야 한다.

제출에 통과한 흐름

def solution(diffs, times, limit):
    left = 1
    right = max(diffs)

    while left <= right:
        level = (left + right) // 2
        total = 0

        for i in range(len(diffs)):
            current_time = times[i]

            if diffs[i] <= level:
                total += current_time
            else:
                previous_time = times[i - 1]
                mistakes = diffs[i] - level
                total += (current_time + previous_time) * mistakes + current_time

        if total > limit:
            left = level + 1
        else:
            right = level - 1

    return left

실제로 막혔던 지점

  • 예제 설명의 숙련도 3은 입력이 아니라 이미 알려진 출력값을 대입한 검증이었다.
  • diffs·times는 선택지가 아니라 같은 인덱스끼리 묶인 순서 있는 퍼즐 목록이었다.
  • 숙련도는 기본 시간을 줄이지 않고 실패 횟수만 바꾼다.
  • diff-level은 남은 작업량이 아니라 문제에서 직접 정의한 실패 횟수다.
  • 이전 퍼즐은 현재 퍼즐을 시도하기 전에 항상 푸는 것이 아니라 현재 퍼즐에서 실패한 뒤에만 다시 푸는 벌칙이다.
  • range(len(diffs))는 난이도만큼 반복하는 것이 아니라 모든 퍼즐 인덱스를 한 번씩 방문한다.
  • right=max(diffs)는 가장 어려운 퍼즐을 고르는 것이 아니라 최소 숙련도의 후보 상한을 정한다.
  • total==limit은 제한 시간 안에 정확히 끝낸 성공이다.
