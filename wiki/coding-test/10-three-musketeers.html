삼총사

문제를 풀면서 실제로 사용한 개념, 풀이의 순서와 헷갈렸던 지점을 다시 풀기 좋은 형태로 보존한다.

풀이 완료combination완전탐색triple-loop
프로그래머스 문제 열기 ↗
이 문제 복습핵심 개념풀이 흐름핵심 코드헷갈렸던 지점다시 풀기 체크← 전체 문제

이 문제에서 연습한 핵심

  • combination
  • 완전탐색
  • triple-loop

풀이 흐름

  1. 서로 다른 세 인덱스를 i < j < k 순서로 고른다.
  2. 세 값의 합이 0인지 확인한다.
  3. 조건을 만족하는 조합 수를 센다.

기억할 코드 형태

for i in range(n):
    for j in range(i + 1, n):
        for k in range(j + 1, n):
            if number[i] + number[j] + number[k] == 0:
                answer += 1

헷갈렸던 지점

값이 같더라도 위치가 다르면 다른 학생이다. 조합은 순서를 세지 않으므로 인덱스를 증가하는 순서로만 고른다.

다시 풀 때 확인할 것

i < j < k가 한 조합을 정확히 한 번만 세는 이유를 설명한다.
