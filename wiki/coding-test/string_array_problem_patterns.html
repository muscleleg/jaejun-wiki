문자열·배열 문제 해결 패턴

개별 문제 답을 외우지 않고, 입력 계약을 확인한 뒤 정규화·양끝 비교·누적·순서 보존·정렬 key로 바꾸는 공통 사고법을 모읍니다.

1. 먼저 보존할 것과 버릴 것을 정한다

질문결과에 미치는 영향
대소문자를 구분하는가?원문 비교 또는 case normalization
공백·구두점을 무시하는가?filter 단계 필요
Unicode 문자가 가능한가?단순 ASCII 범위 계산 회피
중복을 없애도 원래 순서를 보존하는가?set 단독 사용 여부 결정
숫자 범위가 primitive를 넘는가?문자열 계산 또는 큰 정수 필요

같은 “문자열 뒤집기”도 전체 문자, 단어 순서, 각 단어 내부 중 무엇을 뒤집는지 다릅니다. 예제보다 문제의 입력·출력 계약을 먼저 한 문장으로 적습니다.

2. 비교 전에 정규화 pipeline을 만든다

normalized = "".join(
    char.casefold()
    for char in text
    if char.isalnum()
)

lower()는 일반적인 대소문자 변환이고 casefold()는 Unicode caseless comparison에 더 적극적입니다. 어떤 언어권 문자를 허용하는지에 따라 결과가 달라질 수 있으므로 “영문 대문자는 32를 더한다” 같은 ASCII(미국 정보 교환 표준 부호) 전용 계산을 일반 해법으로 쓰지 않습니다.

3. 뒤집기는 index 범위를 먼저 그린다

Python에서 전체 문자열은 text[::-1]로 뒤집을 수 있습니다. 직접 구현해야 하면 mutable character array에서 left와 right를 교환합니다.

chars = list(text)
left, right = 0, len(chars) - 1
while left < right:
    chars[left], chars[right] = chars[right], chars[left]
    left += 1
    right -= 1
result = "".join(chars)

단어별 뒤집기라면 공백을 잃어도 되는지 확인합니다. split()과 " ".join()은 여러 공백을 하나로 바꾸므로 원본 간격 보존이 요구되면 다른 tokenization이 필요합니다.

4. Palindrome은 양끝 포인터의 대표 문제다

def is_palindrome(text):
    chars = [c.casefold() for c in text if c.isalnum()]
    left, right = 0, len(chars) - 1
    while left < right:
        if chars[left] != chars[right]:
            return False
        left += 1
        right -= 1
    return True

Palindrome(회문)은 앞뒤로 읽었을 때 같은 sequence입니다. 정규화한 새 list를 만들면 시간 O(n), 보조 공간 O(n)입니다. 원문 위에서 양쪽의 무시할 문자를 건너뛰면 보조 공간을 O(1)로 줄일 수 있지만 code와 Unicode 처리 계약이 복잡해집니다.

5. 중복 제거는 membership과 순서를 분리해 생각한다

seen = set()
result = []
for value in values:
    if value not in seen:
        seen.add(value)
        result.append(value)

set은 “이미 봤는가”를 평균 O(1)에 검사하고, result list는 원래 순서를 보존합니다. 값이 작은 정수 범위로 제한되면 boolean array가 더 단순할 수 있습니다. 반대로 마지막 항목만 남기거나 빈도 순으로 정렬해야 하면 같은 code를 그대로 쓸 수 없습니다.

6. 숫자 추출은 문자 선택과 수 변환을 나눈다

digits = "".join(char for char in text if char.isdigit())
number = int(digits) if digits else 0

선행 0을 보존해야 한다면 integer로 바꾸면 안 됩니다. 매우 긴 숫자도 언어의 정수 범위를 확인합니다. Java에서는 ASCII 숫자만 대상으로 할 때 value = value * 10 + (ch - '0')로 누적할 수 있지만 overflow 검사와 입력 범위가 필요합니다.

7. 정렬 문제는 비교 기준을 tuple로 표현한다

records.sort(key=lambda item: (-item.score, item.name, item.id))

점수 내림차순, 이름 오름차순, ID 오름차순처럼 우선순위를 차례로 tuple에 둡니다. 원본 값을 직접 뒤집거나 문자열을 이어 붙인 임시 key는 type과 자릿수에 따라 잘못된 순서를 만들 수 있습니다.

두 숫자를 이어 붙여 가장 큰 수를 만드는 유형처럼 비교가 a+b와 b+a에 달리면 일반 숫자 정렬이 아닙니다. comparator의 반사성·추이성을 작은 반례로 확인합니다.

8. 누적·약수·행렬도 범위를 먼저 줄인다

  • 합과 나머지: 덧셈 때마다 modulo를 적용해 중간값을 제한할 수 있습니다.
  • 약수: d가 n의 약수이면 n/d도 약수이므로 d*d ≤ n까지만 검사합니다. 제곱수의 가운데 약수는 한 번만 셉니다.
  • 행렬 덧셈: 두 행렬의 row·column Shape이 같은지 먼저 확인하고 각 위치를 한 번 방문합니다.
  • Bit 연산: signed integer, shift 범위, leading zero 표현을 입력 계약과 함께 봅니다.

10. 결론

문자열·배열 문제는 입력 계약 → 정규화 → 사용할 자료구조 → scan 방향 → 경계값 → 복잡도 순서로 풀면 개별 답안이 공통 패턴으로 정리됩니다. 기존 문제 기록은 해답 모음이 아니라 이 판단을 다시 연습할 예제로 사용합니다.
