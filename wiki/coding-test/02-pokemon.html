폰켓몬

문제를 풀면서 실제로 사용한 개념, 풀이의 순서와 헷갈렸던 지점을 다시 풀기 좋은 형태로 보존한다.

풀이 완료set중복제거min
프로그래머스 문제 열기 ↗
이 문제 복습핵심 개념풀이 흐름핵심 코드헷갈렸던 지점다시 풀기 체크← 전체 문제

이 문제에서 연습한 핵심

  • set
  • 중복제거
  • min

풀이 흐름

  1. set으로 서로 다른 종류 수를 구한다.
  2. 뽑을 수 있는 수는 전체 마릿수의 절반이다.
  3. 두 제한 중 작은 값을 답으로 선택한다.

기억할 코드 형태

answer = min(len(set(nums)), len(nums) // 2)

헷갈렸던 지점

종류가 아무리 많아도 선택 가능한 마릿수보다 많이 고를 수 없고, 선택 수가 많아도 실제 종류 수를 넘을 수 없다.

다시 풀 때 확인할 것

종류 수와 선택 가능 수가 각각 더 작은 예를 하나씩 만들어 결과를 예측한다.
