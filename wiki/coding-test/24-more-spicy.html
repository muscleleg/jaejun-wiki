더 맵게

섞는 규칙은 일찍 찾았지만 Heap(힙)을 정렬된 리스트처럼 다뤄 실패했다. 최소 힙이 보장하는 범위와 마지막 원소 하나가 남았을 때의 성공·실패 조건을 중심으로 복습한다.

풀이 완료heappriority-queueheapqexception
프로그래머스 문제 열기 ↗
이 문제 복습처음 생각heap[1] 착각Heap 조작heapify 위치종료 조건수정한 흐름Heap 체크리스트← 전체 문제

처음 생각은 맞았다

  1. 가장 작은 음식 두 개를 꺼낸다.
  2. 첫 번째 + 두 번째 * 2로 섞는다.
  3. 섞은 값을 다시 넣는다.
  4. 최솟값이 K 이상이 될 때까지 반복한다.

문제는 알고리즘 방향보다 Python의 Heap을 다루는 방식에 있었다.

실수 1 · heap[1]을 두 번째 최솟값으로 봤다

heapq.heapify(scoville)

target = scoville[0] + scoville[1] * 2

최소 힙에서 인덱스로 보장되는 것은 heap[0]이 최솟값이라는 사실뿐이다. 부모가 자식보다 작거나 같다는 Heap 조건은 전체 정렬을 뜻하지 않으므로 heap[1]이 두 번째 최솟값인지는 보장되지 않는다.

first = heapq.heappop(scoville)
second = heapq.heappop(scoville)
기억할 것
heap[0] → 최솟값 보장
heap[1] → 두 번째 최솟값 보장 안 됨

실수 2 · Heap을 리스트처럼 잘라 수정했다

# 잘못 접근한 형태
scoville = scoville[1:]
scoville[0] = target

슬라이싱하거나 특정 인덱스를 직접 덮어쓰면 Heap 조건이 유지된다고 보장할 수 없다. 최소값 제거와 새 값 삽입은 Heap 조건을 다시 맞춰주는 연산을 사용한다.

first = heapq.heappop(scoville)
second = heapq.heappop(scoville)
heapq.heappush(scoville, first + second * 2)

실수 3 · 반복할 때마다 heapify()하려 했다

heapq.heapify(scoville)는 처음 리스트를 Heap으로 바꿀 때 한 번만 필요하다. 이후 heappop()과 heappush()가 매번 Heap 조건을 유지한다.

heapq.heapify(scoville)

while ...:
    first = heapq.heappop(scoville)
    second = heapq.heappop(scoville)
    heapq.heappush(scoville, new_value)

실수 4 · 원소 하나가 남았을 때 바로 실패시켰다

len(scoville) > 1인 동안만 섞은 뒤 무조건 -1을 반환하면, 마지막 한 값이 이미 K 이상인 성공 사례도 실패로 처리한다.

성공마지막 값이 K 이상이면 이미 모든 음식이 조건을 만족한다.
실패마지막 값이 K보다 작은데 원소가 하나뿐이면 더 섞을 수 없다.

따라서 현재 최소값으로 성공 여부를 먼저 확인하고, 그다음 섞기에 필요한 원소 수를 확인한다.

if scoville[0] >= K:
    return count

if len(scoville) < 2:
    return -1

수정한 전체 흐름

import heapq

def solution(scoville, K):
    heapq.heapify(scoville)
    count = 0

    while scoville:
        if scoville[0] >= K:
            return count

        if len(scoville) < 2:
            return -1

        first = heapq.heappop(scoville)
        second = heapq.heappop(scoville)
        heapq.heappush(scoville, first + second * 2)
        count += 1

    return -1

heapify()는 O(n), 각 삽입·삭제는 O(log n)이다. 반복 중 전체를 다시 정렬하지 않고 필요한 최솟값만 효율적으로 꺼낸다.

  5. 새로운 값은 heappush()로 넣는가?

알고리즘 방향은 맞았고, 실패 원인은 자료구조가 보장하는 성질·마지막 종료 조건·원소 부족 예외를 정확히 구분하지 못한 데 있었다.
