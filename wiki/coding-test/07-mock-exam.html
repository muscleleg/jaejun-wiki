문제를 풀면서 실제로 사용한 개념, 풀이의 순서와 헷갈렸던 지점을 다시 풀기 좋은 형태로 보존한다.

이 문제에서 연습한 핵심

  • pattern
  • modulo
  • score

풀이 흐름

  1. 각 수포자의 반복 패턴을 리스트로 둔다.
  2. 문제 번호를 패턴 길이로 나눈 나머지로 답을 꺼낸다.
  3. 정답과 같으면 점수를 올리고 최고점 동점자를 모두 반환한다.

기억할 코드 형태

guess = pattern[index % len(pattern)]

헷갈렸던 지점

입력 문제 수가 패턴보다 길어도 %를 쓰면 패턴이 처음부터 반복된다. 최고점이 같을 때 한 명만 반환하면 안 된다.

다시 풀 때 확인할 것

패턴 길이가 5일 때 index 7이 패턴의 몇 번째 값을 가리키는지 계산한다.
