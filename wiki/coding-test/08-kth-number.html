K번째수

문제를 풀면서 실제로 사용한 개념, 풀이의 순서와 헷갈렸던 지점을 다시 풀기 좋은 형태로 보존한다.

풀이 완료slicingsortindex
프로그래머스 문제 열기 ↗
이 문제 복습핵심 개념풀이 흐름핵심 코드헷갈렸던 지점다시 풀기 체크← 전체 문제

이 문제에서 연습한 핵심

  • slicing
  • sort
  • index

풀이 흐름

  1. 명령의 i번째부터 j번째까지 자른다.
  2. 잘라낸 배열을 정렬한다.
  3. 정렬 결과의 k번째 값을 선택한다.

기억할 코드 형태

part = sorted(array[i - 1:j])
answer = part[k - 1]

헷갈렸던 지점

문제의 위치 번호는 1부터 시작하지만 Python 인덱스는 0부터 시작한다. 슬라이스의 끝 j는 포함되지 않기 때문에 그대로 쓴다.

다시 풀 때 확인할 것

i=2, j=5라면 왜 array[1:5]인지 설명한다.
