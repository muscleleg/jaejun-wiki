카펫

문제를 풀면서 실제로 사용한 개념, 풀이의 순서와 헷갈렸던 지점을 다시 풀기 좋은 형태로 보존한다.

풀이 흐름

  1. 전체 격자 수 brown + yellow를 계산한다.
  2. 전체 수의 약수인 가로 후보만 검사한다.
  3. 가로×세로와 내부 노란 영역 조건을 모두 만족하는 후보를 찾는다.

기억할 코드 형태

total = brown + yellow
if total % width == 0:
    height = total // width
    if width >= height and (width - 2) * (height - 2) == yellow:
        return [width, height]

헷갈렸던 지점

수학식을 세운 뒤에도 가능한 후보를 코드로 하나씩 넣어 검사할 수 있다. 약수가 아닌 가로는 정수 세로를 만들지 못하므로 제외한다.

다시 풀 때 확인할 것

(w-2)(h-2)가 노란 격자 수가 되는 이유를 그림 없이 설명한다.
