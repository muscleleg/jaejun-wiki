체육복

문제를 풀면서 실제로 사용한 개념, 풀이의 순서와 헷갈렸던 지점을 다시 풀기 좋은 형태로 보존한다.

풀이 완료set차집합greedy
프로그래머스 문제 열기 ↗
이 문제 복습핵심 개념풀이 흐름핵심 코드헷갈렸던 지점다시 풀기 체크← 전체 문제

이 문제에서 연습한 핵심

  • set
  • 차집합
  • greedy

풀이 흐름

  1. 도난당했지만 여벌도 가진 학생은 두 집합에서 먼저 제외한다.
  2. 남은 학생을 순서대로 보며 앞번호나 뒷번호에게 빌린다.
  3. 한 벌은 한 번만 빌려줄 수 있으므로 사용한 여벌을 제거한다.

기억할 코드 형태

lost_set = set(lost) - set(reserve)
reserve_set = set(reserve) - set(lost)

헷갈렸던 지점

순회 중 집합을 갱신하므로 이미 빌려준 학생을 다시 사용할 수 없다. remove는 값이 없으면 오류가 나고 discard는 조용히 넘어간다.

다시 풀 때 확인할 것

도난과 여벌 목록에 동시에 들어간 학생을 먼저 제거해야 하는 이유를 설명한다.
