타겟 넘버

문제를 풀면서 실제로 사용한 개념, 풀이의 순서와 헷갈렸던 지점을 다시 풀기 좋은 형태로 보존한다.

풀이 완료DFSrecursionbinary-tree
프로그래머스 문제 열기 ↗
이 문제 복습핵심 개념풀이 흐름핵심 코드헷갈렸던 지점다시 풀기 체크← 전체 문제

이 문제에서 연습한 핵심

  • DFS
  • recursion
  • binary-tree

풀이 흐름

  1. 각 숫자마다 + 또는 -를 선택하는 두 갈래로 재귀 호출한다.
  2. 모든 숫자를 사용한 리프에서 target과 같으면 1, 아니면 0을 반환한다.
  3. 두 자식이 반환한 정답 개수를 부모에서 더한다.

기억할 코드 형태

def dfs(i, total):
    if i == len(numbers):
        return 1 if total == target else 0

    return (
        dfs(i + 1, total - numbers[i])
        + dfs(i + 1, total + numbers[i])
    )

헷갈렸던 지점

재귀는 정답 하나를 즉시 만드는 것이 아니라 선택 트리의 모든 리프를 검사한다. 바깥 함수의 지역변수를 안쪽 함수에서 수정한다면 global이 아니라 nonlocal을 사용한다.

다시 풀 때 확인할 것

숫자 하나가 추가될 때 리프 개수가 왜 두 배가 되는지 설명한다.
