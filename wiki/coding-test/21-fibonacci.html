이 문제에서 연습한 핵심

  • dynamic-programming
  • iteration
  • assignment

풀이 흐름

  1. 재귀로 같은 값을 반복 계산하지 않는다.
  2. 이전 두 피보나치 값을 a와 b에 저장한다.
  3. 반복마다 두 값을 동시에 다음 상태로 이동한다.

기억할 코드 형태

a, b = 0, 1
for _ in range(n):
    a, b = b, a + b
return a

헷갈렸던 지점

Python 동시 대입은 오른쪽 값을 먼저 계산한 뒤 왼쪽에 넣는다. 반복이 끝났을 때 a가 F(n)이 되도록 초기값과 반복 횟수를 맞춰야 한다.

다시 풀 때 확인할 것

n=0, 1, 2를 직접 따라가며 반환되는 a를 확인한다.
