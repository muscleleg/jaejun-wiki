기능개발

문제를 풀면서 실제로 사용한 개념, 풀이의 순서와 헷갈렸던 지점을 다시 풀기 좋은 형태로 보존한다.

풀이 완료queuedequesimulation
프로그래머스 문제 열기 ↗
이 문제 복습핵심 개념풀이 흐름핵심 코드헷갈렸던 지점다시 풀기 체크← 전체 문제

이 문제에서 연습한 핵심

  • queue
  • deque
  • simulation

풀이 흐름

  1. 각 작업의 진도를 날짜마다 증가시킨다.
  2. 맨 앞 작업이 완료됐을 때만 배포 판단을 시작한다.
  3. 앞에서부터 연속으로 완료된 작업을 한 번에 제거해 배포 수를 기록한다.

기억할 코드 형태

from collections import deque

progresses = deque(progresses)
first = progresses.popleft()

헷갈렸던 지점

뒤 작업이 먼저 100이 되어도 앞 작업이 끝나기 전에는 배포할 수 없다. 진도 증가와 배포 판단을 분리해야 하며, 리스트 pop(0)보다 deque.popleft()가 큐에 맞다.

다시 풀 때 확인할 것

[93, 30, 55], [1, 30, 5]가 왜 [2, 1]로 묶이는지 설명한다.
