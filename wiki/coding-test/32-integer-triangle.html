정수 삼각형

첫 행의 누적값에서 시작해 각 위치에 도착할 수 있는 이전 위치의 최고 누적값을 더하고, 마지막 행의 최댓값을 반환한다. 상태 전이를 직접 설명·구현해 정확성·효율성 20개 테스트를 모두 통과하고 시간 O(N²)·추가 공간 O(N)을 설명했다.

이전 행의 각 위치까지 최고 누적합만 보관한다

첫 행은 그 위치까지 오는 경로가 하나뿐이므로 초기 누적값으로 사용한다. ac_value[i]는 이전 행의 i번 위치까지 내려왔을 때 얻을 수 있는 최고 누적합이다. 현재 행의 모든 값을 new_value에 계산한 뒤 이전 상태를 교체하고, 마지막 행에서는 max(ac_value)를 반환한다.

왼쪽 끝·가운데·오른쪽 끝의 이전 후보가 다르다

현재 행의 위치에 따라 도착할 수 있는 부모의 수가 달라진다.

  • 왼쪽 끝 i == 0: 이전 행의 0번만 가능하다.
  • 가운데: 이전 행의 i-1번과 i번 중 큰 누적값을 고른다.
  • 오른쪽 끝 i == len(row)-1: 이전 행의 i-1번만 가능하다.
왼쪽 끝  = row[i] + ac_value[0]
가운데   = row[i] + max(ac_value[i - 1], ac_value[i])
오른쪽 끝 = row[i] + ac_value[i - 1]

직접 구현해 통과한 코드

def solution(triangle):
    ac_value = triangle[0]

    for row_index in range(1, len(triangle)):
        row = triangle[row_index]
        new_value = []

        for i in range(len(row)):
            if i == 0:
                new_value.append(row[i] + ac_value[0])
            elif i == len(row) - 1:
                new_value.append(row[i] + ac_value[i - 1])
            else:
                new_value.append(
                    row[i] + max(ac_value[i - 1], ac_value[i])
                )

        ac_value = new_value

    return max(ac_value)

입력이 한 행뿐이면 반복문을 실행하지 않고 첫 행의 최댓값을 바로 반환하므로 new_value를 별도로 참조하지 않는다.

경계 조건과 행 상태 교체를 교정했다

  • i == len(row)는 유효한 마지막 Index보다 1 크므로 반복 중 절대 참이 아니다. 오른쪽 끝은 i == len(row)-1이다.
  • 가운데 위치는 두 부모 중 큰 누적값에 현재 값을 더해야 한다.
  • 현재 행의 계산이 끝나면 ac_value = new_value로 다음 행의 이전 상태를 갱신해야 한다.
  • 마지막에는 현재 누적 상태의 최댓값인 max(ac_value)를 반환한다.
  • 한 행 입력에서도 정의되지 않은 new_value를 참조하지 않도록 반환 기준을 ac_value로 유지한다.

전체 칸 수만큼 계산해 시간 O(N²), 두 행을 보관해 공간 O(N)이다

각 칸의 경계 비교, 부모 최댓값, 덧셈과 Append는 모두 O(1)이다. 하지만 땅따먹기의 고정 4열과 달리 삼각형은 행마다 칸 수가 1, 2, ..., N으로 증가한다. 따라서 실행하는 칸의 총수는 다음과 같다.

1 + 2 + ... + N
= N(N + 1) / 2
→ O(N²)

바깥 반복 최대 N번과 안쪽 반복 최대 N번이라는 상한으로 보아도 O(N²)이며, 사용자는 “이건 고정 아니니까”라고 땅따먹기와의 차이를 설명했다.

ac_value와 new_value는 마지막 행 부근에서 각각 최대 N개의 누적값을 가진다. 계산 중 두 배열을 함께 보유해 약 2N개가 되어도 Big-O에서는 상수를 제거하므로 입력 삼각형을 제외한 추가 공간은 O(N)이다.

제출 증거

  • 정확성 테스트 10개 전체 통과
  • 효율성 테스트 10개 전체 통과
  • 총 20개 테스트 전체 통과

문제를 읽은 뒤 첫 행, 양쪽 경계, 가운데, 마지막 최댓값의 전이를 자기 말로 설명했고 코드를 직접 구현했다.

첫 학습 완료와 남은 재구현

상태 전이, 제출, 시간·공간 복잡도 설명까지 확인해 정수 삼각형 첫 학습은 완료했다. 다만 이전 코드를 보지 않은 재구현은 아직 확인하지 않았고, 등굣길로 DP 상태를 확장해야 하므로 통합 관문은 진행 중으로 유지한다.

  • 이전 코드를 보지 않고 양쪽 경계와 가운데 전이를 다시 구현한다.
  • 한 행 입력에서도 max(ac_value)가 동작하는지 확인한다.
  • 고정 4열의 O(N)과 증가하는 삼각형 열의 O(N²) 차이를 다시 설명한다.
