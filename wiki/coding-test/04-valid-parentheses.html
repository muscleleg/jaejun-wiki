올바른 괄호

문제를 풀면서 실제로 사용한 개념, 풀이의 순서와 헷갈렸던 지점을 다시 풀기 좋은 형태로 보존한다.

재풀이 완료counter조기종료stack
프로그래머스 문제 열기 ↗
이 문제 복습핵심 개념풀이 흐름핵심 코드헷갈렸던 지점다시 풀기 체크← 전체 문제

이 문제에서 연습한 핵심

  • counter
  • 조기종료
  • stack

풀이 흐름

  1. 여는 괄호는 count에 1을 더한다.
  2. 닫는 괄호는 count에서 1을 뺀다.
  3. 중간에 음수가 되면 대응할 여는 괄호가 없으므로 즉시 실패한다.
  4. 끝에서 count가 0인지 확인한다.

기억할 코드 형태

if ch == '(':
    count += 1
else:
    count -= 1

if count < 0:
    return False

return count == 0

헷갈렸던 지점

마지막 합이 0인지만 보면 ')('도 통과한다. 따라서 순회 중 음수 검사와 마지막 0 검사가 둘 다 필요하다.

다시 풀 때 확인할 것

')('과 '(()'가 각각 어느 조건에서 실패하는지 말한다.
