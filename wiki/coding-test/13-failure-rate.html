실패율

문제를 풀면서 실제로 사용한 개념, 풀이의 순서와 헷갈렸던 지점을 다시 풀기 좋은 형태로 보존한다.

풀이 완료dictsortlambdaexception
프로그래머스 문제 열기 ↗
이 문제 복습핵심 개념풀이 흐름핵심 코드헷갈렸던 지점다시 풀기 체크← 전체 문제

이 문제에서 연습한 핵심

  • dict
  • sort
  • lambda
  • exception

풀이 흐름

  1. 각 스테이지에 머무는 사용자 수를 센다.
  2. 현재 스테이지 도달 인원으로 나누어 실패율을 계산한다.
  3. 실패율 내림차순, 스테이지 번호 오름차순으로 정렬한다.

기억할 코드 형태

rate = 0 if people_count == 0 else failed / people_count
rates.sort(key=lambda x: (-x[1], x[0]))

헷갈렸던 지점

도달 인원이 0이면 나눗셈을 할 수 없다. 정렬 key에서 음수를 사용하면 실패율만 내림차순으로 만들 수 있다.

다시 풀 때 확인할 것

실패율이 같은 두 스테이지가 어떤 순서로 나오는지 설명한다.
