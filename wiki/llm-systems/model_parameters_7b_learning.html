7B 모델의 파라미터와 가중치 숫자표

7B가 입력 개수나 벡터 종류가 아니라, 모델 내부의 학습된 숫자를 모두 센 값이라는 점을 Q·K·V와 FFN 코드에 연결한다.

현재 이해도

문서가 존재하는 것과 이해를 검증한 것은 구분한다. 아직 대화에서 자기 말 설명이나 작은 예제 재구현을 확인하지 않았으므로 완료 항목을 표시하지 않는다.

검증 완료 0 / 20%
  • ○ 핵심 입력·처리·출력 흐름을 자기 말로 설명한다.
  • ○ 작은 숫자나 코드 예제로 결과를 예측하고 검증한다.

여기서 파라미터는 함수 인자가 아니다

머신러닝에서 파라미터는 모델이 학습하면서 조정하고, 모델 파일 안에 저장하는 숫자 하나를 뜻한다.

W_Q =
[0.1, 0.2]
[0.3, 0.4]

이 2 × 2 가중치 행렬에는 숫자가 4개 있다. 따라서 W_Q는 파라미터 4개를 가진다.

입력과 구분한다.
x는 이번 요청에서 들어온 입력 벡터다. W_Q는 모델 내부에 저장되어 입력을 Query로 바꾸는 학습된 가중치 행렬이다.

W_Q와 Q는 서로 다르다

Q = x @ W_Q
K = x @ W_K
V = x @ W_V
대상무엇인가?입력이 바뀌면?7B 파라미터에 포함되는가?
x현재 Token의 입력 벡터바뀐다아니다
W_Q, W_K, W_V모델 내부의 학습된 가중치 행렬추론 중에는 그대로 사용한다포함된다
Q, K, V현재 입력과 가중치 행렬을 곱한 중간 결과바뀐다아니다

따라서 7B를 셀 때는 현재 입력에서 만들어진 Q, K, V를 세지 않는다. 모델에 저장된 W_Q, W_K, W_V의 모든 칸을 센다.

FFN에도 가중치 행렬이 있다

FFN(x) = activation(x @ W₁ + b₁) @ W₂ + b₂

W₁과 W₂는 FFN 내부의 큰 가중치 행렬이다. b₁과 b₂를 사용하는 구조라면 그 안의 숫자도 파라미터다.

즉 Attention뿐 아니라 FFN, Embedding, 정규화 등에도 모델 내부에 저장되는 학습된 숫자가 있다.

70억 개는 무엇을 합친 것인가

Embedding의 학습된 숫자
+ 모든 Layer의 W_Q, W_K, W_V 숫자
+ Attention 출력 변환 가중치 숫자
+ FFN의 가중치 숫자
+ 정규화 등 나머지 학습된 숫자
= 약 70억 개

이 총합이 약 70억 개인 모델을 7B 모델이라고 부른다.

7B가 뜻하지 않는 것
입력이 70억 개라는 뜻도 아니고, Hidden State가 70억 차원이라는 뜻도 아니며, 만들 수 있는 벡터 종류가 70억 개라는 뜻도 아니다.

예를 들어 Hidden State가 계속 4096차원이어도, 그것을 여러 Layer에서 변환하기 위해 저장한 모든 가중치 행렬의 칸을 합치면 수십억 개가 될 수 있다.

왜 FP32 7B가 약 28GB인가

약 70억 개 × 원소 하나당 4 bytes ≈ 28GB

FP32 파라미터 숫자 하나가 4 bytes이므로, 모델 가중치만 단순 계산해도 약 28GB가 필요하다. 이 계산에는 입력 Tensor, Attention 중간 결과, KV Cache 등 실행 중 추가로 필요한 메모리는 포함하지 않았다.
