Qwen BlockLinear들LoRA프로젝트 연결

1. Qwen Decoder-only Block

hidden state
  → Q/K/V Linear
  → Multi-Head Attention
  → o_proj
  → residual + normalization
  → gate/up/down MLP
  → residual + normalization
  → 다음 Block

Decoder-only 언어 모델은 사용자가 직접 Transformer 코드를 고쳐야 하는 구조가 아니다. AutoModelForCausalLM 같은 공통 입구가 기존 config와 가중치를 읽고, 학습 wrapper가 그 모델에 adapter를 장착한다.

2. QKV·o_proj·MLP는 모두 Linear 계층이다

부분역할프로젝트에서의 의미
q_proj·k_proj·v_proj입력 표현을 Query·Key·Value로 투영어떤 정보에 주목할지 계산하는 입력을 만든다.
o_projHead별 결과를 이어 붙인 뒤 학습된 행렬로 다시 조합여러 관점을 다음 Block 표현으로 섞는다.
gate/up/down_projMLP 내부의 확장·게이트·축소 변환Attention 외의 표현 변환에도 adapter를 적용한다.

Transformer의 Multi-Head 계산은 Multi-Head Attention 문서와 연결한다. 7B가 무엇을 세는지는 파라미터와 가중치 문서에서 확인한다.

3. LoRA는 원본에 작은 보정을 더한다

원래: y = xW
LoRA: y = xW + x(BA) · α/r
학습: W는 고정, A와 B만 업데이트

W 전체를 바꾸는 대신 작은 rank r 행렬 A, B가 표현의 특정 방향을 보정한다. 그래서 base model의 언어·추론 능력을 재사용하면서 좁은 도구 출력 행동을 조정할 수 있다.

하이퍼파라미터를 읽는 법
r은 보정 행렬의 rank, alpha는 보정 크기, dropout은 과적합을 줄이기 위한 확률이다. 어떤 값을 선택했는지는 개별 프로젝트의 실험 기록에서 따로 비교해야 한다.

5. 적용 사례로 이동하기

이 문서는 특정 모델의 학습 설정이나 프로젝트 코드를 복사하지 않는다. 실제 LoRA 학습을 어떤 문제에 적용했는지는 프로젝트 학습 단계에서 확인한다.
