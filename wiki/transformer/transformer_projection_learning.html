Q·K·V Projection과
Linear 가중치

같은 입력을 서로 다른 가중치 표에 통과시켜 Query·Key·Value 관점의 중간 표현을 만드는 과정을 정리한다.

← Transformer 상위 문서전체 Projection 원문 ↗Attention 계산 →

같은 입력, 서로 다른 Projection

입력 x 하나를 세 개의 서로 다른 학습 가능한 가중치 표에 통과시킨다.

Q = x @ W_Q
K = x @ W_K
V = x @ W_V
Query현재 Token이 어떤 정보를 찾는지 나타내는 표현
Key각 Token이 어떤 정보인지 비교에 사용할 표현
Value관련도가 높을 때 실제로 가져올 표현

같은 x를 넣어도 W_Q, W_K, W_V가 다르므로 Q·K·V의 숫자는 서로 다르게 나온다.

nn.Linear가 만드는 새로운 특징

PyTorch의 Linear는 입력 특징들을 서로 다른 비율로 조합해 새로운 출력 특징을 만든다.

x = [x₁, x₂]

y₁ = x₁ × w₁₁ + x₂ × w₁₂
y₂ = x₁ × w₂₁ + x₂ × w₂₂
PyTorch Shapenn.Linear(in_features, out_features)weight.shape = [out_features, in_features]

가중치 행에 사람이 미리 “문법”, “위치” 같은 의미를 지정하는 것은 아니다. 학습을 통해 유용한 조합이 생기고, 나중에 그 표현을 사람이 해석할 수 있게 된다.

Projection 결과는 최종 예측값이 아니다

Q·K·V는 단어를 바로 예측하는 결과가 아니라 Attention 계산에 사용할 중간 표현이다.

x
→ Q, K, V Projection
→ Attention
→ multi_head_output
→ W_O Output Projection
→ 다음 Transformer 층
→ hidden state
→ vocabulary logits

따라서 Q·K·V의 숫자가 정답 Token과 직접 같아질 필요는 없다. 이 값들은 최종 예측을 잘 만들기 위한 내부 표현이다.

Q·K·V 가중치는 어떻게 학습되는가?

Q·K·V의 가중치를 각각 정답에 직접 맞추는 것이 아니다. 최종 예측 Loss가 전체 계산 그래프를 거꾸로 통과하면서 모든 가중치에 Gradient를 전달한다.

최종 logits
→ Loss
→ loss.backward()
→ W_Q, W_K, W_V의 Gradient 계산
→ Optimizer가 가중치 업데이트

따라서 Q·K·V Projection은 Transformer의 Attention 구조 안에서 최종 Loss를 줄이는 방향으로 함께 조정된다.

초기 상태 주의 — 실습에서 Linear 가중치가 랜덤으로 초기화되어 있으면 Q·K·V 출력도 임의의 숫자다. 아직 학습되지 않았으므로 그 숫자에 완성된 의미가 있다고 해석하면 안 된다.
