임베딩 행렬은 실제로 어떻게 초기화될까?

임베딩 가중치는 [vocab_size, d_model] 크기의 행렬입니다. 각 행은 토큰 하나의 임베딩 벡터이고, 행 안의 각 칸은 해당 벡터의 한 차원을 나타냅니다.

embedding.weight[vocab_size, d_model]
[
  [w₁₁, w₁₂, ..., w₁d],  # 토큰 1의 임베딩 벡터
  [w₂₁, w₂₂, ..., w₂d],  # 토큰 2의 임베딩 벡터
  ...
]

초기화 함수는 이 행렬의 각 원소에 확률분포에서 뽑은 랜덤 값 하나를 넣습니다. 모든 원소가 같은 확률 규칙을 사용하지만 실제로 뽑히는 값은 서로 다릅니다.

개념적 동작실제 코드는 행렬 전체를 한 번에 처리
for token in range(vocab_size):
    for dimension in range(d_model):
        embedding[token, dimension] = 기댓값이_0인_분포에서_하나_뽑기()
1번 차원분포에서 추출 → 0.21
2번 차원분포에서 추출 → -0.48
3번 차원분포에서 추출 → 0.07
4번 차원분포에서 추출 → -0.33
W = [0.21, -0.48, 0.07, -0.33] 각 차원에서 실제로 뽑힌 값을 모으면 토큰 하나의 임베딩 벡터가 됩니다.

기댓값이 0이라는 것은 실제 초기값이 0이라는 뜻이 아닙니다. 각 원소가 가질 수 있는 모든 랜덤 값에 값 × 확률을 적용해 더했을 때 0이 되는 분포를 사용한다는 뜻입니다. 실제로 한 번 뽑힌 값은 대부분 0이 아닌 작은 양수 또는 음수입니다.

분포의 기댓값

E[wᵢ] = 0
랜덤 추출 규칙의 이론적인 중심

≠
한 번 생성된 벡터의 합

w₁+w₂+...+w_d
정확히 0일 필요가 없는 실제 결과

초기화에서 하지 않는 일 — 벡터 좌표를 모두 더하지 않고, 차원 수로 나누지 않으며, 실제 평균이나 기댓값을 계산하지도 않습니다. 기댓값이 0인 분포를 지정한 뒤 각 원소를 그 분포에서 독립적으로 한 번씩 뽑습니다.

임베딩 벡터 초기화: 전체 흐름

1. 토큰 하나는 d_model개의 원소를 가진다

d_model=512라면 토큰 하나의 임베딩 벡터에는 랜덤한 숫자 512개가 들어갑니다.

W = [w₁, w₂, ..., w₅₁₂]

2. 각 원소는 평균 0인 분포에서 뽑는다

각 원소를 평균이 0인 같은 정규분포에서 독립적으로 하나씩 뽑습니다.

wᵢ ~ N(0, σ²) E[wᵢ]=0은 가능한 양수와 음수 값의 확률적 기여도가 상쇄된다는 뜻입니다. 실제로 뽑힌 값이 0이라는 뜻은 아닙니다.

3. 평균 0만으로는 값의 크기를 결정할 수 없다

-0.01/+0.01, -1/+1, -100/+100은 모두 기댓값이 0일 수 있지만 퍼지는 크기는 완전히 다릅니다.

평균 또는 기댓값

어디를 중심으로 랜덤 값을 뽑을 것인가

+
표준편차

그 중심에서 얼마나 퍼지게 뽑을 것인가

4. 원본 임베딩 벡터 전체의 제곱합을 약 1로 만들고 싶다

벡터 길이 제곱은 모든 원소 제곱의 합입니다. 우리가 원하는 것은 분산 자체가 1이 되는 것이 아니라, 512개 원소의 제곱합 기댓값이 1이 되는 것입니다.

||W||² = w₁²+w₂²+...+w₅₁₂² E[||W||²] = 1

여기서 분산과 연결합니다. 먼저 512개 원소의 제곱합 기댓값을 1로 정했기 때문에, 이제 512개 원소를 하나의 자료 집합처럼 놓고 분산 공식으로 연결할 수 있습니다. 초기화 분포의 평균이 0이라는 조건을 함께 사용하면 (원소-평균)²이 원소²로 단순해지고, 제곱합 예산 1에서 각 원소의 분산과 표준편차를 거꾸로 구할 수 있습니다.

5. 512개 원소를 자료 집합처럼 보고 분산 공식으로 연결한다

512개 원소를 하나의 자료 집합처럼 보면, 분산은 각 원소에서 평균을 뺀 뒤 제곱하고 모두 더한 다음 512로 나눈 값입니다.

분산 = ((w₁-평균)² + ... + (w₅₁₂-평균)²)
──────────────
512 초기화 분포의 평균을 0으로 보면, 각 원소에서 평균을 뺀 값은 원소 자체가 됩니다.

6. 제곱 크기 예산 1을 512개 원소가 나눠 가진다

평균이 0이면 분산은 원소 제곱의 평균과 같은 모양이 됩니다. 제곱합의 기댓값이 1이므로, 원소 하나의 제곱 기여도는 평균적으로 1/512가 됩니다.

분산 ≈ (w₁²+w₂²+...+w₅₁₂²)
──────────────
512 제곱합 ≈ 1이면 분산 ≈ 1/512

실제 벡터에서 제곱합이나 평균이 정확히 이 값이 된다는 뜻은 아닙니다. 같은 초기화 규칙으로 랜덤 추출을 반복했을 때 평균적으로 이 목표에 가까워진다는 뜻입니다.

E[wᵢ²] = 1/512 E[||W||²] = 512 × (1/512) = 1

7. 초기화 함수에는 분산이 아니라 표준편차를 넣는다

분산이 1/512라면 표준편차는 분산의 제곱근입니다. 따라서 코드에 전달할 표준편차는 1/√512입니다.

σ = √(1/512) = 1/√512 ≈ 0.044

8. PyTorch 코드로 표현한다

embedding_init.pymean과 std
nn.init.normal_(
    self.embedding.weight,
    mean=0.0,
    std=1 / math.sqrt(d_model),
)

1/√512는 실제 초기값이나 최대 범위가 아니라, 랜덤 값이 0 주변에서 퍼지는 정도인 표준편차입니다.

중심mean=0 → E[wᵢ]=0
전체 목표E[||W||²]=1
원소 기여E[wᵢ²]=1/d_model
분산Var(wᵢ)=1/d_model
표준편차std=1/√d_model
예산 1이 의미하는 것

예산 1은 w₁+w₂+...+w₅₁₂=1이라는 뜻이 아닙니다. 원소 제곱합으로 계산하는 벡터 길이 제곱의 기댓값, 즉 E[w₁²+w₂²+...+w₅₁₂²]=1이라는 뜻입니다.

mean=0

랜덤 값들이 특정 양수나 음수 방향으로 치우치지 않고 0을 중심으로 나오게 합니다.

+
std=1/√512

각 원소 제곱의 기대 기여도가 1/512이 되도록 랜덤 값의 퍼짐을 정합니다.

최종 정리 — 512차원 임베딩 벡터의 원소 제곱합이 평균적으로 1이 되도록 원소 하나의 분산을 1/512로 정합니다. 초기화 함수에는 분산의 제곱근인 표준편차를 전달해야 하므로 1/√512를 사용합니다. 평균은 0으로 설정해 랜덤 값들이 특정 방향으로 편향되지 않고 0을 중심으로 나오게 합니다.

전체 예산에 맞춰 표준편차를 정한다

벡터 길이 제곱의 목표 예산을 B라고 하면, 먼저 E[||W||²]=B로 둡니다. 원소가 d_model개이고 각 원소의 분산이 σ²이면 전체 예산은 다음과 같습니다.

dmodel × σ² = B σ² = B/d_model
σ = √(B/d_model)
제곱 크기 예산 B=1

std = √(1/d_model) = 1/√d_model

목표 벡터 길이 r

B=r²이므로 std=r/√d_model

예를 들어 벡터 길이를 약 2로 만들고 싶다면 제곱 크기 예산은 B=2²=4이고, 표준편차는 2/√d_model이 됩니다.

길이 목표원하는 벡터 길이 r 결정
제곱 예산B = r²
원소 분산σ² = B/d_model
표준편차σ = √(B/d_model) = r/√d_model
