Scaled Dot-Product Attention

각 Token의 Query가 모든 Key와 비교해 Score를 만들고, Scaling·Mask·Softmax를 거쳐 Value의 가중합을 만든다.

scores = query @ key.transpose(-2, -1)
scaled_scores = scores / math.sqrt(d_k)
masked_scores = scaled_scores.masked_fill(mask, float("-inf"))
attention_weights = F.softmax(masked_scores, dim=-1)
attention_output = attention_weights @ value

Score의 Shape은 [batch, query_token, key_token]이고, 출력은 Query마다 Value 정보를 섞은 [batch, query_token, d_v]다. Mask는 Q나 K를 없애는 연산이 아니라 Softmax 직전의 볼 수 없는 Score를 제외한다.

Q·K·V Projection

같은 입력 x를 서로 다른 nn.Linear에 통과시켜 Query·Key·Value를 만든다. Projection은 Token 수를 바꾸지 않고 마지막 특징 차원을 학습된 가중치로 변환한다.

query = query_projection(x)
key = key_projection(x)
value = value_projection(x)

세 Projection은 최종 Loss에서 전달된 Gradient로 함께 학습되지만 서로 다른 가중치를 가지므로, 같은 입력을 질문·비교 기준·전달할 내용이라는 다른 표현으로 바꾼다.

Multi-Head Attention

하나의 d_model을 여러 head_dim 조각으로 나누면 Head마다 같은 Attention 계산을 독립적으로 수행할 수 있다. Token 순서를 보존한 채 Head 축을 앞으로 옮겨 계산하고, 결과를 다시 Token 기준으로 이어 붙인다.

[batch, token, d_model]
→ view(batch, token, num_heads, head_dim)
→ transpose(1, 2)
→ [batch, num_heads, token, head_dim]
→ Head별 Attention
→ transpose + reshape
→ [batch, token, d_model]
→ output_projection

reshape()는 Head 결과를 이어 붙이고, Output Projection W_O는 그 특징을 학습된 방식으로 다시 섞는다.
