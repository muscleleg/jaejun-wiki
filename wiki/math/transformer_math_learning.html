Core flow

Transformer에서 다시 쓰는 수학의 한 줄 연결

평균·분산·표준편차는 값의 중심과 퍼진 정도를 설명하고, 그 크기를 조절하는 원리가 Embedding 초기화, Attention Scaling, LayerNorm에 반복해서 등장합니다. sin·cos는 같은 위치를 여러 속도의 파동으로 표현해 순서 정보를 만듭니다.

1. 평균에서 표준편차까지

평균 μ = (x₁ + x₂ + ... + xₙ) / n

분산 = ((x₁-μ)² + (x₂-μ)² + ... + (xₙ-μ)²) / n

표준편차 = √분산

분산은 평균에서 떨어진 거리를 제곱해 평균낸 값이고, 표준편차는 그 분산에 제곱근을 씌워 원래 값과 같은 단위로 되돌린 값입니다. LayerNorm은 Token 하나의 마지막 특징 축에서 이 평균과 표준편차를 구해 중심과 규모를 조절합니다. 자세한 계산은 통계 기초 문서에서 이어집니다.

2. 왜 Attention Score를 √d_k로 나누는가

각 항이 서로 독립이고 평균 0, 분산 1이라는 단순화된 가정에서 두 항의 합 Score=A+B를 먼저 봅니다. A,B∈{-1,1}이면 가능한 Score는 2,0,0,-2이고 평균은 0입니다.

분산 = (2² + 0² + 0² + (-2)²) / 4 = 2
표준편차 = √2

같은 조건의 독립적인 항을 d_k개 더하면 합의 분산은 약 d_k, 표준편차는 약 √d_k가 됩니다. 따라서 Dot Product Score를 √d_k로 나누면 표준편차 규모가 다시 약 1이 되어 Softmax 입력이 차원 수만큼 과도하게 커지는 일을 줄입니다. 이 설명은 독립성·평균 0·분산 1이라는 가정 아래의 직관이며, 실제 학습값이 항상 정확히 그 분포라는 뜻은 아닙니다.

3. 벡터 전체 제곱합 예산과 원소 분산을 구분한다

E[||w||²] = E[w₁² + ... + w_d²]
          ≈ d × 원소당 분산

벡터의 기대 제곱합을 약 1로 두려면:
원소당 분산 ≈ 1 / d
원소당 표준편차 ≈ 1 / √d

“벡터 전체 제곱합의 기댓값이 1”은 “벡터 원소 집단의 분산이 1”과 같은 말이 아닙니다. 평균이 0에 가까울 때 제곱합 1을 원소 수 d로 나누면 원소당 분산은 약 1/d가 됩니다. 이 구분이 Embedding이나 Linear 초기화의 크기 감각으로 이어집니다. 벡터 길이와 차원은 벡터·차원 문서에서 자세히 봅니다.

4. 위치와 정규화에 다시 연결한다

sin·cos Positional Encoding은 짝수·홀수 차원에 sin과 cos를 나누어 적용하고, 차원마다 다른 주파수를 사용해 같은 위치에 고유한 파동 조합을 만듭니다. 학습형 Position Embedding은 정해진 sin·cos 대신 위치별 벡터를 파라미터로 학습하는 대안입니다. 삼각함수의 파동 감각은 삼각함수 문서에서 이어집니다.

LayerNorm은 값을 0~1 사이로 자르는 정규화가 아닙니다. Token마다 마지막 특징 축의 평균을 빼고 표준편차로 나눈 뒤, 학습 가능한 γ와 β로 다시 조정합니다. 따라서 정규화 직후 값은 평균 0·표준편차 1에 가깝지만, affine 변환 뒤의 최종 통계는 달라질 수 있습니다.

핵심 결론 — 원소당 표준편차 1/√d는 벡터 초기화의 전체 크기를, Attention의 1/√d_k는 내적 합의 크기를, LayerNorm은 각 Token 특징의 중심과 규모를 조절합니다. 같은 제곱근이 보여도 무엇을 나누는지와 가정은 서로 다릅니다.
