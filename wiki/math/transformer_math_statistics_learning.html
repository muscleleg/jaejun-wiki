Concept 01

평균은 값들이 모이는 중심이다

평균은 여러 값을 모두 더한 뒤 개수로 나눈 값입니다. 랜덤 초기화에서는 숫자를 매우 많이 뽑았을 때 어느 지점을 중심으로 모이는지를 나타냅니다.

평균 = (x₁ + x₂ + ... + xₙ) / n
평균이 0이라는 뜻

모든 값이 0이라는 뜻이 아닙니다. 양수와 음수가 0을 중심으로 나오며, 많이 뽑아 평균을 내면 0에 가까워진다는 뜻입니다.

평균 0 주변

-0.8, 0.2, 1.1, -0.4

· • · • · ● · • ·
평균 1 주변

0.91, 1.03, 1.12, 0.87

· · · • ● • · · ·
Concept 02

분산은 평균에서 퍼진 정도다

두 데이터의 평균이 같아도 하나는 평균 근처에 모이고 다른 하나는 멀리 퍼질 수 있습니다. 분산은 이 퍼짐을 숫자로 표현합니다.

분산 = ((x₁ - 평균)² + ... + (xₙ - 평균)²) / n

평균을 구한다. 예: [1, 2, 3]의 평균은 2

각 값에서 평균을 뺀다. 결과는 [-1, 0, 1]

거리의 부호를 없애기 위해 제곱한다. 결과는 [1, 0, 1]

제곱한 거리의 평균을 구한다. 분산은 2/3 ≈ 0.667

평균이 0이면

(xᵢ - 0)² = xᵢ²이므로 분산은 단순히 각 값을 제곱한 것의 평균이 됩니다.

Concept 03

표준편차는 분산을 원래 단위로 되돌린 값이다

특정 값 하나가 평균에서 떨어진 정도는 편차이고, 모든 값의 편차를 이용해 데이터 전체가 얼마나 퍼져 있는지 나타낸 것이 표준편차입니다.

먼저 용어 구분하기

xᵢ-평균은 특정 값 하나의 편차, 편차 제곱의 평균은 분산, 분산에 제곱근을 씌운 값은 표준편차입니다.

[1, 2, 3]으로 표준편차 계산하기

평균을 구한다.
(1+2+3)/3 = 2

각 값에서 평균을 뺀다.
1-2=-1, 2-2=0, 3-2=1
편차는 [-1, 0, 1]입니다.

편차를 각각 제곱한다.
(-1)²=1, 0²=0, 1²=1
편차 제곱은 [1, 0, 1]입니다.

편차 제곱의 평균을 구한다.
(1+0+1)/3 = 2/3 ≈ 0.667
이 값이 분산입니다.

분산에 제곱근을 씌운다.
√0.667 ≈ 0.816
이 값이 표준편차입니다.

표준편차 = √(((x₁-평균)² + (x₂-평균)² + ... + (xₙ-평균)²) / n)

왜 편차를 제곱할까?

편차를 그대로 더하면 평균보다 작은 값의 음수 편차와 큰 값의 양수 편차가 상쇄됩니다.

편차 = [-1, 0, 1] 합 = -1+0+1 = 0

퍼져 있는데도 결과가 0이 되므로 각 편차를 제곱해 모두 양수로 만듭니다.

편차 제곱 = [1, 0, 1]

왜 다시 제곱근을 씌울까?

분산은 편차를 제곱했기 때문에 단위도 제곱됩니다. 제곱근을 씌워 원래 데이터와 같은 단위로 돌아오면 퍼진 정도를 직관적으로 읽을 수 있습니다.

데이터와 편차의 단위 = cm 분산의 단위 = cm² 표준편차의 단위 = cm
표준편차 = √분산 분산 = 표준편차²
분산표준편차해석
11평균에서 비교적 넓게 퍼짐
0.010.1평균 근처에 모임
0.00010.01평균에 매우 가깝게 모임

통계 계산과 랜덤 초기화는 방향이 반대다

데이터의 표준편차 계산

이미 존재하는 데이터에서 평균과 편차를 계산해 표준편차가 얼마인지 알아냅니다.

가중치 랜덤 초기화

원하는 평균과 표준편차를 먼저 지정하고, 그 조건을 따르는 확률분포에서 랜덤 값을 생성합니다.

통계 계산: 이미 있는 데이터 → 표준편차 계산 랜덤 초기화: 원하는 표준편차 지정 → 해당 분포에서 데이터 생성
PyTorch의 std 설정

nn.init.normal_(weight, mean=..., std=...)는 실제 초기값을 먼저 만든 뒤 표준편차를 계산하는 함수가 아닙니다. std로 0 주변에서 얼마나 퍼진 랜덤 값을 생성할지 먼저 지정합니다.

Concept 04

N(0, 1)은 1 근처에서 뽑는다는 뜻이 아니다

수학에서 정규분포는 N(평균, 분산)으로 적습니다. 첫 숫자는 중심, 두 번째 숫자는 퍼진 정도입니다.

N(0, 1) │ └─ 분산 1 └──── 평균 0
수학 표기

N(0, 1/d_model)
두 번째 자리에 분산을 씁니다.

PyTorch 코드

mean=0.0
std=1/√d_model
API에는 표준편차를 전달합니다.

Concept 05

E[...]는 기댓값을 계산하는 연산자다

E는 영어 Expectation의 첫 글자입니다. 숫자나 변수가 아니라, 대괄호 안의 랜덤한 표현식이 확률적으로 평균 얼마가 되는지 계산하라는 연산 기호입니다.

기댓값의 정의

랜덤 변수가 가질 수 있는 모든 값에 각각의 발생 확률을 곱한 기여분을 모두 더한 값입니다. 가능한 값이 연속적으로 무한히 많은 경우에도 같은 원리를 확률밀도 전체에 적용합니다.

E[X] = Σ(가능한 값 × 그 값이 나올 확률)
√9

√는 제곱근 연산자이고 계산 결과는 3입니다.

E[X]

E는 기댓값 연산자이고 계산 결과는 확률분포를 고려한 하나의 숫자입니다.

E[X] → X의 기댓값 E[X²] → X를 제곱한 값의 기댓값 E[||W||²] → 랜덤 벡터 W의 길이 제곱에 대한 기댓값

기댓값은 확률을 고려한 이론적인 평균이다

가능한 각 결과에 그 결과가 나올 확률을 곱한 뒤 모두 더합니다.

E[X] = Σ(결과 × 그 결과가 나올 확률)

가장 단순한 예제: 1 또는 2

랜덤 변수 X가 1 또는 2 중 하나이고, 두 값이 나올 확률이 각각 50%라고 가정해봅시다.

X=1일 확률: 50% X=2일 확률: 50% 결과 1의 기여분 = 1×0.5 = 0.5 결과 2의 기여분 = 2×0.5 = 1.0 E[X] = 0.5+1.0 = 1.5
각 결과의 기댓값이 아니라 기여분이다

“1의 기댓값이 0.5” 또는 “2의 기댓값이 1”이라고 표현하지 않습니다. 0.5와 1.0은 각각의 결과가 전체 기댓값에 더하는 확률 가중 기여분이고, 이들을 모두 더한 1.5가 랜덤 변수 X의 기댓값입니다.

이 랜덤 선택을 여러 번 반복하면 1, 2, 2, 1, 1, 2, ...처럼 결과가 나오고, 실제 결과의 평균은 반복 횟수가 많아질수록 1.5에 가까워집니다.

공정한 주사위는 모든 눈의 확률이 1/6로 같으므로 기댓값이 단순 산술평균과 같은 모양이 됩니다.

E[X] = 1×(1/6) + 2×(1/6) + ... + 6×(1/6) = (1+2+3+4+5+6)/6 = 3.5

기댓값 3.5가 실제 주사위 눈으로 나온다는 뜻은 아닙니다. 주사위를 매우 많이 던졌을 때 실제 결과의 평균이 이론적으로 3.5에 가까워진다는 뜻입니다.

실제 평균과 기댓값의 차이

실제 데이터 평균

이미 관찰한 값들을 더해 개수로 나눕니다. 예: [6,1,2,6]의 평균은 3.75입니다.

기댓값 E[X]

실험하기 전에 확률분포를 이용해 계산한 이론적인 평균입니다. 공정한 주사위에서는 3.5입니다.

결과별 확률이 다르면 기댓값은 단순 평균과 달라집니다.

X=10일 확률: 80% X=20일 확률: 20% E[X] = 10×0.8 + 20×0.2 = 12

임베딩 초기화에서 무엇이 랜덤한가?

가중치 벡터 W는 정규분포에서 랜덤하게 뽑히므로 초기화할 때마다 달라집니다. 따라서 W로 계산한 ||W||²도 매번 달라지는 랜덤한 값입니다.

첫 초기화: ||W₁||² = 0.8 두 번째: ||W₂||² = 1.2 세 번째: ||W₃||² = 1.0 E[||W||²] = 가능한 모든 초기화와 확률을 고려한 이론적 평균

E[wᵢ]=0과 E[||W||²]=1은 모순이 아니다

각 원소가 +0.5 또는 -0.5로 같은 확률로 초기화되는 4차원 벡터를 생각해봅시다.

E[wᵢ] = (+0.5)×0.5 + (-0.5)×0.5 = 0 (+0.5)² = 0.25 (-0.5)² = 0.25 E[||W||²] = 0.25+0.25+0.25+0.25 = 1
서로 다른 두 기댓값

E[wᵢ]=0은 각 원소가 양수와 음수로 0을 중심으로 분포한다는 뜻입니다. E[||W||²]=1은 원소들을 제곱해 더한 벡터 전체 크기가 평균적으로 1이라는 뜻입니다. 원래 값에서는 부호가 상쇄되지만 제곱하면 모두 양수가 되므로 두 조건이 동시에 가능합니다.

각 원소의 기댓값 E[wᵢ] = 0 벡터 길이 제곱의 기댓값 E[||W||²] = 1
Transformer 코드와 연결

mean=0.0은 각 원소의 기댓값을 0으로 정하고, std=1/√d_model은 각 원소가 0 주변에서 퍼지는 정도를 정합니다. 이 설정으로 원본 임베딩 벡터 길이 제곱의 기댓값을 1로 맞춥니다.

분포에서 뽑는 것과 실제 벡터를 평균내는 것은 다르다

임베딩의 각 차원은 기댓값이 0인 같은 분포에서 랜덤 값 하나를 독립적으로 뽑습니다. 기댓값은 분포가 가진 이론적 성질이며, 초기화할 때 실제 벡터 원소를 더하거나 평균내서 0으로 만드는 과정이 아닙니다.

각 차원의 추출 규칙: E[w₁] = 0 E[w₂] = 0 ... E[w_d] = 0 한 번 뽑힌 실제 벡터: W = [0.21, -0.48, 0.07, -0.33]
기댓값이 0인 분포

각 원소가 가질 수 있는 모든 값의 확률 가중 기여분을 더하면 0입니다. 양수와 음수의 기여가 이론적으로 상쇄됩니다.

실제 벡터의 원소 합

한 번 뽑힌 w₁+w₂+...+w_d는 정확히 0일 필요가 없습니다. 이를 0으로 강제하는 초기화가 아닙니다.

초기화에서 실제로 하는 일

임베딩 행렬의 각 칸마다 기댓값이 0인 확률분포에서 랜덤 값 하나를 뽑습니다. 실제 기댓값을 계산하거나, 좌표를 더하거나, 차원 수로 나누는 연산은 하지 않습니다.
