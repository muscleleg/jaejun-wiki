1. 먼저 데이터의 모양과 자료형을 본다

사용한 공개 회원 이탈 데이터는 7,043행, 21열이었다. 이 데이터에서 한 행은 고객 한 명을 뜻한다.

확인 항목실제 결과해석
df.shape(7043, 21)고객 7,043명과 열 21개
MonthlyChargesfloat64월 요금이 숫자로 읽힘
TotalChargesobject누적 요금인데 문자열이 섞였을 가능성
자료형이 문제를 알려 준다.
TotalCharges는 금액이므로 숫자형이 자연스럽다. 그런데 object였기 때문에 숫자로 변환되지 않는 값이 들어 있는지 확인할 이유가 생겼다.

2. isna()가 0이어도 빈 정보가 있을 수 있다

df.isna().sum() 결과는 모든 열에서 0이었다. 이 결과의 정확한 뜻은 “Pandas가 NaN, None, pd.NA 같은 결측값으로 인식한 칸이 0개”라는 것이다.

하지만 TotalCharges에는 공백 문자열이 있었다. 공백 문자열은 값이 없어 보이지만 문자열이므로 isna()는 False로 판단한다.

셀의 값isna()이유
NaN, None, pd.NATruePandas가 결측값으로 인식
" "False공백을 담은 문자열이라는 값이 존재
기억법
isna()는 “is NA? 이 값이 NA인가?”라고 기억한다.

공백 문자열 11개를 찾은 코드

df["TotalCharges"].str.strip().eq("").sum()
str.strip()문자열의 앞뒤 공백을 제거한다. " "는 ""가 된다.
eq("")공백 제거 결과가 빈 문자열과 같은지 비교해 True 또는 False를 만든다.
sum()True=1, False=0으로 합산해 True 개수를 센다.

실제 결과는 11이었다. 문자열을 합친 것이 아니라 빈 문자열인 칸을 뜻하는 True가 11개였다는 뜻이다.

3. 불리언 인덱싱으로 해당 행을 직접 본다

blank_total_charges = df["TotalCharges"].str.strip().eq("")

df.loc[
    blank_total_charges,
    ["tenure", "MonthlyCharges", "TotalCharges", "Churn"],
]

blank_total_charges에는 각 행마다 True 또는 False가 들어 있다. 이것을 df.loc[행 조건, 열 목록]의 행 조건에 넣으면 True인 행만 선택한다.

False인 행 → 제외   ·   True인 행 → 선택

출력을 확인한 결과, TotalCharges가 공백인 11개 행은 tenure가 모두 0이었다.

불리언 인덱싱
DataFrame의 열을 이용해 행마다 조건표를 만들고, 그 조건표를 loc의 행 필터로 사용할 수 있다.

4. 공백을 정식 결측값으로 바꾼 뒤 근거를 가지고 처리한다

df["TotalCharges"] = pd.to_numeric(
    df["TotalCharges"],
    errors="coerce",
)

pd.to_numeric()은 숫자 문자열을 실제 숫자로 바꾼다. errors="coerce"는 공백처럼 숫자로 바꿀 수 없는 값에서 오류를 멈추는 대신 NaN으로 바꾸라는 뜻이다.

검증결과
df["TotalCharges"].dtypefloat64
df["TotalCharges"].isna().sum()11

왜 0으로 채웠는가?

전체 데이터가 11개인 것이 아니다. 전체 7,043개 행 중 결측 행이 11개이며, 비율은 약 0.16%다.

11 ÷ 7,043 × 100 ≈ 0.16%

이 11명은 모두 tenure=0이었고 TotalCharges는 누적 요금이다. 따라서 아직 이용 기간이 쌓이지 않은 고객의 누적 요금을 0으로 해석해 대체했다.

df["TotalCharges"] = df["TotalCharges"].fillna(0)

df["TotalCharges"].isna().sum()
# 0
기억법
fillna(0)는 “fill NA with 0, NA를 0으로 채워라”라고 기억한다.
중요한 제한
모든 결측값은 무조건 0으로 채운다는 규칙이 아니다. 이번에는 tenure=0과 누적 요금이라는 열의 의미가 함께 있었기 때문에 0 대체를 선택했다. 결측이 생긴 이유와 열의 의미가 다르면 삭제, 중앙값 대체 등 다른 판단이 필요하다.
