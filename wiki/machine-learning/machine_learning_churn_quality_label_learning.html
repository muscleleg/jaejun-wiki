6. 여기서 normalize=True는 평균이 아니라 비율이다

churn_ratio = (
    df["Churn"]
    .value_counts(normalize=True)
    .mul(100)
)
value_counts()각 값이 몇 개 있는지 센다.
normalize=True각 Count를 전체 Count로 나누어 합이 1인 비율로 만든다.
mul(100)소수 비율에 100을 곱해 퍼센트로 바꾼다.
No = 5,174 ÷ 7,043 ≈ 0.7346 → 73.46%
Yes = 1,869 ÷ 7,043 ≈ 0.2654 → 26.54%

normalize의 공통 느낌은 값을 일정한 기준에 맞추는 것이지만, 무엇을 기준으로 맞추는지는 기능마다 다르다.

기능무엇을 맞추는가?
value_counts(normalize=True)각 Count를 전체 Count로 나눈 비율이며 합이 1
Transformer LayerNorm각 Token 벡터의 평균과 분산을 정돈

따라서 이번 normalize=True는 mean()으로 평균을 구한 것이 아니다.
