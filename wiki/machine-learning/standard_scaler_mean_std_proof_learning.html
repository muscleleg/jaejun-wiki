StandardScaler: 평균 0·표준편차 1이 되는 전개

zᵢ = (xᵢ − μ) / σ를 만들었을 때 왜 새 열의 평균은 0, 표준편차는 1인지 평균과 표준편차의 정의부터 생략 없이 연결한다.

목표와 기호 원래 평균 원래 표준편차 새 평균 새 표준편차 전체 연결

0. 무엇을 증명하는가

원래 한 숫자형 열을 다음처럼 쓰자.

x₁, x₂, ···, xₙ

StandardScaler는 각 원소를 다음 규칙으로 바꾼다.

zᵢ = xᵢ − μσ

여기서 증명할 결과는 다음 두 개다.

새 열의 평균mean(z) = 0
새 열의 표준편차Std(z) = 1
기호를 먼저 분리한다.
∑는 여러 값을 모두 더하라는 합 기호다. σ는 원래 열 x의 표준편차다. 모양이 비슷해 보여도 완전히 다른 기호다.

가장 중요한 구분: σ와 σz는 다른 대상이다

이 증명의 목표는 σ = 1을 보이는 것이 아니다. σ는 시작할 때부터 원래 데이터 x의 표준편차라고 이름 붙인 값이다.

원래 데이터x₁, x₂, ···, xₙ
평균 μ, 표준편차 σ
변환된 데이터zᵢ = (xᵢ − μ) / σ
표준편차를 새 이름 σz로 둔다.
증명 목표: σz = 1
여기서 σ는 원래 x의 표준편차이고, σz는 변환 뒤 z의 표준편차다.

따라서 아래에서 σ² = (1 / n)Σ(xᵢ − μ)²를 사용하는 것은 “새 표준편차가 1임을 이미 증명했다”는 뜻이 아니다. 그것은 단지 원래 x가 얼마나 퍼져 있었는지, 즉 원래 분산이 σ²라는 정보를 꺼내 쓰는 것이다.

이 문서는 복습용 증명 초안이다.
이전 실습에서는 출력 평균과 표준편차를 확인했지만, 이 전개를 사용자가 직접 다시 설명하거나 계산해 검증한 것은 아직 아니다. 따라서 이해 완료로 표시하지 않는다.

1. 원래 데이터 x의 평균

원래 열의 평균을 μ라고 하면, 평균의 정의는 “전체 합을 원소 개수로 나눈 값”이다.

μ = x₁ + x₂ + ··· + xₙn

같은 식을 합 기호로 줄여 쓰면 다음과 같다.

μ = 1n ∑i=1n xᵢ

이후 새 평균의 분자를 정리하려면 원소의 합이 무엇인지 필요하다. 그래서 양변에 n을 곱한다.

nμ = n × x₁ + x₂ + ··· + xₙn
nμ = x₁ + x₂ + ··· + xₙ

즉, 아래 식을 얻는다.

x₁ + x₂ + ··· + xₙ = nμ

2. 원래 데이터 x의 표준편차

원래 열의 표준편차가 σ라면 정의는 다음과 같다. 이 문서에서는 StandardScaler와 동일하게 n으로 나누는 정의를 쓴다.

σ = √[ (x₁ − μ)² + (x₂ − μ)² + ··· + (xₙ − μ)²n ]

합 기호로 쓰면 다음과 같다.

σ = √[ 1n ∑i=1n (xᵢ − μ)² ]

양변을 제곱하면 오른쪽의 제곱근과 제곱이 서로 없어져 다음 식이 남는다.

σ² = 1n ∑i=1n (xᵢ − μ)²

왼쪽 σ²는 원래 열의 분산이다. 이 식은 뒤에서 대괄호 안의 긴 식을 σ²로 바꿀 때 사용한다.

여기까지의 연결
분산 = σ², 표준편차 = σ이며, 원래 데이터의 “평균에서 떨어진 정도의 제곱 평균”이 바로 σ²다.

3. 새 데이터 z의 평균을 직접 구한다

변환 뒤 각 값은 다음과 같다.

z₁ = (x₁ − μ) / σ
z₂ = (x₂ − μ) / σ
...
zₙ = (xₙ − μ) / σ

새 열의 평균을 z̄라고 하면 평균의 정의에 그대로 넣는다.

z̄ = z₁ + z₂ + ··· + zₙn

이제 각 zᵢ 자리에 실제 변환식을 넣는다.

z̄ = 1n [ x₁ − μσ + x₂ − μσ + ··· + xₙ − μσ ]

대괄호 안은 모두 같은 σ로 나누고 있다. 따라서 a / σ + b / σ = (a + b) / σ처럼 합칠 수 있다.

z̄ = (x₁ − μ) + (x₂ − μ) + ··· + (xₙ − μ)nσ

이제 분자만 괄호를 연다.

(x₁ − μ) + ··· + (xₙ − μ)
= x₁ + x₂ + ··· + xₙ − nμ

앞에서 평균의 정의로 얻은 x₁ + ··· + xₙ = nμ를 이 식에 넣는다.

z̄ = nμ − nμnσ
= 0nσ
= 0
새 평균 결론
mean(z) = 0. 각 값에서 같은 원래 평균 μ를 빼면, 모든 값의 합에서 원래 합 nμ가 정확히 빠지기 때문이다.

4. 새 데이터 z의 표준편차를 직접 구한다

새 데이터 z의 표준편차에는 원래 σ와 섞이지 않도록 σz라는 이름을 붙인다. 즉 σz = Std(z)다. 지금부터 계산하는 대상은 σz다.

어떤 열 a의 평균이 ā일 때 표준편차 공식은 다음이다.

Std(a) = √[ 1n ∑i=1n (aᵢ − ā)² ]

지금은 aᵢ 자리에 zᵢ, 평균 자리에 z̄를 넣는다.

Std(z) = √[ 1n ∑i=1n (zᵢ − z̄)² ]
σz = √[ 1n ∑i=1n (zᵢ − z̄)² ]

바로 위에서 z̄ = 0임을 계산했다. 따라서 zᵢ − 0 = zᵢ이므로 식은 다음처럼 바뀐다.

Std(z) = √[ 1n ∑i=1n zᵢ² ]

4-1. zᵢ 자리에 실제 StandardScaler 식을 넣는다

zᵢ = (xᵢ − μ) / σ였으므로, zᵢ²는 분수 전체를 제곱한 값이다.

zᵢ² = ( xᵢ − μσ )²
= (xᵢ − μ)²σ²

따라서 새 표준편차 식은 아래와 같다.

Std(z) = √[ 1n ∑i=1n (xᵢ − μ)²σ² ]

모든 항이 같은 σ²로 나누어져 있으므로 그것을 합 밖으로 꺼낼 수 있다.

Std(z) = √[ 1σ² × [ 1n ∑i=1n (xᵢ − μ)² ] ]

4-2. 대괄호 안을 왜 σ²로 바꿀 수 있는가

2절에서 원래 표준편차의 정의를 제곱해 다음 식을 얻었다.

σ² = 1n ∑i=1n (xᵢ − μ)²

새 표준편차 식의 대괄호 안은 오른쪽과 문자 하나까지 같은 식이다. 따라서 대괄호 안을 σ²로 치환한다.

σz = √[ 1σ² × σ² ]
= √[ σ²σ² ]
= √1
= 1
새 표준편차 결론
σz = 1. 원래 열이 퍼져 있던 정도 σ를 변환에서 한 번 나눴고, 표준편차 계산에서는 제곱이 들어가 σ² / σ² = 1로 상쇄된다. 증명한 것은 σ = 1이 아니라 σz = 1이다.

5. 처음부터 끝까지 한 줄로 연결

원래 평균μ = (x₁ + ··· + xₙ) / n
따라서 x₁ + ··· + xₙ = nμ
원래 표준편차σ = √[(1 / n)Σ(xᵢ − μ)²]
따라서 σ² = (1 / n)Σ(xᵢ − μ)²
변환zᵢ = (xᵢ − μ) / σ
mean(z) = x₁ + ··· + xₙ − nμnσ = nμ − nμnσ = 0
Std(z) = √[ 1σ² × [ 1nΣ(xᵢ − μ)² ] ] = √[ 1σ² × σ² ] = √1 = 1
성립 조건
원래 열의 표준편차가 σ > 0이어야 한다. 모든 값이 완전히 같으면 σ = 0이고 0으로 나눌 수 없으므로 이 식을 그대로 적용할 수 없다.
