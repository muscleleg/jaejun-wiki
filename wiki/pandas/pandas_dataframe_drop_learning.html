Pandas data preprocessing

DataFrame.drop()

행 또는 열을 삭제할 때 axis가 무엇을 가리키는지, 원본을 유지하는 방식과 직접 수정하는 방식이 어떻게 다른지 정리한다.

핵심 문장
axis=0이면 행, axis=1이면 열을 삭제한다. inplace=False는 새 DataFrame을 반환하고, inplace=True는 원본을 수정한다.
목차 1. drop()의 역할2. axis3. 열 삭제4. 행 삭제5. 여러 개 삭제6. inplace=False7. inplace=True8. 다시 대입하기9. 삭제 후 index10. 최종 압축

1. drop()은 무엇을 하는가

drop()은 DataFrame에서 행(row) 또는 열(column)을 삭제할 때 사용한다. 머신러닝 전처리에서는 필요 없는 컬럼을 제거하는 일이 많아 자주 사용한다.

df.drop(...)

2. axis는 어디에서 삭제할지 정한다

axis=0  # 행
axis=1  # 열

지금 단계에서는 0은 행, 1은 열이라고 기억하면 된다.

import pandas as pd

df = pd.DataFrame({
    'Name': ['철수', '영희', '민수'],
    'Age': [20, 25, 30],
    'Gender': ['M', 'F', 'M']
})

# 출력
  Name  Age Gender
0   철수   20      M
1   영희   25      F
2   민수   30      M

3. 열 삭제

df.drop('Age', axis=1)

Age라는 이름을 열(column) 쪽에서 찾아 삭제하라.

  Name Gender
0   철수      M
1   영희      F
2   민수      M

'Age'는 무엇을 삭제할지, axis=1은 열에서 찾으라는 뜻이다.

4. 행 삭제

df.drop(1, axis=0)

index가 1인 행을 삭제하라.

  Name  Age Gender
0   철수   20      M
2   민수   30      M

1은 삭제할 index, axis=0은 행 쪽에서 찾으라는 뜻이다.

5. 여러 개를 삭제할 때는 리스트를 전달한다

열 여러 개 삭제

df.drop(['Age', 'Gender'], axis=1)

  Name
0   철수
1   영희
2   민수

행 여러 개 삭제

df.drop([0, 2], axis=0)

  Name  Age Gender
1   영희   25      F

6. 기본값 inplace=False

원본 DataFrame을 바꾸지 않고 변경된 새 DataFrame을 반환한다.

new_df = df.drop('Age', axis=1)
원본 df
Name  Age  Gender
철수   20   M
영희   25   F
민수   30   M
새 new_df
Name  Gender
철수   M
영희   F
민수   M

강의에서 이를 강조한 이유는 원본을 바로 파괴하지 않는 습관을 들이기 위해서다. 잘못 삭제했더라도 원본이 남고, 단계별 전처리 결과를 확인하기도 편하다.

원본 데이터
   ↓
전처리된 데이터
   ↓
또 다른 전처리 결과

7. inplace=True는 원본을 직접 수정한다

df.drop('Age', axis=1, inplace=True)

실행 후에는 원래 Age가 있던 상태가 df에 남지 않는다. 그리고 가장 중요한 점은 반환값이 None이라는 것이다.

# 정상: 원본을 직접 수정
df.drop('Age', axis=1, inplace=True)

# 잘못된 사용
df = df.drop('Age', axis=1, inplace=True)

# 오른쪽 반환값이 None이므로 결과적으로
df = None

원본을 수정하려면 대입하지 말고 inplace=True로 호출한다.

8. df = df.drop(...)은 어떻게 동작하는가

df = df.drop('Age', axis=1)

이 코드는 inplace=False 방식이다.

기존 df
  ↓
drop() 실행
  ↓
Age가 제거된 새로운 DataFrame 생성
  ↓
그 새로운 DataFrame을 다시 df가 가리킴

최종적으로는 df가 바뀐 것처럼 보이지만, df.drop(..., inplace=True)와 내부 동작은 다르다.

9. 행을 삭제해도 index는 자동 재정렬되지 않는다

# 원래 index: 0, 1, 2, 3, 4
df.drop([0, 1, 2], axis=0)

# 결과
  Name
3 준호
4 수진

drop()은 행만 삭제할 뿐 index 번호를 다시 매겨주지 않는다. 따라서 결과가 자동으로 0, 1로 바뀌지 않는다.

10. 오늘 배운 내용 압축

df.drop('Age', axis=1)
# Age 열 삭제

df.drop(1, axis=0)
# index 1인 행 삭제

new_df = df.drop('Age', axis=1)
# 원본 유지, 새로운 결과 반환

df.drop('Age', axis=1, inplace=True)
# 원본 자체 수정
절대 헷갈리지 말 것
df = df.drop('Age', axis=1, inplace=True)라고 쓰면 df가 None이 된다.
