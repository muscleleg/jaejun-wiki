5. 평균변화율에서 순간변화율로

Gradient를 이해하려면 먼저 두 점 사이의 평균변화율과 한 점에서의 순간변화율을 구분해야 합니다.

두 점 사이의 평균변화율

다음과 같이 단순한 Loss 함수 하나를 생각합니다.

Loss(w) = (w − 3)²

w=1일 때 Loss는 4이고, w=2일 때 Loss는 1입니다.

대상처음나중변화량
w12+1
Loss41−3
평균변화율 = Loss 변화량w 변화량 = −31 = −3

−3은 이 구간에서 w가 증가할 때 Loss가 감소했다는 뜻입니다.

두 번째 점을 기준점에 점점 가깝게 가져온다

기준점 w=1은 그대로 두고, 비교할 두 번째 점을 점점 가까이 가져옵니다.

비교 구간평균변화율
1 → 2−3
1 → 1.1−3.9
1 → 1.01−3.99
1 → 1.001−3.999

두 점의 간격을 0에 한없이 가깝게 줄이면 변화율은 −4에 가까워집니다. 이것을 w=1이라는 한 점에서의 순간변화율 또는 미분값이라고 합니다.

w=1에서 dLossdw = −4

왼쪽에서 접근해도 같은가?

w=0.9999처럼 기준점의 왼쪽에서도 접근할 수 있습니다.

왼쪽에서 접근

w 변화량은 음수, Loss 변화량은 양수이므로 변화율은 음수이며 약 −4.0001이 됩니다.

오른쪽에서 접근

w 변화량은 양수, Loss 변화량은 음수이므로 변화율은 음수이며 약 −3.9999가 됩니다.

양쪽에서 같은 값 −4에 가까워지므로 이 점에서 미분할 수 있습니다. 접근하는 쪽은 달라도 변화량의 부호까지 함께 나누기 때문에 같은 순간변화율을 얻습니다.

PyTorch가 실제로 w를 조금씩 움직여 보는 것은 아닙니다. 작은 간격으로 접근하는 설명은 순간변화율의 의미를 이해하기 위한 것입니다. PyTorch의 자동미분은 저장된 계산식에 미분 규칙을 적용해 현재 순간변화율을 바로 계산합니다.

실제 실습 데이터에서 평균변화율과 w.grad 구분하기

실제 데이터 네 개를 사용하고 현재 값을 w=1, b=1로 놓으면 예측, 오차, Loss는 다음과 같습니다.

y_pred = [1, 2, 3, 4]
y      = [2, 5, 8, 11]
errors = [-1, -3, -5, -7]

loss = (1² + 3² + 5² + 7²) / 4
     = 21

b=1은 고정하고 w만 1 → 1.1로 움직이면 새로운 Loss는 19.335가 됩니다.

평균변화율 = 19.335 − 211.1 − 1 = −16.65

하지만 −16.65는 0.1이라는 구간에서 계산한 평균변화율이지, 정확한 w.grad는 아닙니다. 움직이는 크기를 바꾸면 평균변화율도 달라집니다.

w의 비교 구간w 변화량평균변화율
1 → 1.10.1−16.65
1 → 1.010.01−16.965
1 → 1.0010.001−16.9965

이동량을 0에 한없이 가깝게 줄이면 평균변화율은 −17에 가까워집니다. 이 극한값이 현재 w=1, b=1에서의 순간변화율입니다.

w.grad = ∂Loss∂w = lim(Δw→0) Loss(w+Δw,b) − Loss(w,b)Δw = −17
평균변화율

실제로 선택한 이동 구간에 따라 값이 달라집니다.

순간변화율 · w.grad

이동량을 0에 가깝게 보냈을 때 수렴하는 현재 한 점의 변화율입니다.

학습할 값이 여러 개라면 각각 구한다

실제 Loss는 w와 b 두 값에 의해 결정됩니다.

Loss(w, b)
w에 대한 순간변화율

b는 고정하고 w만 아주 조금 변한다고 보았을 때 Loss가 변하는 비율입니다. PyTorch는 이를 w.grad에 저장합니다.

b에 대한 순간변화율

w는 고정하고 b만 아주 조금 변한다고 보았을 때 Loss가 변하는 비율입니다. PyTorch는 이를 b.grad에 저장합니다.

Gradient = [w에 대한 순간변화율, b에 대한 순간변화율]

즉 Gradient는 특별한 별개의 숫자가 아니라, 학습할 값 각각의 순간변화율을 모아 놓은 것입니다.

6. backward()가 Gradient를 계산한다

loss.backward()

print(w.grad)
print(b.grad)

backward()는 어떤 외부 함수에 Loss를 다시 전달하는 호출이 아닙니다. 현재 loss Tensor 자신이 기억하고 있는 계산 그래프에서 출발해 앞의 계산을 거꾸로 따라가며, w와 b 각각에 대한 Loss의 순간변화율을 계산합니다.

loss평균 오차
squared_errors오차 제곱
errors예측−정답
y_predxw+b
w, b조절 대상
backward()는 w와 b를 움직이지 않습니다. 실행 전후의 w와 b는 그대로이고, 계산 결과인 w.grad와 b.grad만 채워집니다.
반환값이 아니라 .grad에 저장합니다. result = loss.backward()의 result는 None입니다. 계산된 변화율은 requires_grad=True로 표시한 학습 대상의 w.grad, b.grad에 각각 저장됩니다.

부호는 어느 방향으로 움직일지 알려준다

GradientLoss를 줄이는 방향
음수해당 값을 증가시킵니다.
양수해당 값을 감소시킵니다.
0현재 위치에서 기울기가 평평합니다.

예를 들어 w.grad=-31.4925라면, 현재 위치에서 w를 조금 증가시킬 때 Loss가 감소한다는 뜻입니다.

w와 w.grad는 다릅니다.
w는 예측 직선의 기울기이고, w.grad는 그 기울기 w를 바꿀 때 Loss가 변하는 방향과 정도입니다.

하나의 Weight에서 행렬 전체 학습까지

Weight 하나에서 Loss의 순간변화율을 구하는 기초부터 nn.Linear(4, 4)의 Weight와 Bias 전체가 한 학습 Step에서 조정되는 과정까지 하나의 흐름으로 연결합니다.

이 절에서 확인하는 범위

아래의 “출력마다 Weight 행이 직접 연결된다”는 설명은 하나의 Linear 계층과 고정된 입력을 기준으로 합니다. 더 깊은 신경망에서는 뒤 계층이 출력을 다시 섞거나 앞 계층의 값을 공유할 수 있으므로, 모델 전체의 파라미터가 서로 완전히 독립이라는 뜻은 아닙니다.

1. 가장 단순한 모델

먼저 Weight가 하나뿐인 모델을 생각합니다.

y = x × w
주어지는 값

x는 모델에 들어오는 입력이고, 정답은 모델이 맞혀야 하는 값입니다.

학습되는 값

w는 모델이 학습하며 조정하는 Weight이고, y는 현재 Weight로 계산한 예측값입니다.

x = 2
정답 = 10
w = 1

y = x × w
  = 2 × 1
  = 2

현재 모델은 2를 예측했지만 정답은 10입니다.

2. 예측과 정답의 차이를 Loss로 나타낸다

Loss = (예측값 − 정답)²
Loss = (2 - 10)²
     = 64

Loss가 작을수록 모델의 예측이 정답에 가깝다는 뜻입니다. 현재 Loss는 64이지만 항상 고정된 숫자는 아닙니다. 예측값 y가 Weight w로 계산되므로, w가 바뀌면 예측과 Loss도 함께 바뀝니다.

w = 1 → y = 2 → Loss = 64
w = 2 → y = 4 → Loss = 36
w = 3 → y = 6 → Loss = 16
Weight 변화w가 바뀝니다.
예측값 변화y=xw가 바뀝니다.
Loss 변화정답과의 차이가 바뀝니다.

현재 모델에서는 y=2w이므로 Loss를 Weight의 함수로 쓸 수 있습니다.

Loss(w) = (2w − 10)²

3. 조금 움직인 구간의 평균변화율

w=1일 때 Loss는 64입니다. Weight를 1에서 1.01로 아주 조금 증가시키면 다음과 같습니다.

Loss(1.01)
= (2×1.01 - 10)²
= (2.02 - 10)²
≈ 63.6804

Weight 변화량 = 1.01 - 1
              = +0.01

Loss 변화량   = 63.6804 - 64
              = -0.3196

Weight를 0.01만큼 증가시키자 Loss가 약 0.3196 감소했습니다. 이 두 점 사이의 평균변화율은 다음과 같습니다.

평균변화율 = Loss 변화량Weight 변화량 = −0.31960.01 ≈ −31.96

4. 평균변화율에서 순간변화율로

−31.96은 w=1과 w=1.01 사이에서 구한 평균변화율입니다. 이동량을 0.01 → 0.001 → 0.0001처럼 0에 한없이 가깝게 줄이면 평균변화율은 −32에 가까워집니다. 이 극한값이 w=1인 한 점에서의 정확한 순간변화율, 즉 Gradient입니다.

w.grad = dLossdw = −32

Gradient가 음수라는 것은 현재 위치에서 Weight를 증가시키면 Loss가 감소한다는 뜻입니다.

5. Gradient의 반대 방향으로 Weight를 조정한다

Gradient는 Loss가 증가하는 방향을 가리키므로 Loss를 줄이려면 그 반대 방향으로 이동합니다.

새 Weight = 기존 Weight − 학습률 × Gradient
학습률 = 0.01

새 w = 1 - 0.01×(-32)
     = 1.32

Gradient가 음수이므로 빼기와 만나 실제 Weight는 증가합니다. 한 학습 Step은 현재 위치의 Gradient를 계산하고, 학습률로 실제 이동 크기를 정해 파라미터를 갱신하는 과정입니다.

6. Linear(4, 4)의 Weight와 Bias

이제 같은 원리를 여러 Weight와 Bias를 가진 nn.Linear(4, 4)로 확장합니다. 이 계층에는 Shape이 [4, 4]인 Weight 행렬과 Shape이 [4]인 Bias 벡터가 있습니다.

Weight

[[w11, w12, w13, w14],
 [w21, w22, w23, w24],
 [w31, w32, w33, w34],
 [w41, w42, w43, w44]]

Bias

[b1, b2, b3, b4]
y1 = x1·w11 + x2·w12 + x3·w13 + x4·w14 + b1
y2 = x1·w21 + x2·w22 + x3·w23 + x4·w24 + b2
y3 = x1·w31 + x2·w32 + x3·w33 + x4·w34 + b3
y4 = x1·w41 + x2·w42 + x3·w43 + x4·w44 + b4
출력 = 입력 @ Weightᵀ + Bias

Weight 원소는 4×4=16개이고 Bias 원소는 4개이므로, 총 20개의 학습 파라미터가 있습니다.

7. 출력마다 직접 연결된 Weight 행이 다르다

첫째·둘째 출력

y1은 Weight 1행과 b1, y2는 Weight 2행과 b2를 직접 사용합니다.

셋째·넷째 출력

y3은 Weight 3행과 b3, y4는 Weight 4행과 b4를 직접 사용합니다.

Weight 1행과 b1 변경 → y1 변경
Weight 2행과 b2 변경 → y2 변경
Weight 3행과 b3 변경 → y3 변경
Weight 4행과 b4 변경 → y4 변경

따라서 하나의 Linear 계층에 같은 고정 입력을 넣는 이 범위에서는 Weight 1행과 b1만 바꾸면 y1은 바뀌지만 y2, y3, y4는 직접 바뀌지 않습니다.

8. 최종 Loss 하나가 모든 파라미터와 연결된다

예측이 [y1, y2, y3, y4], 정답이 [t1, t2, t3, t4]이고 평균제곱오차를 사용한다면 최종 Loss는 하나입니다.

Loss = ((y1−t1)² + (y2−t2)² + (y3−t3)² + (y4−t4)²) / 4

출력별 오차는 여러 개지만 평균을 내어 최종 Loss 하나를 만듭니다. 그 Loss 안에는 y1~y4가 있고, 각 출력 안에는 다시 Weight와 Bias가 들어 있습니다.

Weight·Bias20개 학습 파라미터
y1~y4네 개의 출력
최종 Loss평균한 하나의 값

따라서 Loss는 하나여도 각 Weight와 Bias가 그 Loss에 미치는 영향은 원소별로 따로 계산할 수 있습니다.

9. 각 파라미터 방향의 순간변화율

개념적으로 w11에 대한 Gradient는 다른 파라미터를 고정하고 w11만 아주 조금 움직였을 때 최종 Loss가 변하는 순간변화율입니다. w12와 b1도 같은 방식으로 생각합니다.

w11만 조금 변경 → y1 변화 → 최종 Loss 변화 → ∂Loss/∂w11
w12만 조금 변경 → y1 변화 → 최종 Loss 변화 → ∂Loss/∂w12
b1만 조금 변경  → y1 변화 → 최종 Loss 변화 → ∂Loss/∂b1
∂Loss/∂w11, ∂Loss/∂w12, ... , ∂Loss/∂w44
∂Loss/∂b1,  ∂Loss/∂b2,  ∂Loss/∂b3,  ∂Loss/∂b4

그 결과 파라미터와 같은 Shape의 Gradient가 만들어집니다.

Weight

파라미터 Shape [4,4] → Gradient Shape [4,4]

Bias

파라미터 Shape [4] → Gradient Shape [4]

10. backward()는 실제로 하나씩 움직여보지 않는다

“다른 값을 고정하고 한 원소만 조금 움직인다”는 설명은 각 편미분의 의미를 이해하기 위한 사고 실험입니다. PyTorch가 Weight 16개와 Bias 4개를 실제로 하나씩 바꾸면서 Loss를 20번 다시 계산하는 것은 아닙니다.

Weight·BiasForward의 학습 파라미터
Linear 출력기록된 계산 관계
Lossbackward()의 출발점

loss.backward()는 Forward에서 기록된 계산 관계를 거꾸로 따라가며 미분 규칙을 적용합니다. 이를 통해 모든 Weight와 Bias의 Gradient를 효율적인 Tensor 연산으로 함께 계산하고 각 파라미터의 .grad에 저장합니다. 이때 파라미터 값 자체는 아직 바뀌지 않습니다.

11. 한 학습 Step에서 모든 원소를 각자 업데이트한다

Gradient 계산이 끝나면 각 파라미터에 같은 업데이트 규칙을 적용합니다.

새 파라미터 = 기존 파라미터 − 학습률 × 해당 파라미터의 Gradient
새 w11 = 기존 w11 - 학습률 × w11.grad
새 w12 = 기존 w12 - 학습률 × w12.grad
...
새 w44 = 기존 w44 - 학습률 × w44.grad

새 b1 = 기존 b1 - 학습률 × b1.grad
...
새 b4 = 기존 b4 - 학습률 × b4.grad

모든 원소를 한 학습 Step에서 함께 업데이트하지만 모두 같은 양만큼 움직이는 것은 아닙니다. 각 원소는 자신에게 계산된 Gradient의 부호와 크기에 따라 서로 다른 방향과 거리로 이동합니다.

12. “병렬로 학습한다”는 의미

Weight 1행과 b1 → y1 계산식
Weight 2행과 b2 → y2 계산식
Weight 3행과 b3 → y3 계산식
Weight 4행과 b4 → y4 계산식

컴퓨터는 이 네 출력 계산식을 하나씩 수동으로 처리하지 않고 행렬 연산으로 함께 계산합니다. 이어 최종 Loss 하나에서 모든 원소의 Gradient를 Tensor 연산으로 함께 계산하고, 한 Step에서 모두 업데이트합니다.

Forwardy1~y4를 함께 계산
Loss최종 Loss 하나 계산
Backward모든 Gradient 계산
Step각 원소를 함께 갱신
병렬 계산과 파라미터 독립성을 같은 뜻으로 보면 안 됩니다.

이 예에서는 각 출력이 서로 다른 Weight 행에 직접 연결되지만, “병렬 학습”의 핵심은 Tensor 연산으로 여러 출력과 Gradient를 함께 계산한다는 뜻입니다. 모든 파라미터가 같은 값으로 움직이거나, 더 깊은 모델에서도 서로 영향을 주지 않는다는 뜻은 아닙니다.

전체 흐름

1. 입력이 Linear에 들어간다.
2. Weight 행렬을 곱하고 Bias 벡터를 더한다.
3. 여러 출력값이 만들어진다.
4. 출력값과 정답을 비교해 최종 Loss 하나를 만든다.
5. Loss에 대한 각 Weight·Bias 원소의 Gradient를 계산한다.
6. 모든 원소를 각자의 Gradient에 따라 함께 조정한다.
7. 이 과정을 반복하며 Loss를 줄인다.
핵심 정리

Loss는 하나지만, 그 Loss가 각각의 Weight와 Bias에 얼마나 민감한지는 원소별로 계산할 수 있습니다. Linear의 각 출력은 해당 Weight 행과 Bias에 직접 연결되고, PyTorch는 모든 Gradient를 Tensor 연산으로 계산하여 각 파라미터를 서로 다른 크기와 방향으로 함께 조정합니다.
