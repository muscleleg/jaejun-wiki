데이터에서 y = 3x + 2를 찾아내기

랜덤한 기울기와 절편에서 출발해, 예측 오차를 측정하고 Gradient를 이용해 두 값을 한 번 수정하는 과정을 코드 한 줄씩 이해합니다.

전체 목표 전체 코드 w와 b 오차와 MSE 평균변화율과 미분 Gradient 값 수정 실제 데이터 MLP Tensor Shape 타입 Device·CUDA 병렬 연산

1. 데이터에서 y = 3x + 2를 찾는다

입력 x로 정답 y를 예측하고, 여러 데이터에 공통으로 맞는 weight와 bias를 학습한다. 이 작은 문제는 예측·Loss·Gradient·업데이트라는 신경망 학습의 기본 흐름을 그대로 가진다.

2. 한 번의 학습 흐름

prediction = x * weight + bias
loss = ((prediction - y) ** 2).mean()
loss.backward()

with torch.no_grad():
    weight -= learning_rate * weight.grad
    bias -= learning_rate * bias.grad

weight.grad.zero_()
bias.grad.zero_()

Forward가 예측을 만들고, Loss가 틀린 정도를 한 숫자로 만들며, backward()가 각 파라미터에 대한 변화율을 계산한다.

3. 랜덤한 파라미터에서 시작한다

weight와 bias는 정답을 미리 아는 값이 아니라 학습할 Tensor다. requires_grad=True는 이 값으로 이어지는 연산을 기록해 나중에 Gradient를 구하겠다는 뜻이다.

4. MSE Loss로 예측 오차를 측정한다

오차를 제곱하면 양수와 음수가 상쇄되지 않고, 큰 오차에 더 큰 비용을 준다. 여러 샘플의 제곱 오차를 평균내면 현재 파라미터 조합의 성능을 한 숫자로 비교할 수 있다.

첫 예측·Tensor·MSE 계산을 실제 숫자로 보기 →

5. 평균변화율에서 순간변화율로 간다

두 점 사이의 평균변화율에서 두 번째 점을 기준점에 가까이 보내면 현재 위치의 순간변화율에 접근한다. 학습에서는 이 순간변화율이 파라미터를 어느 방향으로 얼마나 움직일지 알려준다.

6. backward()가 Gradient를 계산한다

weight.grad는 weight 자체의 변화량이 아니라, weight를 조금 바꿨을 때 Loss가 변하는 비율이다. 부호는 Loss를 줄이려면 어느 방향으로 움직여야 하는지 알려준다.

7. Gradient의 반대 방향으로 파라미터를 수정한다

parameter -= learning_rate * gradient에서 학습률은 Gradient를 얼마만큼 반영할지 정한다. Gradient가 음수면 빼기와 음수가 만나 파라미터가 증가한다. backward()는 Gradient를 누적하므로 다음 Step 전에 0으로 지운다.

학습률·no_grad()·누적 Gradient·업데이트 검산 보기 →

8. nn.Linear와 Optimizer가 같은 역할을 나눠 맡는다

model = nn.Linear(1, 1)
loss_fn = nn.MSELoss()
optimizer = torch.optim.SGD(model.parameters(), lr=0.1)

optimizer.zero_grad()
prediction = model(x)
loss = loss_fn(prediction, y)
loss.backward()
optimizer.step()

nn.Linear는 weight와 bias를 보관하며 Forward를 수행하고, Loss 함수는 오차를 계산한다. Optimizer는 등록된 파라미터의 Gradient를 읽어 업데이트한다. 모두 같은 수정 전 상태에서 계산된 Gradient를 한 Step에서 함께 적용한다.

9. Dataset과 DataLoader가 입력·정답을 Batch로 묶는다

TensorDataset(x, y)는 같은 인덱스의 입력과 정답을 한 샘플로 묶고, DataLoader는 이를 batch_size만큼 꺼낸다. 마지막에 남은 샘플 수가 Batch 크기보다 작으면 더 작은 마지막 Batch가 만들어진다.

10. 실제 표 데이터에서는 전처리부터 MLP까지 연결한다

작은 숫자 Tensor에서 시작한 흐름을 공개 회원 이탈 데이터로 확장했다. Pandas의 19개 원본 Feature를 One-Hot·StandardScaler로 45개 숫자 Feature로 바꾸고, NumPy → float32 Tensor → TensorDataset → DataLoader → [batch,45] → [batch,16] → [batch,1] MLP와 초기 BCE Loss까지 연결했다. 이어 같은 Batch에서 SGD를 한 번 적용해 Loss가 0.6564000844955444 → 0.6511512994766235로 내려가는 실행도 확인했으며, 다차원 Linear의 파라미터·Shape 설명과 반복 학습은 아직 진행 중이다.

12. 장치 이동에서 GPU 병렬 연산까지 연결한다
