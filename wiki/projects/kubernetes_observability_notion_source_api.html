편입 원칙
기존 상세 문서는 유지하고, Notion 원문의 질문·구조·API·비교를 별도 source archive로 연결했다. 자격증명·환경 주소·개인 경로는 공개하지 않는다.

현재 이해도

원문을 편입한 것과 현재 구현·보안·계약을 다시 검증한 것은 다르다. 이 문서는 0%에서 시작한다.

편입 후 검증 메모

  • 원문과 현재 구현: 이 문서는 Notion 시점의 source archive다. 현재 프로젝트 허브와 실제 OpenAPI/schema를 기준으로 endpoint drift를 확인한다.
  • 권한: cluster credential과 ServiceAccount 권한은 최소화하고 logs·events·metrics 조회 범위를 분리한다.
  • AI 응답: summary·inference·evidence를 구조적으로 분리하고, 근거 없는 원인 단정을 허용하지 않는다.
  • API 계약: status code·pagination·timeout·partial failure·schema version을 테스트해 Frontend와 Backend의 암묵적 결합을 줄인다.
