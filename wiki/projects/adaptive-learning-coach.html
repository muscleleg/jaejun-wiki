개인화 학습 코치 위키

Codex와 같은 코딩 에이전트와 공부한 과정이 다음 학습까지 이어지도록 만든 저장소 기반 학습 자동화 하네스입니다. 로드맵은 최종 목표·현재 관문·완료 조건·다음 순서를 기억하고, 학습 기록은 실제로 공부한 내용·확인한 이해·막힌 지점을 남깁니다. 코딩 에이전트는 둘을 함께 읽어 지금 할 한 단계와 다음 설명을 갱신합니다. 한 번 확인한 핵심 개념은 독립적인 기억 강화 세션에서 시간이 지난 뒤 자료 없이 다시 꺼내 장기기억 유지 여부를 확인합니다.

학습 중 다른 의문이 생겨도 당장 방향을 바꿀 필요가 없습니다. 의문을 보류 이유와 함께 남겨 두면 에이전트가 현재 학습을 우선하고, 다시 배울 시점이 왔을 때 해당 내용을 제안합니다. 다음 대화는 마지막으로 확인한 지점에서 이어지며, 기한이 된 회상 문제가 있으면 새 학습 전에 최대 세 개만 짧게 확인합니다.

프로젝트 형태코딩 에이전트가 저장소를 읽고 수정하는 학습 방식입니다. HTML·CSS·JavaScript로 결과를 보여 주고 Git으로 문서의 변경 이력을 관리합니다. 별도의 백엔드 서비스나 독립 실행형 AI 제품은 아닙니다.

개발 배경

문제는 공부할 내용이 부족한 것이 아니라, 매 순간 무엇을 먼저 해야 하는지 다시 결정해야 한다는 점이었습니다. 새 의문을 바로 따라가면 현재 학습이 끊기고, 미루면 잊을 것 같아 불안했습니다.

학습 속도가 빨라질수록 또 다른 문제가 생겼습니다. 배운 날에는 설명하고 구현할 수 있어도 시간이 지나면 핵심 흐름과 코드가 흐려졌고, 문서를 다시 읽는 것만으로는 기억에서 직접 꺼낼 수 있는지 확인하기 어려웠습니다.

기존 방식떠오른 의문이 곧 다음 할 일이 됩니다.

학습 방향이 자주 바뀌고, 중단 뒤에는 어디서 다시 시작할지 판단해야 합니다.

개선 방식의문을 기록하고 지금 중요한 학습을 계속합니다.

에이전트가 보류 이유와 다시 볼 조건을 기억하므로 나중에 반드시 보강할 수 있습니다.

가장 큰 변화은 “지금 무엇을 하지?”를 고민하는 시간이 줄었다는 점입니다. 로드맵에는 앞으로 갈 순서가, 학습 기록에는 실제로 공부한 내용과 확인 근거가 남습니다. 두 기록이 함께 있기 때문에 새 의문을 잊지 않으면서도 현재 가장 중요한 학습에 집중할 수 있습니다. 기억 강화 세션은 여기에 시간이 지난 뒤에도 남아 있는 지식을 실제 답변으로 다시 확인하는 순환을 더합니다.

  2. 목표 02
    지금 중요한 학습에 집중

    새 관심사는 잃지 않게 기록하되 현재 학습을 임의로 밀어내지 않게 합니다.

  3. 목표 03
    중단 지점에서 바로 재개

    마지막으로 확인한 내용과 다음 행동을 읽어 이미 끝낸 설명을 반복하지 않습니다.

  4. 목표 04
    사용자의 언어로 다시 설명

    과거에 사용한 표현과 직접 다룬 예제를 새로운 설명과 실습에 활용합니다.

  5. 목표 05
    시간이 지난 뒤에도 기억에서 회수

    처음 이해한 근거와 지연 회상 결과를 분리하고, 실제 성공 정도에 따라 다음 확인 간격을 조정합니다.

주요 기능

네 기능이 하나의 학습 순환을 만듭니다. 공부하면서 생긴 증거와 의문을 자동으로 기록하고, 확인된 핵심 개념은 기억 강화 세션에서 다시 꺼냅니다. 로드맵과 학습 기록을 비교해 지금 할 한 단계를 정하고, 확인된 설명은 체계적으로 쌓아 필요할 때 빠르게 찾습니다.

    자동 학습 기록과 보류 목록LLM이 학습 내용을 자동으로 정리하고, 큰 의문은 다시 볼 조건과 함께 보관합니다.
  2. 02
    기억 강화 세션AI 엔지니어 성장과 기업 코딩 테스트 합격에 필요한 지식을 우선순위와 간격에 따라 자료 없이 다시 확인합니다.
  3. 03
    로드맵·학습 기록 기반 코칭앞으로 갈 방향과 지금까지 확인한 근거·기억 강화 결과를 함께 읽어 다음 설명과 실습을 정합니다.
  4. 04
    체계적인 문서 축적과 빠른 탐색학습 내용을 주제와 관계에 따라 쌓고, 검색과 지식 지도에서 필요한 문서를 빠르게 찾습니다.

기록 자동화
사용자는 질문하고 설명하고 실습합니다.

LLM을 사용하는 코딩 에이전트가 대화와 실습 결과를 읽어 이해한 내용과 남은 의문을 구분합니다. 날짜·학습 주제·총 공부시간은 하나의 학습 기록 JSON에 함께 쌓고, 빌드가 이 원본에서 캘린더와 공부시간을 포함한 날짜별 기록 화면을 만듭니다. 확인된 진전은 관문별 실습 기록에는 실행 근거로, 주제별 기술 문서에는 다시 쓸 수 있는 설명으로 나누어 보존합니다.

기억 강화 연결
확인된 지식을 별도의 세션으로 보냅니다.

위키에 새로 추가하거나 보강한 내용 중 설명·예측·구현으로 이해가 확인된 단위를 기억 강화 세션의 JSON 목록에 쌓습니다. 처음 이해한 기록과 시간이 지난 뒤의 유지 결과를 섞지 않으므로, 문서를 많이 만든 것과 실제로 기억에 남은 것을 구분할 수 있습니다.

집중 유지
모든 의문을 지금 해결하지 않습니다.

현재 학습에 꼭 필요한 질문만 바로 다루고, 큰 개념이거나 오래 걸리는 질문은 보류 목록으로 옮겨 지금 가장 중요한 학습을 계속합니다.

사용자가 얻는 변화배운 내용을 직접 기록하고 분류해 로드맵과 문서까지 갱신하면 학습보다 정리에 더 많은 시간이 들 수 있습니다. 코딩 에이전트가 이 정리 작업과 우선순위 판단을 자동화하므로, 사용자는 새 의문을 잊지 않으면서도 지금 가장 중요한 공부에 계속 집중할 수 있습니다. 짧은 회상 결과가 누적되면 많이 배운 내용 중 실제로 남아 있는 지식과 다시 꺼내야 할 지식을 구분할 수 있습니다.

기능 02

기억 강화 세션

위키에 쌓인 AI 지식과 코딩 테스트 풀이를 자료 없이 다시 꺼내고, 실제 결과에 따라 다음 확인 시점을 조정합니다.

방향 고정
복습이 향할 곳을 두 목표로 제한합니다.

AI 엔지니어로서 성장과 기업 코딩 테스트 합격에 반복해서 필요한 지식을 유지합니다. 로드맵별 분류나 분야별 고정 할당량은 두지 않습니다.

JSON 누적
HTML이 아니라 하나의 상태 파일에 기억 근거를 쌓습니다.

각 항목의 중요도, 처음 이해한 근거, 다음 확인일, 간격 단계와 전체 결과 이력을 JSON에 보존합니다. 화면은 이 데이터를 읽어 보여 주는 열람 결과입니다.

우선순위 선택
최근 실패·중요도·밀린 기간을 비교해 최대 세 개만 고릅니다.

중요도가 낮은 내용도 버리지 않고 후순위로 남깁니다. 한 방향이 오랫동안 선택에서 사라지지 않는지도 누적 결과로 확인합니다.

간격 조정
실패·힌트·무힌트 성공·변형 적용을 서로 다르게 기록합니다.

자료 없이 답한 정도에 따라 다음 복습 간격을 줄이거나 늘립니다. 처음 배운 날의 성공은 이해 근거로, 하루 이상 지난 뒤의 성공은 유지 근거로 구분합니다.

사용자가 얻는 변화배운 내용이 단순히 문서로 남는 데서 끝나지 않고, 실제로 기억에서 꺼낼 수 있는지 주기적으로 확인됩니다. 새 학습 흐름을 끊지 않는 짧은 세션으로 약한 기억을 먼저 발견하고 다시 강화할 수 있습니다.

회상 확인

새로 확인한 설명은 주제와 상위·하위 관계에 따라 기존 문서 체계 안에 연결합니다. 기록이 늘어나도 관련 내용을 한 흐름으로 따라갈 수 있게 정리합니다.

빠른 검색과 연결기억나는 단어나 개념 관계만으로 필요한 문서에 접근합니다.

전체 문서 검색은 원하는 기록으로 바로 이동하게 하고, 지식 지도는 같은 개념과 연결된 설명을 함께 찾게 합니다. 위키가 커져도 어디서부터 다시 볼지 찾는 시간을 줄입니다. 기술 블로그는 사용자가 소개하기로 한 위키 문서를 하나의 글 목록으로 보여 주고, 각 글에는 핵심 내용을 구분하는 태그를 붙입니다. 제목·문서 설명·위키 카테고리는 기존 문서 색인에서 가져와 같은 원문으로 연결합니다. 블로그와 위키에 본문을 이중 저장하지 않으므로 글을 고쳐도 원문 하나만 갱신하면 됩니다.

사용자가 얻는 변화학습 기록이 쌓일수록 정리 부담이 커지는 대신, 필요한 내용을 빠르게 찾아 복습이나 다음 학습에 바로 사용할 수 있습니다. 그중 따로 소개할 글은 사용자가 직접 선정하며, 에이전트가 질문이나 문서 완성만으로 자동 선정하지 않습니다.

빠른 접근 경로전체 문서 찾기기술 블로그지식 지도

학습이 이어지는 과정

앞에서 소개한 네 기능은 따로 움직이지 않습니다. 한 번의 질문과 실습이 기록으로 남고, 확인된 핵심 개념은 기억 강화 세션에서 간격을 두고 다시 꺼내며, 그 결과가 다음 행동과 설명을 바꿉니다. 확인된 내용은 다시 찾을 수 있는 문서가 되어 다음 학습으로 이어집니다.

  1. 01
    질문하고 직접 확인합니다.

    사용자는 자신의 말로 설명하고 결과를 예상한 뒤, 작은 예제를 실행해 이해한 내용과 새 의문의 근거를 남깁니다. 기한이 된 회상 문제가 있으면 원문을 열기 전에 기억에서 먼저 답합니다.

  2. 02
    현재 위치와 새 근거를 비교합니다.

    코딩 에이전트는 로드맵의 현재 관문과 기존 학습 기록, 지연 회상 결과를 함께 읽어 새 의문을 지금 다룰지 보류할지, 약한 기억을 언제 다시 확인할지 판단합니다.

  3. 03
    로드맵·기록·문서를 갱신합니다.

    지금 필요한 한 단계, 확인된 이해, 막힌 지점과 보류 이유를 역할에 맞는 기록에 나누어 남깁니다. 회상 성공 정도에 따라 다음 확인 간격도 갱신합니다.

  4. 04
    누적된 상태에서 다시 시작합니다.

    다음 대화에서는 기한이 된 회상을 최대 세 개만 확인한 뒤 마지막 학습 지점에서 이어가고, 필요한 설명은 문서 검색과 지식 지도에서 바로 찾아 활용합니다.

↺다음 질문은 처음부터 시작하지 않습니다.새 질문과 실습 결과, 시간이 지난 뒤의 회상 결과가 다시 이 순환의 근거가 되어 다음 학습의 방향과 출발점을 더 구체적으로 만듭니다.

사용자가 얻는 변화새 의문을 잊지 않으면서도 지금 중요한 공부를 계속하고, 다음 대화에서는 무엇을 할지 다시 고민하지 않고 마지막 학습 지점에서 바로 이어갈 수 있습니다. 동시에 많이 배운 내용 중 무엇이 실제 장기기억에 남아 있는지도 지연 회상 근거로 확인할 수 있습니다.

자동화의 역할과 경계

사용자는 학습하고 판단하며, 코딩 에이전트는 기억·제안·문서화를 보조합니다.이 화면 자체가 대화형 코칭을 수행하는 별도의 백엔드 서비스는 아닙니다. 사용자는 Codex와 같은 코딩 에이전트와 대화하고, 코딩 에이전트가 저장소의 지침과 누적 상태를 읽고 갱신하며, 정적 HTML 위키는 그 결과를 보여 줍니다.

사용자가 결정하고 수행하는 일

  • 핵심 학습 방향과 공개 범위를 정합니다.
  • 직접 설명하고 결과를 예상한 뒤, 예제를 실행해 이해를 확인합니다.
  • 회상 문제에서는 원문을 보기 전에 기억에서 먼저 답합니다.
  • 에이전트의 제안과 기록이 의도에 맞는지 최종 판단합니다.

코딩 에이전트가 보조하는 일

  • 대화·실습 결과와 로드맵·학습 기록을 비교합니다.
  • 지금 할 한 단계와 기한이 된 회상 문제를 제안합니다.
  • 확인된 이해·지연 회상 결과·남은 의문을 구분해 기록합니다.
  • 학습 문서와 공개 화면이 누적된 상태와 어긋나지 않는지 확인합니다.

저장과 열람의 경계로드맵은 앞으로 갈 방향을 기억합니다. 학습 기록 JSON은 날짜·공부한 내용·총 공부시간을, 기억 강화 상태 JSON은 이미 배운 지식의 중요도·다음 확인일·전체 결과 이력을, 보류 목록은 나중에 다시 볼 의문을 기억합니다. 학습 캘린더·공부시간을 포함한 날짜별 기록과 기억 강화 세션 HTML은 각 JSON에서 생성한 열람 화면이며 별도의 이력 원본이 아닙니다. 홈·프로젝트·위키·블로그 목록에 반복되는 제목·설명·태그·등록일·노출 위치·선택형 썸네일은 하나의 콘텐츠 카탈로그에 저장하고, 각 화면은 같은 항목을 목적에 맞는 카드나 목록으로 다르게 렌더링합니다. 실제 본문은 카탈로그의 href가 가리키는 HTML 문서 하나로 유지합니다.

에이전트는 사용자가 정한 방향 안에서만 우선순위를 제안합니다. 장기 목표를 임의로 바꾸거나 확인하지 않은 내용을 완료로 기록하지 않습니다.

학습 기록을 신뢰할 수 있는 이유

자동 기록과 다음 행동 제안은 많이 남기는 것보다, 실제로 확인한 이해와 시간이 지난 뒤의 유지 여부를 정확하게 기억할 때 가치가 있습니다. 그래서 학습 근거, 지연 회상, 다음 행동, 공개 기록을 서로 다른 기준으로 확인합니다.

이해 확인
공부한 시간이나 코드의 양만으로 완료를 판단하지 않습니다.

사용자가 자신의 말로 설명하고 결과를 예상한 뒤, 작은 예제를 직접 실행해 확인할 수 있는지를 봅니다.

장기 유지
처음 배운 날의 성공과 지연 회상 성공을 분리합니다.

하루 이상 지난 뒤 자료 없이 설명·Shape 예측·코드 재구현에 성공한 결과만 유지 근거로 기록하고, 힌트 사용 여부와 변형 적용 결과에 따라 다음 간격을 조정합니다.

다음 행동
로드맵의 방향과 실제 학습 기록을 함께 대조합니다.

현재 관문을 막는 내용만 바로 보강하고, 범위가 크거나 오래 걸리는 의문은 보류 이유와 다시 볼 조건을 남긴 뒤 현재 학습을 계속합니다.

공개 기록
JSON 원본과 사람이 보는 화면을 독립적으로 대조합니다.

학습 날짜·주제 수·공부시간을 JSON에서 읽고, 캘린더 링크·공부시간이 결합된 날짜별 카드·상단 합계가 모두 같은지 검사합니다. 기존 링크·문서 계층·검색·지식 지도와 공개 안전 검사도 함께 유지합니다.

이 프로젝트의 핵심은 문서의 양이 아니라 학습 → 간격 회상 → 판단 → 기록 → 다음 학습이 실제 근거를 따라 계속 이어지는 데 있습니다.
