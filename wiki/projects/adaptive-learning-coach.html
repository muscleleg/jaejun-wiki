개인화 학습 코치 위키

Codex와 같은 코딩 에이전트와 공부한 과정이 다음 학습까지 이어지도록 만든 저장소 기반 학습 자동화 하네스입니다. 로드맵은 최종 목표·현재 관문·완료 조건·다음 순서를 기억하고, 학습 기록은 실제로 공부한 내용·확인한 이해·막힌 지점을 남깁니다. 코딩 에이전트는 둘을 함께 읽어 지금 할 한 단계와 다음 설명을 갱신합니다.

학습 중 다른 의문이 생겨도 당장 방향을 바꿀 필요가 없습니다. 의문을 보류 이유와 함께 남겨 두면 에이전트가 현재 학습을 우선하고, 다시 배울 시점이 왔을 때 해당 내용을 제안합니다. 다음 대화는 마지막으로 확인한 지점에서 이어집니다.

프로젝트 형태코딩 에이전트가 저장소를 읽고 수정하는 학습 방식입니다. HTML·CSS·JavaScript로 결과를 보여 주고 Git으로 문서의 변경 이력을 관리합니다. 별도의 백엔드 서비스나 독립 실행형 AI 제품은 아닙니다.

개발 배경

문제는 공부할 내용이 부족한 것이 아니라, 매 순간 무엇을 먼저 해야 하는지 다시 결정해야 한다는 점이었습니다. 새 의문을 바로 따라가면 현재 학습이 끊기고, 미루면 잊을 것 같아 불안했습니다.

기존 방식떠오른 의문이 곧 다음 할 일이 됩니다.

학습 방향이 자주 바뀌고, 중단 뒤에는 어디서 다시 시작할지 판단해야 합니다.

개선 방식의문을 기록하고 지금 중요한 학습을 계속합니다.

에이전트가 보류 이유와 다시 볼 조건을 기억하므로 나중에 반드시 보강할 수 있습니다.

가장 큰 변화은 “지금 무엇을 하지?”를 고민하는 시간이 줄었다는 점입니다. 로드맵에는 앞으로 갈 순서가, 학습 기록에는 실제로 공부한 내용과 확인 근거가 남습니다. 두 기록이 함께 있기 때문에 새 의문을 잊지 않으면서도 현재 가장 중요한 학습에 집중할 수 있습니다.

  2. 목표 02

  3. 목표 03
    중단 지점에서 바로 재개

  4. 목표 04
    사용자의 언어로 다시 설명

빠른 검색과 연결기억나는 단어나 개념 관계만으로 필요한 문서에 접근합니다.

전체 문서 검색은 원하는 기록으로 바로 이동하게 하고, 지식 지도는 같은 개념과 연결된 설명을 함께 찾게 합니다. 위키가 커져도 어디서부터 다시 볼지 찾는 시간을 줄입니다.

학습이 이어지는 과정

앞에서 소개한 세 기능은 따로 움직이지 않습니다. 한 번의 질문과 실습이 기록으로 남고, 그 기록이 다음 행동과 설명을 바꾸며, 확인된 내용은 다시 찾을 수 있는 문서가 되어 다음 학습으로 이어집니다.

  1. 01
    질문하고 직접 확인합니다.

    사용자는 자신의 말로 설명하고 결과를 예상한 뒤, 작은 예제를 실행해 이해한 내용과 새 의문의 근거를 남깁니다.

  2. 02
    현재 위치와 새 근거를 비교합니다.

    코딩 에이전트는 로드맵의 현재 관문과 기존 학습 기록을 함께 읽어, 새 의문을 지금 다룰지 보류할지 판단합니다.

  3. 03
    로드맵·기록·문서를 갱신합니다.

    지금 필요한 한 단계, 확인된 이해, 막힌 지점과 보류 이유를 역할에 맞는 기록에 나누어 남깁니다.

  4. 04
    누적된 상태에서 다시 시작합니다.

    다음 대화에서는 마지막 학습 지점에서 이어가고, 필요한 설명은 문서 검색과 지식 지도에서 바로 찾아 활용합니다.

사용자가 얻는 변화새 의문을 잊지 않으면서도 지금 중요한 공부를 계속하고, 다음 대화에서는 무엇을 할지 다시 고민하지 않고 마지막 학습 지점에서 바로 이어갈 수 있습니다.

자동화의 역할과 경계

사용자는 학습하고 판단하며, 코딩 에이전트는 기억·제안·문서화를 보조합니다.이 화면 자체가 대화형 코칭을 수행하는 별도의 백엔드 서비스는 아닙니다. 사용자는 Codex와 같은 코딩 에이전트와 대화하고, 코딩 에이전트가 저장소의 지침과 누적 상태를 읽고 갱신하며, 정적 HTML 위키는 그 결과를 보여 줍니다.

사용자가 결정하고 수행하는 일

  • 핵심 학습 방향과 공개 범위를 정합니다.
  • 직접 설명하고 결과를 예상한 뒤, 예제를 실행해 이해를 확인합니다.
  • 에이전트의 제안과 기록이 의도에 맞는지 최종 판단합니다.

코딩 에이전트가 보조하는 일

  • 대화·실습 결과와 로드맵·학습 기록을 비교합니다.
  • 지금 할 한 단계를 제안하고 확인된 이해와 남은 의문을 기록합니다.
  • 학습 문서와 공개 화면이 누적된 상태와 어긋나지 않는지 확인합니다.

저장과 열람의 경계로드맵은 앞으로 갈 방향을, 학습 기록은 지금까지 확인한 근거를, 보류 목록은 나중에 다시 볼 의문을 기억합니다. 학습 문서는 확인된 설명을 체계적으로 축적하고, 정적 HTML 위키는 이 내용을 읽고 다시 찾을 수 있게 보여 줍니다.

에이전트는 사용자가 정한 방향 안에서만 우선순위를 제안합니다. 장기 목표를 임의로 바꾸거나 확인하지 않은 내용을 완료로 기록하지 않습니다.

학습 기록을 신뢰할 수 있는 이유

자동 기록과 다음 행동 제안은 많이 남기는 것보다, 실제로 확인한 이해를 정확하게 기억할 때 가치가 있습니다. 그래서 학습 근거, 다음 행동, 공개 기록을 서로 다른 기준으로 확인합니다.

이해 확인
공부한 시간이나 코드의 양만으로 완료를 판단하지 않습니다.

사용자가 자신의 말로 설명하고 결과를 예상한 뒤, 작은 예제를 직접 실행해 확인할 수 있는지를 봅니다.

다음 행동
로드맵의 방향과 실제 학습 기록을 함께 대조합니다.

현재 관문을 막는 내용만 바로 보강하고, 범위가 크거나 오래 걸리는 의문은 보류 이유와 다시 볼 조건을 남긴 뒤 현재 학습을 계속합니다.

공개 기록
