편입 원칙
기존 상세 문서는 유지하고, Notion 원문의 질문·구조·API·비교를 별도 source archive로 연결했다. 자격증명·환경 주소·개인 경로는 공개하지 않는다.

현재 이해도

원문을 편입한 것과 현재 구현·보안·계약을 다시 검증한 것은 다르다. 이 문서는 0%에서 시작한다.

드라이버 작성

# src/db.py
import os
from dotenv import load_dotenv

from sqlalchemy.ext.asyncio import create_async_engine, async_sessionmaker
from sqlalchemy.orm import DeclarativeBase

# 환경 변수 파일 읽기
load_dotenv()

POSTGRES_USER = os.getenv("POSTGRES_USER", "postgres")
POSTGRES_PASSWORD = os.getenv("POSTGRES_PASSWORD")
POSTGRES_HOST = os.getenv("POSTGRES_HOST", "localhost")
POSTGRES_PORT = os.getenv("POSTGRES_PORT", "5432")
POSTGRES_DB = os.getenv("POSTGRES_DB", "postgres")

DATABASE_URL = (
    f"postgresql+asyncpg://{POSTGRES_USER}:{POSTGRES_PASSWORD}"
    f"@{POSTGRES_HOST}:{POSTGRES_PORT}/{POSTGRES_DB}"
)


# Base 클래스
class Base(DeclarativeBase):
    pass


# Async 엔진
engine = create_async_engine(
    DATABASE_URL,
    echo=True,
)

# Async 세션팩토리
SessionLocal = async_sessionmaker(
    bind=engine,
    autoflush=False,
    autocommit=False,
    expire_on_commit=False,
)

편입 후 검증 메모

  • 자격증명: Notion token·database ID·API key·connection URL은 공개본에서 제거했다. 실제 값은 최소 권한과 회전이 가능한 secret store에서 주입한다.
  • 수집 경계: 공개/공유된 page만 수집하고 권한 변경·삭제·하위 page 이동을 증분 동기화에 반영한다.
  • RAG 평가: 검색 hit와 답변 자연스러움만 보지 않고 문서 충실도·인용 정확성·모르는 질문 거절을 평가한다.
  • 다중 사용자: vector namespace·metadata filter·SQL row ownership과 cache까지 사용자 격리를 일관되게 적용한다.
