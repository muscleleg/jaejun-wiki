1. 평가가 답하려는 질문

파인튜닝 전후의 모델이 같은 사용자 요청에 대해 같은 도구 계약을 얼마나 잘 지키는지 비교한다. 이 코드는 Kubernetes API를 호출하지 않는다. 모델이 반환한 함수 후보를 검증하고 점수로 바꾸는 평가 하네스다.

같은 holdout JSONL
  → vLLM OpenAI-compatible 서버
  → OpenAI SDK chat.completions.create()
  → message.tool_calls 추출
  → score_case()로 한 건 채점
  → summarize()로 100건 집계
  → details.jsonl + summary.json
공정 비교의 핵심
Base와 Tuned를 서로 다른 문장이나 다른 생성 조건으로 평가하면 개선인지 데이터 차이인지 알 수 없다. 그래서 같은 holdout 100건, BF16, temperature=0, tool_choice="auto", thinking 비활성화 조건을 고정했다.

2. 파일별 책임

평가 코드는 입력을 준비하는 파일, 모델을 호출하는 파일, 한 건을 채점하는 파일, RunPod에서 전체 순서를 묶는 셸 파일로 나뉜다.

3. 모델 요청과 응답 추출

OpenAI-compatible 요청

response = client.chat.completions.create(
    model=model,
    messages=[
        {"role": "system", "content": SYSTEM_PROMPT},
        {"role": "user", "content": case.prompt},
    ],
    tools=TOOLS,
    tool_choice="auto",
    temperature=0,
    max_tokens=256,
    extra_body={"chat_template_kwargs": {"enable_thinking": False}},
)

client는 외부 OpenAI 모델을 뜻하지 않는다. base_url을 RunPod의 vLLM 주소로 지정한 OpenAI Python SDK 객체다. SDK 형식은 같지만 실제 추론은 RunPod의 Qwen Base 또는 Merged Tuned 모델이 수행한다.

  • tools=TOOLS: 모델이 선택할 수 있는 전체 다섯 도구의 계약
  • tool_choice="auto": 요청에 따라 호출 또는 no-call을 모델이 결정
  • temperature=0: 비교 시 샘플링 변동을 줄이는 고정 조건
  • max_tokens=256: 한 응답이 과도하게 길어지지 않도록 제한
  • enable_thinking=False: 평가 대상인 tool call 전에 reasoning 출력이 끼지 않도록 고정

tool_calls를 내부 구조로 바꾸기

message = response.choices[0].message
calls = [
    ActualCall(
        name=call.function.name,
        arguments_json=call.function.arguments,
    )
    for call in (message.tool_calls or [])
]

OpenAI 응답의 message.tool_calls가 없으면 빈 리스트다. 각 호출에서 함수 이름과 인자 JSON 문자열만 꺼내 ActualCall로 감싼다. 아직 Kubernetes handler를 실행하거나 tool 결과를 다시 모델에 넣지 않는다.

예외도 평가 데이터다.
서버 오류나 응답 파싱 오류가 나면 예외를 버리지 않고 score_case(case, [], error=...)로 전달한다. 그래야 API 오류와 모델의 no-call을 구분해 결과 파일에 남길 수 있다.

4. 한 건을 채점하는 순서

scoring.py의 score_case()는 결과를 한 번에 “맞다/틀리다”로 판단하지 않고, 계약의 층을 아래 순서로 분해한다.

expected가 있는가? ── 아니오 → 실제 호출이 없고 오류도 없으면 no-call 성공
       │
       예
       ↓
호출 개수·오류 확인
  → 정확히 한 호출이면 함수명 확인
  → arguments_json 파싱
  → dict인지 확인
  → canonical Schema로 jsonschema.validate()
  → 기대 arguments와 exact match
  → 모든 조건이 참이면 full_success
필드의미판정 예
call decision호출이 필요한 요청에 호출했고, no-call 요청에는 호출하지 않았는가expects_call == emitted_call
tool selection호출 함수명이 기대한 도구명과 정확히 같은가list_pods와 get_pod는 다름
JSON validity인자 문자열이 JSON으로 파싱되는가따옴표가 깨지면 실패
Schema validity파싱된 dict가 도구의 타입·필수·enum 계약을 지키는가허용되지 않은 키나 enum이면 실패
Argument exact match기대 인자 dict와 실제 dict가 완전히 같은가사용자가 말하지 않은 namespace를 넣으면 실패
Full success위 호출·도구·JSON·Schema·인자 조건을 모두 통과했는가모든 계약의 AND

인자 precision·recall

정확히 같은 dict만 보는 지표 외에, 키 단위로 맞은 수(TP)·추가/오답(FP)·누락/오답(FN)을 세어 argument precision·recall·F1도 계산한다. 그래서 “인자 하나만 틀린 호출”과 “전혀 다른 호출”을 구분해 볼 수 있다.

기대 호출이 없는 행에서는 도구명·Schema를 평가하지 않고 no_call_correct만 본다. 단순히 빈 응답이면 성공이라는 뜻이 아니라, 지원하지 않는 요청에 도구를 억지로 호출하지 않았고 API 오류도 없어야 한다.

5. 100건을 집계하는 지표

summarize(scores)는 개별 CaseScore 목록을 전체 수치로 바꾼다. 이번 holdout은 기대 tool call 85건과 기대 no-call 15건으로 구성했다.

지표분모질문
Call decision accuracy전체 100건호출/비호출 결정을 맞혔는가
Tool selection accuracy기대 호출 85건호출할 도구명을 맞혔는가
JSON·Schema validity실제 호출이 하나인 행출력 형식과 계약을 지켰는가
Argument exact match기대 호출 85건인자 dict가 완전히 같은가
No-call accuracy기대 no-call 15건지원하지 않는 요청을 호출하지 않았는가
Full success전체 100건한 건의 최종 계약을 끝까지 통과했는가

최종 결과는 Base BF16의 Full success 36/100에서 Tuned BF16 96/100으로 올랐다. 이 수치는 단순히 호출 여부만 본 것이 아니라, 도구명·JSON·Schema·정확한 인자와 no-call까지 포함한 엄격한 결과다. 모든 지표의 정의는 범용 평가 계약 문서에서 개념적으로 다시 확인할 수 있다.

6. RunPod 평가 러너의 실행 순서

scripts/run_runpod_bf16_eval.sh는 단순히 Python 평가 파일을 실행하지 않는다. 동일한 서버 조건인지 확인하고, 평가가 끝나면 서버 프로세스도 정리한다.

필수 명령·Python import 확인
  → holdout SHA-256 검증
  → 포트 사용 여부 확인
  → 모델 revision과 실행 metadata 확정
  → vLLM OpenAI server 시작
  → /health polling
  → /v1/models에서 served alias 확인
  → evaluate_runpod_bf16 호출
  → details·summary 저장
  → EXIT trap으로 vLLM 종료

vLLM 서버 플래그

python -m vllm.entrypoints.openai.api_server \
  --model "$MODEL" \
  --served-model-name "$MODEL_ALIAS" \
  --dtype bfloat16 \
  --max-model-len 4096 \
  --gpu-memory-utilization 0.85 \
  --enable-auto-tool-choice \
  --tool-call-parser hermes \
  --reasoning-parser qwen3 \
  --generation-config vllm

--served-model-name은 SDK 요청의 model 문자열과 서버가 광고하는 이름을 일치시킨다. --enable-auto-tool-choice와 Hermes parser는 모델의 구조화된 tool call을 OpenAI 응답으로 변환하는 서버 측 설정이다. 서버 설정의 일반적인 계층은 프로젝트 실행 환경 문서에서 이어 본다.

checksum과 metadata

러너는 holdout 파일의 SHA-256이 기대값과 다르면 즉시 중단한다. 서버 metadata에는 run id, 모델 alias·revision, dtype, vLLM 버전, host·port, max length, GPU 사용률, parser와 실제 실행 명령을 기록한다. 따라서 나중에 “어떤 모델을 어떤 조건에서 평가했는가”를 결과만 보고도 확인할 수 있다.

def evaluate(client: OpenAI, model: str, cases: list[Any]) -> list[CaseScore]:
    scores: list[CaseScore] = []
    for index, case in enumerate(cases, start=1):
        try:
            response = client.chat.completions.create(
                model=model,
                messages=[
                    {"role": "system", "content": SYSTEM_PROMPT},
                    {"role": "user", "content": case.prompt},
                ],
                tools=TOOLS,
                tool_choice="auto",
                temperature=0,
                max_tokens=256,
                # Qwen3 supports thinking and non-thinking modes. Function-call
                # evaluation uses non-thinking mode so both baseline and tuned
                # models get the exact same deterministic request shape.
                extra_body={"chat_template_kwargs": {"enable_thinking": False}},
            )
            message = response.choices[0].message
            calls = [
                ActualCall(
                    name=call.function.name,
                    arguments_json=call.function.arguments,
                )
                for call in (message.tool_calls or [])
            ]
            score = score_case(case, calls)
        except Exception as exc:
            score = score_case(case, [], error=f"{type(exc).__name__}: {exc}")
        scores.append(score)
        print(
            f"[{index:03d}/{len(cases):03d}] {case.case_id}: "
            f"{'PASS' if score.full_success else 'FAIL'}",
            flush=True,
        )
    return scores

def write_results(
    *,
    output_dir: Path,
    run_id: str,
    model: str,
    dataset: Path,
    dataset_sha256: str,
    metadata: dict[str, Any],
    scores: list[CaseScore],
) -> tuple[Path, Path]:
    output_dir.mkdir(parents=True, exist_ok=True)
    details_path = output_dir / f"{run_id}_details.jsonl"
    summary_path = output_dir / f"{run_id}_summary.json"

    with details_path.open("w", encoding="utf-8") as stream:
        for score in scores:
            stream.write(json.dumps(score.to_dict(), ensure_ascii=False) + "\n")

    report = {
        "run_id": run_id,
        "model": model,
        "dataset": str(dataset.resolve()),
        "dataset_sha256": dataset_sha256,
        "inference": {
            "temperature": 0,
            "max_tokens": 256,
            "tool_choice": "auto",
            "enable_thinking": False,
        },
        "server": metadata,
        "metrics": summarize(scores),
    }
    summary_path.write_text(
        json.dumps(report, ensure_ascii=False, indent=2) + "\n",
        encoding="utf-8",
    )
    return details_path, summary_path


def main() -> None:
    args = parse_args()
    cases = load_dataset(args.dataset)
    if args.limit is not None:
        cases = cases[: args.limit]
    metadata = json.loads(args.metadata_json.read_text(encoding="utf-8"))
    client = OpenAI(base_url=args.base_url, api_key=args.api_key)
    scores = evaluate(client, args.model, cases)
    details_path, summary_path = write_results(
        output_dir=args.output_dir,
        run_id=args.run_id,
        model=args.model,
        dataset=args.dataset,
        dataset_sha256=args.dataset_sha256,
        metadata=metadata,
        scores=scores,
    )
    print(json.dumps(summarize(scores), ensure_ascii=False, indent=2))
    print(f"details={details_path}")
    print(f"summary={summary_path}")


if __name__ == "__main__":
    main()

def _normalize_dataset_row(value: dict[str, Any]) -> dict[str, Any]:
    """Accept both compact evaluation rows and held-out training-format rows."""
    if "prompt" in value:
        return value

    messages = value["messages"]
    user_messages = [message for message in messages if message.get("role") == "user"]
    assistant_messages = [
        message for message in messages if message.get("role") == "assistant"
    ]
    if len(user_messages) != 1 or len(assistant_messages) != 1:
        raise ValueError("expected exactly one user and one assistant message")

    tool_calls = assistant_messages[0].get("tool_calls", [])
    if len(tool_calls) > 1:
        raise ValueError("evaluation supports at most one expected tool call")

    expected = None
    if tool_calls:
        function = tool_calls[0]["function"]
        arguments = function.get("arguments", {})
        if isinstance(arguments, str):
            arguments = json.loads(arguments)
        if not isinstance(arguments, dict):
            raise TypeError("expected tool arguments must be an object")
        expected = {"name": function["name"], "arguments": arguments}

    return {
        "id": value["id"],
        "category": value["category"],
        "difficulty": value["difficulty"],
        "prompt": user_messages[0]["content"],
        "expected": expected,
    }


def load_dataset(path: Path) -> list[Any]:
    cases = []
    with path.open(encoding="utf-8") as stream:
        for line_number, line in enumerate(stream, start=1):
            if not line.strip():
                continue
            try:
                value = json.loads(line)
                cases.append(load_case(_normalize_dataset_row(value)))
            except (json.JSONDecodeError, KeyError, TypeError, ValueError) as exc:
                raise ValueError(f"Invalid dataset row at {path}:{line_number}: {exc}") from exc
    return cases

def evaluate(client: OpenAI, model: str, cases: list[Any]) -> list[CaseScore]:
    scores = []
    for index, case in enumerate(cases, start=1):
        try:
            response = client.chat.completions.create(
                model=model,
                messages=[
                    {"role": "system", "content": SYSTEM_PROMPT},
                    {"role": "user", "content": case.prompt},
                ],
                tools=TOOLS,
                tool_choice="auto",
                temperature=0,
                max_tokens=256,
            )
            message = response.choices[0].message
            calls = [
                ActualCall(
                    name=call.function.name,
                    arguments_json=call.function.arguments,
                )
                for call in (message.tool_calls or [])
            ]
            score = score_case(case, calls)
        except Exception as exc:
            score = score_case(case, [], error=f"{type(exc).__name__}: {exc}")
        scores.append(score)
        print(
            f"[{index:03d}/{len(cases):03d}] {case.case_id}: "
            f"{'PASS' if score.full_success else 'FAIL'}"
        )
    return scores


def write_results(
    output_dir: Path,
    model: str,
    dataset: Path,
    scores: list[CaseScore],
) -> tuple[Path, Path]:
    output_dir.mkdir(parents=True, exist_ok=True)
    timestamp = datetime.now(timezone.utc).strftime("%Y%m%dT%H%M%SZ")
    safe_model = model.replace("/", "_")
    details_path = output_dir / f"{timestamp}_{safe_model}_details.jsonl"
    summary_path = output_dir / f"{timestamp}_{safe_model}_summary.json"

    with details_path.open("w", encoding="utf-8") as stream:
        for score in scores:
            stream.write(json.dumps(score.to_dict(), ensure_ascii=False) + "\n")

    report = {
        "model": model,
        "dataset": str(dataset),
        "created_at": timestamp,
        "metrics": summarize(scores),
    }
    summary_path.write_text(
        json.dumps(report, ensure_ascii=False, indent=2) + "\n",
        encoding="utf-8",
    )
    return details_path, summary_path


def main() -> None:
    args = parse_args()
    cases = load_dataset(args.dataset)
    if args.limit is not None:
        cases = cases[: args.limit]
    client = OpenAI(base_url=args.base_url, api_key=args.api_key)
    scores = evaluate(client, args.model, cases)
    details_path, summary_path = write_results(
        args.output_dir, args.model, args.dataset, scores
    )
    print(json.dumps(summarize(scores), ensure_ascii=False, indent=2))
    print(f"details={details_path}")
    print(f"summary={summary_path}")

def _argument_counts(
    expected: dict[str, Any], actual: dict[str, Any]
) -> tuple[int, int, int]:
    true_positives = sum(
        1 for key, value in actual.items() if key in expected and expected[key] == value
    )
    false_positives = len(actual) - true_positives
    false_negatives = sum(
        1 for key, value in expected.items() if key not in actual or actual[key] != value
    )
    return true_positives, false_positives, false_negatives

                "name": call.name,
                "arguments_json": call.arguments_json,
                "parsed_arguments": None,
            }

        )

def _rate(numerator: int, denominator: int) -> float | None:
    return round(numerator / denominator, 4) if denominator else None


def summarize(scores: list[CaseScore]) -> dict[str, Any]:
    expected_call_scores = [score for score in scores if score.expected_tool is not None]
    no_call_scores = [score for score in scores if score.expected_tool is None]
    single_call_scores = [score for score in scores if len(score.actual_calls) == 1]

    true_positives = sum(score.argument_true_positives for score in scores)
    false_positives = sum(score.argument_false_positives for score in scores)
    false_negatives = sum(score.argument_false_negatives for score in scores)
    precision = _rate(true_positives, true_positives + false_positives)
    recall = _rate(true_positives, true_positives + false_negatives)
    argument_f1 = None
    if precision is not None and recall is not None and precision + recall:
        argument_f1 = round(2 * precision * recall / (precision + recall), 4)

    by_category: dict[str, dict[str, Any]] = {}
    for category in sorted({score.category for score in scores}):
        category_scores = [score for score in scores if score.category == category]
        by_category[category] = {
            "cases": len(category_scores),
            "full_success_rate": _rate(
                sum(score.full_success for score in category_scores),
                len(category_scores),
            ),
        }

    return {
        "total_cases": len(scores),
        "expected_call_cases": len(expected_call_scores),
        "expected_no_call_cases": len(no_call_scores),
        "api_errors": sum(score.error is not None for score in scores),
        "call_decision_accuracy": _rate(
            sum(score.call_decision_correct for score in scores), len(scores)
        ),
        "tool_selection_accuracy": _rate(
            sum(bool(score.tool_selection_correct) for score in expected_call_scores),
            len(expected_call_scores),
        ),
        "json_validity_on_single_calls": _rate(
            sum(score.json_valid is True for score in single_call_scores),
            len(single_call_scores),
        ),
        "schema_validity_on_single_calls": _rate(
            sum(score.schema_valid is True for score in single_call_scores),
            len(single_call_scores),
        ),
        "arguments_exact_match": _rate(
            sum(score.arguments_exact is True for score in expected_call_scores),
            len(expected_call_scores),
        ),
        "argument_precision": precision,
        "argument_recall": recall,
        "argument_f1": argument_f1,
        "no_call_accuracy": _rate(
            sum(score.no_call_correct is True for score in no_call_scores),
            len(no_call_scores),
        ),
        "full_success_rate": _rate(
            sum(score.full_success for score in scores), len(scores)
        ),
        "by_category": by_category,
    }
