전체 경로L2·L3vethNATFloating IP검증

1. 먼저 패킷의 전체 경로를 그린다

VM fixed IP
  ↓ Tenant L2
Neutron Router
  ↓ Provider L2
Bridge ── veth pair ── Host L3 endpoint
  ↓ Routing + SNAT
외부 NIC → Upstream Router → Internet

Bridge와 veth는 Ethernet Frame을 이어 주고, IP가 있는 Host Endpoint에서 Linux Network Stack이 Routing 결정을 한다. 외부 Router가 Provider 사설 대역의 반환 경로를 모르면 Host가 SNAT 또는 Masquerade를 적용한다.

2. L2 Port와 L3 Endpoint

역할IP 필요하는 일
Bridge Port보통 없음MAC Table을 기준으로 Ethernet Frame을 전달한다.
Bridge 자체설계에 따라 다름순수 L2 Switch일 수도 있고 Host의 L3 Endpoint가 될 수도 있다.
Routed Interface있음자기 IP에 ARP 응답하고 Kernel Routing Table을 사용한다.
Router Port있음두 Subnet 사이의 L3 경계를 제공한다.

“Interface에는 항상 IP가 있다”는 전제가 틀리다. 어떤 Interface가 Switch Port처럼 Frame만 운반하면 IP가 없어도 정상이다.

3. veth pair는 Network Stack 사이를 잇는 가상 케이블이다

한쪽 끝으로 들어간 Ethernet Frame은 반대쪽 끝으로 나온다. 양쪽 모두 Linux Interface이므로 각각 Bridge Port, Namespace Port 또는 Host Endpoint가 될 수 있다.

OpenStack이 관리하는 Bridge Port  ══ veth pair ══  Host가 관리하는 Gateway Endpoint
IP 없음 · L2 전달                               IP 있음 · Routing 시작

이 분리는 OpenStack이 관리하는 Provider Bridge와 Host NAT 경계를 서로 다른 관리 대상으로 유지할 때 유용하다.

4. NAT는 veth가 아니라 Host의 Packet Filter에서 수행된다

veth는 Frame을 전달할 뿐 주소를 변환하지 않는다. Provider 사설 주소를 외부에서 되돌려 보낼 Route가 없으면, Host가 외부 NIC로 내보내기 전에 Source IP를 자기 주소로 바꾸고 연결 상태를 기억한다.

두 번의 변환을 구분한다.
Neutron Router가 Tenant fixed IP와 Floating IP를 매핑하는 것과, Host가 Provider 주소를 Upstream Network에 맞게 Masquerade하는 것은 서로 다른 경계의 NAT다.

5. Fixed IP와 Floating IP

주소범위역할
Fixed IPTenant NetworkVM Port가 계속 소유하는 내부 주소
Floating IPProvider Network외부에서 선택한 VM Port로 도달하도록 Router가 매핑하는 주소
Host GatewayProvider 경계Router가 Host Routing·NAT로 넘어가는 Next Hop

Floating IP는 VM NIC에 두 번째 주소를 직접 붙이는 것과 다르다. Router가 Provider 쪽 주소와 Tenant fixed IP의 변환 상태를 관리한다.

6. 경계별 검증 순서

  1. Port: Interface가 존재하고 UP인지, Bridge에 연결됐는지 확인한다.
  2. L2: ARP·MAC Learning과 Provider Segment의 연결을 확인한다.
  3. L3: Interface 주소, Prefix, Route와 IP Forwarding을 확인한다.
  4. NAT·Policy: Forward 허용과 변환 규칙, Security Group을 확인한다.
  5. End-to-end: Router Namespace, Host, VM 내부에서 각각 Ping·DNS·Application 요청을 확인한다.
