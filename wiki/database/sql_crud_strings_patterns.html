외부 SQL 문제에서 가져온 학습 조건

출처: HackerRank의 Weather Observation Station 계열 문제를 바탕으로, 공개 위키에는 문제 문장을 복제하지 않고 스키마와 SQL 학습 목표만 재구성한다.

  • 테이블: STATION
  • 열: ID, CITY, STATE, LAT_N, LONG_W
  • 목표: 도시 이름이 모음으로 시작하지 않는 행을 찾고, DISTINCT로 중복을 제거한다.
SELECT DISTINCT city
FROM station
WHERE city NOT RLIKE '^[aeiouAEIOU].*$';

이 표현은 MySQL 계열 예시다. 다른 DB에서는 정규식 연산자나 NOT LIKE 조합을 해당 문법에 맞게 바꾼다.

    last_worn  INT
);

# select * from shirts;

insert into shirts(article, color, shirt_size, last_worn)
values ('t-shirt', 'white', 'S', 10),
       ('t-shirt', 'green', 'S', 200),
       ('polo shirt', 'black', 'M', 10),
       ('tank top', 'blue', 'S', 50),
       ('t-shirt', 'pink', 'S', 0),
       ('polo shirt', 'red', 'M', 5),
       ('tank top', 'white', 'S', 200),
       ('tank top', 'blue', 'M', 15);

##### Add A New Shirt Purple polo shirt, size M last worn 50 days ago #####
insert into shirts (article, color, shirt_size, last_worn)
    value ('purple', 'polo shirt', 'm', 50);

# UPDATE shirts set shirt_size='M' where shirt_id=9;

##### SELECT all shirts But Only Print Out Article and Color #####
select article, color from shirts;

##### SELECT all medium shirts Print Out Everything But shirt_id #####
select article, color, shirt_size, last_worn from shirts where shirt_size='M';


##### Update all polo shirts Change their size to L #####
update shirts set shirt_size='L' where article = 'polo shirt';

##### Update the shirt last worn 15 days ago Change last_worn to 0 #####
update shirts set last_worn=0 where last_worn = 15;

##### Update all white shirts Change size to 'XS' and color to 'off white' #####
update shirts set shirt_size='XS', color='off white' where color = 'white';

##### Delete all old shirts Last worn 200 days ago #####
DELETE FROM shirts WHERE last_worn=200;

##### Delete all tank tops #####
delete FROM shirts where article = 'tank top';

##### Delete all shirts #####
delete From shirts;

##### Drop the entire shirts table Catastrophe Again! #####
drop table shirts;

편입 후 검증 메모

  • 원문 외부 화면: 강의·블로그·문제 사이트의 캡처는 공개 재배포하지 않았다. 캡처에만 있던 결과는 주변 SQL과 이 메모의 텍스트로 보존했다.
  • STATION 예제: 외부 문제의 핵심 스키마는 ID, CITY, STATE, LAT_N, LONG_W이며, 목표는 모음으로 시작하지 않는 도시명을 중복 없이 조회하는 것이다.
  • 패턴 문법: MySQL의 REGEXP/RLIKE, PostgreSQL의 ~/~* 등 정규식 연산자는 DB마다 다르다. 표준 LIKE만으로 가능한지부터 판단한다.
  • 문자열 결합: CONCAT, CONCAT_WS, ||의 지원과 NULL 처리도 DB별로 확인한다.
  • 변경 쿼리: UPDATE·DELETE 전 동일 WHERE 조건의 SELECT로 대상 행을 확인하고, 트랜잭션과 복구 경로를 준비한다. WHERE 없는 변경은 전체 행에 적용될 수 있다.
