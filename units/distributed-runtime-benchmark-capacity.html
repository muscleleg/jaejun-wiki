Benchmark·Capacity 측정 적용 심화

구체적인 서비스 조건에서 응답 시간 기준을 지키는 처리량과 과부하 경계를 측정한다.

짧은 제목 · 선택: Benchmark·Capacity

계획됨달성 기준 0 / 8
이 학습이 필요한 이유
측정법 자체는 이전 GPU 실습에서 배웠다. 새로운 환경의 용량 산정 또는 정책 비교라는 구체적 질문이 생길 때 적용한다.
완료 후 이어지는 일
Gateway·EPP 정책 비교와 Replica·TP·P/D Architecture Scaling 심화의 고정 부하 조건을 제공한다. 필수 통신 학습 경로는 이 실습을 기다리지 않는다.
학습 내용 자세히 보기

이미 배운 Closed-loop·Open-loop·SLO·Goodput 측정법을 새로운 환경에 적용해 서버 한 대의 여유·포화·과부하 기준을 만드는 선택 실습이다. Interconnect·Cross-node 학습의 필수 선수로 요구하지 않으며, 실제 용량 산정이나 Gateway·EPP 정책 비교가 필요할 때 수행한다.
