Single-node Benchmark와 Capacity Planning

짧은 제목 · Benchmark·Capacity

선수 대기완료 조건 0 / 28

학습 후 할 수 있는 일Replica·TP·P/D의 서로 다른 목적과 비용을 동일 GPU Budget에서 비교하고 Workload별 Capacity와 Goodput을 계산한다.

학습 안내

이 학습이 필요한 이유
각 Architecture의 정상 동작을 확인한 뒤 동일 모델·Workload·측정 경계에서 비교해야 선택 기준을 성능 수치와 연결할 수 있다.
완료 후 이어지는 일
선택한 Single-node Runtime 구성을 깨끗한 환경에서 E2E로 재현하고 적용 가능한 Capacity 범위를 제시할 수 있다.
