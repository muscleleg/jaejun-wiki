Cross-node NCCL·KV Transfer와 Network Transport

짧은 제목 · Cross-node Transport

선수 대기완료 조건 0 / 25

학습 후 할 수 있는 일Cross-node 환경의 실제 NIC·Network·NCCL Transport를 확인하고 해당 Transport로 NCCL과 KV Transfer의 Data Path와 성능을 검증한다.

학습 안내

이 학습이 필요한 이유
Single-node P/D 이후에는 노드 경계를 넘을 때 추가되는 Network 비용과 RDMA 제공 여부를 분리해 확인해야 한다.
완료 후 이어지는 일
TCP·RDMA 등 실제 Transport에 맞는 Cross-node 배치와 KV 전송의 적용 범위를 판단할 수 있다.

[런파드 - L4 x 2 (노드당 1장, 2노드)] 서로 다른 물리 노드와 실제 Network Transport를 확인하고 RDMA 제공 여부와 무관하게 사용 가능한 Transport로 NCCL과 KV Transfer를 검증한다.
