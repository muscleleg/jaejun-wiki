활성화 함수와 Gradient 흐름

활성화 함수의 입력·출력·미분과 여러 층을 지나는 Gradient 크기를 연결해 설명한다.

이 학습이 필요한 이유
Forward 값의 Shape과 Loss만 확인하면 Gradient가 앞단까지 전달되지 않는 학습 문제를 놓칠 수 있다.
완료 후 이어지는 일
학습 정체를 활성화·초기화·Gradient 관찰로 검토하고 정규화 계층의 역할과 한계를 비교할 수 있다.

nn.Module 다음에 작은 고정 입력·Target으로 Sigmoid·ReLU·LeakyReLU와 Gradient 전달을 확인한다. DataLoader 전체 학습 전에 Forward·Loss·Backward의 값과 계층별 Gradient를 비교하며 기존 작은 MLP 지식을 재사용한다.

○

Sigmoid·ReLU·LeakyReLU 값과 미분

미충족

양수·음수·0 근처 및 큰 절댓값 입력을 고정해 함수 출력과 미분을 예측하고 Autograd로 검증한다. ReLU의 음수 구간과 Sigmoid 포화 구간을 구분하며 LeakyReLU의 음수 기울기가 바꾸는 항을 설명한다.

○

여러 층의 Gradient 전달 관찰

미충족

같은 작은 입력·모델 깊이·가중치 조건에서 활성화만 바꿔 앞·뒤 계층의 Gradient를 측정한다. 연쇄법칙으로 곱해지는 중간 미분값과 관찰한 크기를 연결하고 입력·가중치·초기화 조건에 따른 한계를 명시한다.

○

기존 MLP의 학습 정체 진단

미충족

Loss와 함께 활성화 분포 및 계층별 Gradient의 0 비율·크기를 관찰하는 코드를 기존 작은 MLP에 적용한다. 고정 조건에서 활성화 하나를 바꿔 비교하고 기울기 소실·ReLU 비활성 구간·학습률 문제를 같은 현상으로 단정하지 않는다.
