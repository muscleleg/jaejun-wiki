이 학습이 필요한 이유
전이학습 방법과 이미지를 처리하는 모델 구조는 서로 다른 질문이므로 CNN에서 익힌 학습 방법을 유지하며 Token 기반 입력의 차이를 확인할 필요가 있다.

사전학습 CNN 전이학습 다음에 이미지를 Patch·Token으로 바꾸는 Vision Transformer의 구조를 별도 단원으로 확인한다. 기존 Transformer Block 지식을 재사용해 작은 Patch 계산과 사전학습 ViT 분류·복원을 연결한다.

Patch 분할·투영과 Token Shape 계산

미충족

작은 이미지 Tensor를 고정 Patch 크기로 나누어 Patch 수·펼친 특징 수를 계산한다. 같은 가중치로 선형 Patch 투영과 대응 구현을 검산하고 위치 표현·분류용 표현이 실제 모델의 어느 축에 연결되는지 확인한다.

○

CNN 계열과 ViT 입력 구조 비교

미충족

Convolution과 Residual의 역할, EfficientNet의 크기 조절 개요, ViT의 Patch·Token·Position·Attention 흐름을 기존 CNN과 Transformer 지식에 연결한다. 대표 CNN 하나와 작은 ViT 하나의 입력·중간·분류 출력 Shape을 확인한다.

○

ViT 전처리와 같은 데이터 분할 재사용

미충족

앞선 CNN 전이학습과 같은 데이터 분할·Label mapping을 재사용하며 선택한 ViT의 Weight·Revision·입력 크기·정규화·처리기를 기록한다. CNN의 변환을 그대로 적용해도 되는지 실제 요구 조건과 출력으로 판단한다.

○

ViT 전이학습과 모델 비교의 범위

미충족

작은 사전학습 ViT로 같은 분류 과제를 실행해 Patch 입력부터 클래스 Logit까지 연결한다. CNN과 비교할 때 사전학습 데이터·모델 크기·입력 해상도·학습 예산 차이를 명시하고 관찰 결과를 구조 하나의 효과로 일반화하지 않는다.

○

ViT 최종 평가와 이미지 한 장 복원

미충족

Validation에서 학습 설정을 선택한 뒤 Test를 평가하고 모델·분류 Head·처리기·Label mapping·설정을 함께 저장한다. 새 실행 상태에서 같은 이미지의 Logit과 Label을 복원하며 이미지 분류 출력과 언어 모델의 Vocabulary 출력을 구분한다.
