High-bandwidth GPU Interconnect와 Data Movement

짧은 제목 · GPU Interconnect

선수 대기완료 조건 0 / 14

학습 후 할 수 있는 일실제 할당 Topology와 Interconnect를 확인하고 확인된 GPU 간 Data Path에서 P2P와 NCCL Collective 성능을 검증한다.

학습 안내

이 학습이 필요한 이유
PCIe 환경의 TP 결과 이후 고속 GPU Interconnect가 제공되는지 먼저 판정해야 존재하지 않는 NVLink를 근거로 잘못 해석하지 않는다.
완료 후 이어지는 일
Topology가 다른 환경의 Collective 결과를 적용 범위와 교란 변수를 포함해 비교할 수 있다.
