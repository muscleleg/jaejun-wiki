학습 후 할 수 있는 일원본 문장을 Token ID Batch로 바꾸고 기준 모델과 PyTorch Embedding 분류 모델을 평가해 원본 문장 추론을 재현한다.

표 데이터와 이미지 다음으로 길이가 다른 Sequence 입력을 다루며 PyTorch 데이터 처리와 모델 입력 범위를 확장하기 위해 필요하다.

학습 내용 자세히 보기

문장을 모델 입력으로 바꾸는 과정과 길이가 다른 데이터를 Batch로 묶는 방법을 익히며 단어 기반 모델과 간단한 Embedding 모델을 비교한다.
