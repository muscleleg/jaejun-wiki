GraphRAG 비교

짧은 제목 · GraphRAG 비교

계획됨완료 조건 0 / 1

학습 후 할 수 있는 일같은 질문에서 Vector RAG와 GraphRAG의 근거·다단계 성공·지연·비용을 비교한다.

학습 안내

이 학습이 필요한 이유
Graph 연결이 늘어났다는 사실만으로 검색과 답변의 품질이 좋아진다고 볼 수 없다.
완료 후 이어지는 일
GraphRAG를 유지할 질문 범위와 추가 비용을 측정 근거로 선택할 수 있다.
학습 내용 자세히 보기

질문에서 필요한 Entity와 관계 경로를 찾아 Graph Context를 구성한다. 같은 질문 세트에서 Vector RAG와 GraphRAG의 검색 성공, 근거 적합성, 다단계 질문 성공과 지연·비용을 비교한다.
