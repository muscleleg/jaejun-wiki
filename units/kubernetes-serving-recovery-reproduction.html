핵심 질문: 저장된 자료만으로 전체 환경과 장애·복구를 재현할 수 있는가? 개념·실습 흐름 Model Server 장애·Endpoint 제외/복구와 Drain → Rolling Update → Rollback을 통합 실행한다. DRA 할당/반환과 Multi-node 그룹 정상/부족/복구를 재현한다. 실제로 통합하지 않은 경로는 별도 시나리오로 표시한다. 앞 통합 단원의 부하·관측 결과와 함께 Manifest·Dashboard·Log·Metric을 보존하고 다시 연다. 저장 자료만으로 환경을 재구성할 Runbook과 Kubernetes/Runtime·Synthetic/실제 하드웨어 책임 비교를 완성한다. 실험과 달성 기준 연결 Endpoint 장애·Drain·업데이트·Rollback은 달성 기준 1~2, 해결 문제·실제/Synthetic/성능 경계 설명은 3~6, 영구 저장·Runbook·재구성은 7~8, DRA·그룹 정상/부족/복구는 9, Kubernetes/Runtime 책임 비교는 10과 연결한다. 실행 조건과 검증 경계 앞 통합 실험과 같은 버전 고정 재현 패키지를 사용하며 재구성 후 전체 Dashboard·수집도 다시 확인한다. DRA와 그룹 경로를 실제로 통합하지 않았다면 별도 시나리오로 표시한다. 로드맵 종합 기준은 두 통합 학습 단원의 자료를 함께 검토하고 실제 Runtime 측정은 후속 로드맵에 남긴다.
