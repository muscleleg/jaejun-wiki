MLA 원리와 PyTorch 구현

MLA의 계산 흐름과 캐시 저장 구조를 GQA와 비교해 설명하고, 작은 PyTorch 구현에서 위치 정보·캐시 Decode·출력 일치·메모리 계산을 검증한다.

이 학습이 필요한 이유
GQA의 KV Head 공유와 RoPE의 위치 회전, 기존 KV Cache 동작을 확인한 다음에는 KV 정보를 공통 벡터로 압축하는 구조를 배워야 Attention 구조에 따라 계산과 저장 항목이 어떻게 달라지는지 이해할 수 있다.
완료 후 이어지는 일
MLA 모델의 설정과 실제 캐시를 읽어 메모리 요구량을 계산하고 이후 모델별 GPU 자원 분석에 적용할 수 있다.
학습 내용 자세히 보기

GQA·RoPE·KV Cache 학습 뒤 Multi-head Latent Attention(다중 헤드 잠재 어텐션)을 별도 학습한다. DeepSeek-V2의 낮은 차원 KV 공동 압축, Query·출력 투영과 확장 행렬의 결합, 내용 계산과 위치 정보의 분리, Prefill·캐시 Decode를 작은 PyTorch 예제로 연결한다. Tensor Shape과 실제 숫자를 예측하고 동일 가중치의 기준 경로와 캐시 경로의 출력 및 저장 용량을 검증한다. 필요한 행렬 차원·낮은 Rank의 의미는 이 예제에서 보충하며 전체 SVD 과정이나 대형 모델 실행을 필수로 요구하지 않는다.

MHA·GQA·MLA의 계산과 캐시 구조 비교

미충족

Multi-head Latent Attention(다중 헤드 잠재 어텐션)의 목적을 설명한다. 동일한 Batch·Token·Head 차원 예제에서 MHA의 Head별 K·V, GQA의 KV Head 공유, MLA의 낮은 차원 공통 벡터를 구분한다. 작은 행렬로 차원 축소와 확장을 계산하고 각 Tensor의 Shape 및 캐시에 저장하는 대상을 예측·검산한다.

○

KV 공동 압축과 투영 행렬 결합 구현

미충족

작은 PyTorch Tensor에서 Hidden State를 공통 KV 벡터로 축소하고 Head별 Key·Value로 확장하는 기준 구현을 작성한다. 위치 회전을 적용하지 않은 내용 계산에서 Key 확장 행렬을 Query 투영과, Value 확장 행렬을 출력 투영과 결합한다. 동일한 가중치와 입력으로 명시적 K·V 확장 경로와 결합 경로의 Attention 출력이 정한 수치 허용오차 안에서 일치하는지 확인한다.

○

위치 정보 분리와 MLA 캐시 구성

미충족

기존 RoPE를 내용 Key에 그대로 적용하면 위치별 회전이 투영 행렬 결합을 방해하는 이유를 작은 행렬 계산으로 확인한다. 내용 계산과 위치 회전용 Query·공유 Key를 분리하는 DeepSeek-V2 방식의 decoupled RoPE를 구현하고, 공통 KV 벡터와 위치 회전용 Key가 함께 캐시에 저장되는 Shape을 확인한다.

○

MLA 전체 Forward와 캐시 Decode의 출력 검증

미충족

동일한 작은 MLA 모델·가중치·입력·위치와 Causal Mask에서 전체 문맥을 다시 계산하는 경로와 Prefill 뒤 새 Token만 처리하는 캐시 경로를 구현한다. 캐시 길이 증가를 확인하고 같은 Token 위치의 Attention 출력과 작은 LM Head Logit을 비교한다. NaN·inf 여부, 최대 절댓값 차이와 dtype에 맞는 atol·rtol, Greedy Token 일치를 기록하며 구현 경로의 일치와 학습된 모델의 품질 평가는 구분한다. CPU에서 가능한 작은 예제로 먼저 검증한다.

○

MLA 캐시 용량 계산과 실제 Tensor 대조

미충족

Batch·Token 수·Layer 수·자료형을 고정하고 공통 KV 차원과 위치 Key 차원에서 캐시 원소 수·Byte를 계산해 실제 Tensor의 numel·element_size 합과 대조한다. 비교용으로 명시한 MHA·GQA 차원을 각각 대입해 저장량 차이를 계산한다. 캐시 Tensor 용량과 GPU 전체 VRAM을 구분하고 저장량 감소만으로 실행 속도나 모델 품질의 향상을 단정하지 않는다.
