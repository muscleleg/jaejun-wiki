완료 후 이어지는 일
제한 시간의 낯선 문제에서도 패턴을 선택·변형하고 실패를 개선할 수 있다.
학습 내용 자세히 보기

이미 배운 범위부터 유형을 공개하지 않은 미풀이 1문제·30~40분 연습을 기존 경로와 병행한다. 문자열 파싱·다중 정렬·격자 시뮬레이션을 보강하고 핵심 패턴별 미풀이 변형 문제의 독립 적용을 확인한다. 새 개념은 먼저 설명하고 대표 문제를 학습한 뒤 평가한다. 주요 패턴 학습과 재구현을 마치면 미풀이 공식 문제로 구성한 3문제·120분 세트에서 2문제 이상 완전 통과를 3세트 연속 달성한다. 세트의 난이도·유형 분산과 문제 선택·전환·검산 시간을 검증하고 실패를 보완하여 미해결 문제를 자료 없이 다시 푼다. 짧은 연습은 지금부터 시작할 수 있으며 최종 종합 검증은 경로 마지막에 둔다.

유형 비공개 혼합 문제 적용

미충족

3문제 중 2문제 이상을 완전히 통과하는 결과를 세 세트 연속 만들고, 실패 지점을 분류해 보완한 뒤 각 미해결 문제도 이전 코드를 보지 않고 다시 풀면 핵심 여정이 완료됩니다. 이 기준은 특정 기업의 공식 합격선이 아닌 내부 훈련 기준입니다.

○

코딩 테스트 문제 해결 흐름 연결 검증

미충족

유형을 미리 밝히지 않은 3문제·120분 세트에서 풀이 전략을 선택·구현·검증하여 2문제 이상 완전 통과를 세 세트 연속 만들고, 실패를 분류·보완한 뒤 미해결 문제를 이전 코드 없이 다시 푼다. 선택한 전략과 반례, 실패 원인 및 시간·공간 복잡도를 함께 설명한다.

○

문자열·정렬 조건·격자 시뮬레이션

미충족

문자열 파싱, 동률을 포함한 다중 정렬 조건, 격자 이동과 상태 갱신을 각각 포함하는 대표 문제를 학습·구현·검증한다. 한 문제에 여러 요소가 있으면 결과를 재사용한다. 코드 전에 입력 좌표와 배열 인덱스, 저장 상태, 갱신 시점, 경계·예외를 설명하고 제출 결과와 복잡도를 확인한다.

○

핵심 패턴의 처음 보는 문제 적용

미충족

대표 문제 학습 뒤 미풀이 변형 문제를 유형명·풀이 힌트 없이 풀고 제약으로부터 전략을 고른 이유, 반례와 복잡도를 설명한다. 해시·정렬, 스택·큐·힙, 완전탐색·그리디, DFS·BFS, 이분탐색, DP, 구간 탐색·백트래킹, 그래프 확장 각 묶음을 최소 한 번 검증한다. 하나의 문제에 실제로 사용한 여러 패턴은 근거를 공유할 수 있다. 이미 배운 범위부터 1문제 30~40분의 짧은 연습을 병행하고 새 묶음을 배울 때 확장한다. 시간 초과·힌트 사용은 부분 근거로 기록하고 보강 후 다른 미풀이 문제로 독립 적용을 확인한다. 최종 혼합 세트의 적합한 결과를 재사용한다.

○

실전 세트 구성과 시간 운영

미충족

기존 3문제·120분, 2문제 이상 완전 통과를 3세트 연속 달성하는 기준에 사용되는 문제는 모두 처음 보는 공식 문제로 선정한다. 각 세트는 구현·문자열/해시·정렬 1문제, 자료구조·탐색 1문제, DP·그래프·이분탐색·구간 중 1문제로 분산하되 유형은 응시자에게 공개하지 않는다. 기본 목표 난이도는 프로그래머스 Lv.2 중심에 Lv.3 도전 문제를 세트당 최대 1개로 두고 실제 수준과 목표 시험에 맞춘 선정 근거를 시작 전에 기록한다. 풀이 중 해설·정답 코드·코치 힌트를 사용하지 않고 문제 선택·전환·검산에 쓴 시간을 기록한다. 실패는 조건 해석·전략 선택·구현·시간 관리로 분류하고 기존 기준대로 미해결 문제를 자료 없이 다시 푼다. 연습·복습 결과를 미풀이 시험 성적으로 중복 집계하지 않는다. 이 기준은 내부 훈련 기준이다.

목표 문맥별 선택 이유

AI 엔지니어 역량에서 선택한 이유

핵심 종착점은 PyTorch로 이해한 추론 흐름을 vLLM과 Multi-GPU 환경까지 확장하고, 성능 차이를 재현 가능한 수치와 병목 근거로 설명하는 것입니다.

이 목표의 학습 경로에는 이 유닛이 선택되지 않았습니다.

코딩 테스트 문제 해결 역량에서 선택한 이유

핵심 종착점은 학습한 패턴의 코드를 그대로 암기하는 것이 아니라 유형 이름을 미리 보지 않은 문제에서도 제약을 읽고 사용할 패턴을 선택·변형해, 3문제·120분 기본 세트에서 구현·검증하고 실패 원인과 시간·공간 복잡도를 설명하며 다시 풀 수 있는 상태입니다.

  1. 경로 10 · 핵심 패턴의 첫 학습과 자료 없는 재구현을 모아 유형 비공개 3문제·120분 세트에 적용하고, 전략 선택·반례·실패·복잡도 설명과 재풀이로 목표 역량을 검증한다.
