Kubernetes Flow Control

짧은 제목 · Flow Control

선수 대기완료 조건 0 / 14

학습 후 할 수 있는 일Kubernetes Serving Control Plane에서 Overload 요청의 Routing·Admission·Queue·Cancellation·Retry 상태 전이를 관찰한다.

학습 안내

이 학습이 필요한 이유
Endpoint 선택만으로 과부하를 제어할 수 없으므로 요청 수용과 대기·거절 정책을 별도의 운영 책임으로 확인해야 한다.
완료 후 이어지는 일
Queue와 Request Metric을 Autoscaling 입력으로 연결하고 Scale-out Lag를 분석할 수 있다.
