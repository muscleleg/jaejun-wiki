새로운 조합의 사전 예측과 검증

모델에서 적절한 GPU를 고르고 GPU에서 사용할 모델과 실행 조건을 정하는 양방향 판단을 독립적으로 수행한다.

이 학습이 필요한 이유
이전에 측정한 결과를 반복하는 것을 넘어 새로운 조합을 사전에 판단할 수 있어야 GPU와 모델 선정 역량을 확인할 수 있다.
완료 후 이어지는 일
새로운 모델이나 GPU를 접했을 때 정보 수집·자원 계산·후보 선정·실측 검증을 하나의 절차로 수행할 수 있다.
학습 내용 자세히 보기

앞선 실험에서 직접 측정하지 않은 모델·GPU 조합에 대해 계산 노트북과 선정 보고서를 만든다. 모델과 사용 요구가 주어진 과제에서는 GPU 후보를 고르고, GPU와 사용 요구가 주어진 과제에서는 모델·정밀도·문맥·동시 요청 수의 범위를 제안한다. 예측과 가정을 먼저 보존한 뒤 RunPod로 검증하고, 메모리 수용·요구 성능·비용·미확인 범위를 함께 결론 낸다.

모델과 사용 요구에서 GPU 선정

미충족

모델·정밀도·문맥·입출력 길이·동시 요청·요구 응답 성능·예산이 주어진 상황에서 GPU 후보를 비교하고 하나를 선정한다. 메모리 예산·예상 병목·성능 범위·작업당 비용·선정 근거를 실행 전에 남기고 RunPod 실측으로 요구 충족 여부를 검증한다.

○

GPU와 사용 요구에서 모델·조건 선정

미충족

지정 GPU에서 사용할 수 있는 복수 모델 후보와 정밀도·문맥 길이·동시 요청 범위를 제안한다. 메모리에 들어가는 조건과 목표 속도를 만족하는 조건을 구분하고 대표 조합 및 한계에 가까운 조건을 측정해 권장 범위와 미확인 범위를 제시한다.

○

새 조합의 예측 오차와 적용 범위 설명

미충족

최종 과제에는 직접 측정하지 않았던 모델·GPU 조합을 포함한다. 사전 예측과 결과의 차이를 수치로 비교하고 계산 노트북·측정 원본·재현 조건을 남긴다. 보정에 사용한 결과와 별도 검증 결과를 구분하며 예측이 잘 맞는 조건과 추가 실측이 필요한 조건을 설명한다.
