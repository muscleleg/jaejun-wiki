    `head_dim=2`인 한 Score를 `Score=A+B`로 두고, `(A+B)²=A²+2AB+B²`를 여러 Score에 걸쳐 평균내는 과정을 따라갔다. 평균 0·분산 1·독립이라는 전제에서는 `A²`와 `B²`의 평균이 각각 1이고 `AB`의 평균이 0에 가까워져 Score 분산이 2, 표준편차가 `√2`가 된다는 점을 확인했다. `Score=[2,0,0,-2]`에서 Score 평균의 제곱은 0이지만, 각 Score를 먼저 제곱한 값은 `[4,0,0,4]`이고 그 평균은 2다. Score 평균이 0일 때 분산 공식의 `(Score-평균)²`가 `Score²`가 되므로 Score 제곱의 평균 2가 곧 분산이고, 표준편차는 `√2`가 된다는 중간 단계를 명확히 연결했다. 모든 원소가 같은 방향이거나 서로 강하게 연관된 경우에도 항상 `√head_dim`이 나오는 것은 아니다. 각 Score 하나의 값이 반드시 커진다는 뜻도 아니며, 평균 0에 가까운 독립적인 곱을 여러 개 합산한 Score 집단의 전체적인 퍼짐이 커진다는 통계적 분석임을 구분했다. Q·K·V Projection부터 Head 분리, Score·Scaling·Softmax, Value 가중합, Token 기준 재정렬, `d_model` 병합과 Output Projection `W_O`까지 하나의 `nn.Module.forward()`로 연결했다. 최종 `projected_output`의 Shape이 `[batch,token,d_model]=[1,2,2]`로 유지되는 것을 실행 결과로 확인했다. `[1,2,3,1]` Tensor에서 Head A의 `[0,1,2]`와 Head B의 `[3,4,5]`가 `transpose(1,2)` 뒤 Token별 `[[0,3],[1,4],[2,5]]` 묶음으로 바뀔 것을 먼저 주석으로 예측했다. 실제 Shape `[1,3,2,1]`과 값이 예상과 일치했다. Residual은 Attention 결과로 원래 입력을 교체하는 것이 아니라, `x + projected_output`으로 원본 Token 정보에 Attention이 알아낸 정보를 더하는 연결이라고 이해했다. 실제 결과 `[[[0.9800,0.0252],[-0.0737,1.0376]]]`와 Shape `[1,2,2]` 유지를 확인했다. Multi-Head Attention 클래스의 입력 `[batch,token,d_model]`에서 Batch가 여러 시퀀스를 담되 서로 섞이지 않고 독립적으로 Attention 계산된다는 점도 복습했다.
