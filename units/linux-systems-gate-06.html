장애 진단 결과물

짧은 제목 · 장애 진단 결과물

계획됨완료 조건 0 / 1

학습 후 할 수 있는 일선택한 Linux 장애를 재현하고 관련 자원 관찰로 원인·수정·재검증을 설명한다.

학습 안내

이 학습이 필요한 이유
명령 출력 수집만으로는 원인이 입증되지 않으므로 가설을 반증하고 수정 효과를 확인해야 한다.
완료 후 이어지는 일
현상과 원인, 복구 근거가 연결된 진단 결과물을 남길 수 있다.
학습 내용 자세히 보기

느린 API, Memory 증가, File Descriptor 고갈 또는 Container OOM 중 하나를 재현한다. 현상 → 가설 → 관찰 명령 → 반증 → 원인 → 수정 → 재검증 순서의 공개 가능한 진단 기록을 만든다. 이 Unit의 종합 활동에서는 느린 API·Memory 증가·File Descriptor 고갈·Container OOM 중 선택한 장애를 재현하고, 그 장애와 관련된 Process·Memory·Filesystem·I/O·Namespace·cgroup의 관찰 근거로 현상·가설·반증·원인·수정·재검증을 설명한다.
