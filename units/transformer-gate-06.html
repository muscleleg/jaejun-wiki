    `[[3,7,2,9],[4,1,6,8]]`에서 `tokens[:, :-1]`을 모든 행의 마지막 열 전까지, `tokens[:, 1:]`을 모든 행의 두 번째 열부터 끝까지로 해석했다. 입력 `[[3,7,2],[4,1,6]]`과 Target `[[7,2,9],[1,6,8]]`의 Shape이 모두 `[2,3]`임을 실행 결과로 확인했다. 모델 Logit `[B,T,V]=[1,3,10]`을 `[3,10]`으로 펼친 값은 위치별 Vocabulary 후보 점수이고, Target `[1,3]`을 `[3]`으로 펼친 값은 각 위치에서 채점할 Token ID라고 구분했다. 세 Prefix의 Logit을 한 Forward에서 병렬 계산하고 세 Token Loss의 평균으로 한 번에 역전파하는 구조를 설명했다. `d_model=2` 모델은 300번 학습해도 Loss 약 `0.462`와 예측 `[9,2,9]`에서 정체됐고, `d_model=4`·`d_ff=16`으로 넓혀 새로 초기화한 모델은 Loss `0.001` 미만과 동일 생성 결과를 재현했다. 차원 변경과 재초기화가 함께 일어났으므로 원인을 LayerNorm 하나로 단정하지 않았다. 잘못된 입력·Target 조합으로 Loss만 낮아진 실패를 추적해 입력 `[3,7,2]`과 Target `[7,2,9]`을 같은 셀에 다시 선언했다. `logits[:, -1, :]`에서 `argmax(dim=-1, keepdim=True)`로 다음 Token ID를 골라 입력 뒤에 붙였고, 실제 생성이 `[3] → [3,7] → [3,7,2] → [3,7,2,9]`로 이어지는 것을 확인했다. Target shift·Causal Mask·Cross Entropy·Optimizer 학습과 Autoregressive Generation을 Tiny Decoder LM 안에서 연결했다.
