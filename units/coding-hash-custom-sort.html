짧은 제목 · 해시·정렬

계획됨완료 조건 0 / 2

학습 후 할 수 있는 일해시의 조회·집계와 사용자 정의 정렬 기준을 구현하고 복잡도와 반례를 설명한다.

학습 안내

이 학습이 필요한 이유
Python 도구를 사용할 줄 아는 것과 문제의 상태를 Key·Value 또는 비교 규칙으로 모델링하는 것은 별도 능력이다.
완료 후 이어지는 일
문자열·빈도·그룹화·다중 정렬 문제가 섞인 미풀이 문제에서 자료구조와 정렬 기준을 선택할 수 있다.
학습 내용 자세히 보기

프로그래머스 의상에서 Key별 빈도와 조합을, 가장 큰 수에서 단순 수치 정렬과 다른 비교 기준을 다룹니다. 조회·그룹화·중복 처리와 정렬 Key·비교 규칙을 입력 제약에서 선택합니다.
