학습 내용 자세히 보기

Tool Calling(도구 호출)에서 모델이 생성하는 도구 이름·인자 요청과 프로그램이 수행하는 실행을 구분한다. 역할이 겹치지 않는 도구와 입력·출력 계약을 정의하고 요청 검증·실행·결과 반환·최종 응답을 연결한다. 조회·계산 같은 작은 도구로 시작하며 RAG 구현은 이 학습 단원의 선수 조건이 아니다.

모델 요청과 코드 실행 구분

미충족

도구 설명·입력 스키마·실행 함수·반환 결과를 각각 가리키고 모델이 만든 인자와 프로그램이 검증·실행하는 책임을 설명한다. 용도가 다른 작은 도구를 정의하고 선택 기준을 설명한다.

○

호출 요청부터 최종 응답까지 추적

미충족

모델 호출 요청 → 도구 이름·인자 검증 → 실행 함수 → 호출 ID에 맞춘 결과 반환 → 다음 모델 응답을 직접 연결한다. 실제 인자·도구 출력·사용자 응답을 로그에서 확인하고 결과를 꾸며 보고하지 않는지 검증한다.

○

잘못된 요청과 실행 실패 처리

미충족

알 수 없는 도구 이름, 잘못된 자료형 또는 필수 인자 누락, 실행 함수 실패를 재현한다. 실행 전 거절과 실행 후 오류 반환을 구분하고 기대 처리와 실제 로그·응답을 비교한다.
