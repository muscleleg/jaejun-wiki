SGD·Momentum·NAG 업데이트 비교

미충족

같은 초기 파라미터·학습률·미리 정한 Gradient 순서로 여러 Step을 계산한다. Momentum의 누적 상태가 다음 수정량에 들어가는 과정을 보여 주고, NAG가 Gradient를 평가하는 위치와 PyTorch 구현의 규약을 구분해 출력과 대조한다.

○

AdaGrad·RMSProp의 Gradient 제곱 누적

미충족

두 파라미터에 서로 다른 크기의 Gradient 순서를 주고 AdaGrad의 제곱합과 RMSProp의 지수 이동평균이 각 분모와 업데이트에 들어가는 값을 계산한다. 작은 상수 epsilon의 역할을 설명하고 PyTorch의 대응 상태와 비교한다.

○

Adam의 두 이동평균과 편향 보정

미충족

이동평균의 의미를 먼저 설명한 뒤 같은 Gradient 순서에서 Adam의 Gradient 이동평균·제곱 이동평균·초기 편향 보정과 최종 수정량을 순서대로 계산한다. torch.optim.Adam의 상태와 파라미터 값을 정한 허용오차로 검증한다.

○

기존 MLP에서 Optimizer 변경 비교

미충족

기존 회원 이탈 MLP의 분할·전처리·초기 가중치·Batch 순서·학습 예산·평가 지표를 고정해 SGD와 Adam을 비교한다. Optimizer별 학습률 선택을 명시하고 같은 학습률에서의 차이와 같은 탐색 예산에서의 선택을 구분한다. Train·Validation 곡선과 Accuracy·Recall을 읽고 단일 실행으로 보편적 우열을 주장하지 않는다.
