학습 내용 자세히 보기

Bootloader 이후 Kernel 초기화와 User Space의 init·service 시작을 이해하고 System Call·Interrupt·Scheduling·Context Switching으로 실행 경계를 연결합니다. 실행 중인 서비스의 Process Tree·부모와 자식·Thread·File Descriptor·Environment·Signal·종료 코드를 관찰합니다. Process·Thread·Coroutine과 User/Kernel Mode를 구분하고 Race Condition·Deadlock을 재현해 Lock 전후 및 Process·Thread·Async 선택 근거를 확인합니다. DataLoader Worker·Model Worker·비동기 CUDA·동시 추론 요청에 적용합니다. Boot·프로세스 관찰·동시성의 기존 기준은 유지하되 같은 프로그램과 관찰 기록을 이어서 사용합니다.
