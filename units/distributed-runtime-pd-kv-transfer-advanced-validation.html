요청별 상세 구간 Trace 검증

미충족

요청별 Queue·Prefill 계산·KV 수신·Decode 계산 구간을 Trace로 분리하고 중첩과 대기 원인을 확인한다. HTTP 구간 및 NIXL 누적 메트릭만으로 독립 계산 시간을 확정하지 않는다.

부분 충족

확인한 내용

  • 실제 GPU 3장·토폴로지와 vLLM·CUDA·NCCL 환경 정보를 노트북과 재현 문서에 보존했다.

남은 내용

  • CPU·호스트 RAM·Driver를 포함한 전체 환경 항목을 이 근거만으로 모두 기록했다고 판정하지 않는다.

관련 학습 기록

  • RTX PRO 4000 Blackwell 3장 한 호스트에서 Qwen3-8B 고정 Revision(b968826d9c46dd6066d109eabc6255188de91218), 각…

    RTX PRO 4000 Blackwell 3장 한 호스트에서 Qwen3-8B 고정 Revision(b968826d9c46dd6066d109eabc6255188de91218), 각 서버 TP=1·BF16, vLLM 0.29.0·NIXL 1.3.2로 P/D와 독립 서버를 비교했다. A/GPU0는 kv_producer, B/GPU1은 kv_consumer, C/GPU2는 kv_both로 구성했고 일반 요청에서는 각 서버가 Prefill과 Decode를 모두 수행함을 확인했다. A→B, C→B, A→C의 KV 전달과 1P1D·2P1D·1P2D 실행을 확인했다. 요청 조정 코드가 Prefill에 원래 입력을 보내 받은 KV 메타데이터를 같은 입력·원래 생성 조건과 함께 Decode에 넘겼다. remote_host/port는 KV 제공 측 위치이며 HTTP 응답은 KV 텐서 자체가 아니다. Decode가 NIXL Pull을 시작해 제공 측 KV를 받는다. 일반 서비스 프록시의 두 내부 요청 역할과 실제 수동 조정 코드를 구분했다. Connector·NIXL·UCX backend·물리 경로의 책임을 구분했고 UCX/CUDA 버퍼와 토폴로지는 확인했으나 실제 전송 경로는 특정하지 않았다. 입력 673토큰에서 수신 전송 +1건·96.75 MiB·외부 KV 입력 +673토큰·실패 0건을 확인했다. 36레이어×8 KV Head×128차원×K/V 2×BF16 2bytes로 토큰당 144KiB, 논리 KV 94.64MiB를 계산했다. 16토큰 블록 43개(688슬롯) 전송이라 96.75MiB가 되며 차이는 빈 슬롯 15개다. 입력 128/673/2048에서 건당 전달량 18/96.75/288MiB, NIXL 평균 67.8/347.9/1044.5ms로 증가했다. 전송 시간 합계와 벽시계, Decode HTTP와 KV 수신의 중복, 수신 서버별 증가량을 합한 가중 평균을 구분했다. 길이·동시성·GPU 수를 맞추고 예열을 제외해 재측정했다. 동시 16·총 80·입력 673·출력 32에서 2P1D는 E2E 3.099초·4.94요청/초·KV 1625.3ms, 1P2D는 5.824초·2.68요청/초·KV 4372.8ms였다. 반복에서도 차이가 유지됐지만 경합 장치는 미확인이다. 별도 동일 자원 비교에서 독립 3개는 E2E 1.579초·9.89요청/초, 2P1D는 3.263초·4.57요청/초로 이 조건에서는 독립 서버가 유리했다. 별도 스트리밍에서 독립 3개와 2P1D의 TTFT는 303.0/2260.9ms, TPOT 추정은 41.0/32.1ms였다. 생성 중 간격 개선을 전체 응답 개선이나 Prefill 간섭 제거의 단독 증거로 해석하지 않았다. 잘못된 엔진 ID 한 개를 넣은 요청은 연결 준비의 engine ID mismatch 및 fail 정책으로 HTTP500을 반환했고 Health는 200이었다. 실패 콜백의 IndexError도 남겼다. 이후 새 정상 P/D 요청은 1.359초·출력32·length로 성공했다. 자동 재시도나 모든 장애 복구를 검증한 것은 아니다. 단독과 P/D 답변의 후반 차이를 관찰했지만 최초 불일치 Token·Logit/KV 수치 동등성·품질 원인은 검증하지 않았다. 원본 노트북·명령·설정·로그·JSON은 커밋 698ef27c884be49c11139955e200fd0bfa30777d에 보존하고 확인 후 GPU를 반납했다. 보존 결과로 14개 문서와 요청 흐름·상태·구성·측정 경계·블록 도식을 정리했다. 문서 정리는 GPU 재측정이 아니다. 이번 GPU는 A40이 아니라 RTX PRO 4000 Blackwell이며 기존 로드맵의 A40 조건과 구분한다. Chunked Prefill 대비, MHA/GQA 정량 비교, 전송 유효 처리량 계산, 전 구성 Queue·TTFT·TPOT 직접 비교는 이 활동에서 완료 근거로 기록하지 않는다.

남은 내용
