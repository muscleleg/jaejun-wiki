PyTorch Profiler 등으로 계산이 실행되는 순서와 시간을 관찰하고, 환경이 지원하면 Nsight 도구로 필요한 메모리·연산 지표를 확인한다. Attention, 가중치 행렬 계산, 정규화·샘플링과 CPU 측 처리 비용을 연결한다. 저장 용량과 실제 메모리 이동량, GPU 사용률과 대역폭 활용률을 구분한다. 원인 가설 하나를 선택해 통제된 추가 실험으로 검증한다.
