임베딩·키워드·벡터 검색

검색 점수·반환 구간을 확인하며 질문에 필요한 근거를 찾는 검색 기준선을 만든다.

이 학습이 필요한 이유
벡터 저장소를 연결한 사실과 필요한 근거가 검색된 사실을 구분해야 답변 오류의 원인을 찾을 수 있다.
완료 후 이어지는 일
검색 결과를 답변 문맥으로 구성하고 검색 방식 변경의 이득을 평가할 수 있다.
학습 내용 자세히 보기

문서와 질문을 검색용 수치 벡터로 바꾸는 임베딩의 역할, 벡터 차원·유사도와 상위 검색 결과 선택을 이해한다. 같은 문서·질문에서 키워드 검색과 벡터 검색을 직접 비교한다. 검색 후보를 합치는 혼합 검색이나 후보를 다시 정렬하는 방법은 관찰한 실패에 맞춰 검토한다.

임베딩과 검색 점수의 의미 설명

미충족

문서·질문 임베딩의 입력·차원·사용 모델을 확인하고 같은 검색 공간을 사용해야 하는 이유를 설명한다. 선택한 유사도 계산의 의미를 작은 벡터 예 또는 실제 점수와 연결하고 유사도 점수가 정답 확률은 아님을 설명한다.

○

동일 자료의 키워드·벡터 검색 구현

미충족

같은 문서 집합과 질문에 대해 키워드 검색과 벡터 검색을 실행하고 반환 청크 ID·출처·점수·검색 개수를 기록한다. 미리 지정한 예상 근거가 어느 위치에 있는지 확인한다.

○

검색 방식별 성공·실패 비교

미충족

고유 명칭·숫자 또는 의미를 바꿔 표현한 질문을 포함해 두 검색 결과를 비교한다. 실패 사례 하나의 원인을 분석하고 검색 개수나 검색 방식 한 가지를 바꿔 같은 질문으로 다시 확인한다. 혼합 검색·재정렬을 택했다면 추가 비용과 선택 이유도 설명한다.
