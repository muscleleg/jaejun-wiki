모델의 메모리 요구량 계산

모델 구조와 실행 조건에서 필요한 메모리의 항목별 근거를 제시하고 GPU 메모리에 수용 가능한지 예상한다.

이 학습이 필요한 이유
가중치 파일 크기만으로 GPU를 고르면 KV 캐시와 실행 중 추가 공간을 빠뜨릴 수 있으므로 전체 요구량을 분해해야 한다.
완료 후 이어지는 일
GPU 후보를 용량 기준으로 걸러내고 문맥·배치·정밀도 변경의 영향을 계산할 수 있다.
학습 내용 자세히 보기

Qwen/Qwen3-4B를 기준으로 config와 가중치 Tensor 모양을 읽는다. 행렬·층·Attention Head·KV Head가 가리키는 대상을 작은 예제로 확인하고, 전체 파라미터와 공유된 가중치의 중복 계산을 점검한다. BF16 가중치 용량과 문맥·배치에 따른 KV 캐시 용량을 구한다. 중간 계산 결과, 임시 작업 공간, 실행기 예약 메모리와 GPU 전체 사용량을 구분해 메모리 예산표를 만든다.
