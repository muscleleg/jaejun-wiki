Encoder–Decoder Seq2Seq

입력열과 출력열의 Batch를 구성하고 RNN 계열 Encoder–Decoder의 학습과 자기회귀 생성을 재현한다.

이 학습이 필요한 이유
입력 수열의 마지막 상태가 다음 수열의 생성에 어떻게 연결되는지 알아야 입력·출력 길이가 다른 문제와 학습·추론의 차이를 이해할 수 있다.

작은 문자열 변환 문제에서 Encoder가 입력열을 읽고 Decoder가 출력열을 생성하는 구조를 만든다. 기존 Embedding·Cross Entropy 지식을 재사용하며 Teacher Forcing과 실제 생성 입력의 차이를 확인한다.

○

입력열·출력열과 길이가 다른 Batch 구성

미충족

작은 기호열 변환 과제의 입력·정답을 정의하고 Token ID·시작/종료 Token·Padding·유효 길이를 구성한다. 입력과 출력의 길이가 다를 수 있음을 Shape으로 확인하고 기존 Embedding 지식을 적용한다.

○

Encoder 상태에서 Decoder 초기 상태로 연결

미충족

RNN 또는 GRU Encoder의 마지막 상태를 Decoder 초기 상태로 전달하는 기준 구현을 작성한다. 입력 전체를 읽는 단계와 출력 Token을 한 개씩 만드는 단계의 입력·상태·Logit Shape을 추적한다.

○

Teacher Forcing과 Token Loss 계산

미충족

학습 중 이전 정답 Token을 다음 Decoder 입력으로 주는 과정을 Target shift로 구성한다. 위치별 raw Logit과 정답 ID를 Cross Entropy에 연결하고 Padding Target의 Loss 제외를 실제 값으로 검증한다.

○

정답 없이 순차 생성과 한계 확인

미충족

학습된 작은 모델에 시작 Token을 주고 이전 예측을 다음 입력으로 사용해 종료 Token 또는 최대 길이까지 생성한다. Teacher Forcing 학습 입력과 생성 입력의 차이, 입력 길이에 따른 실패 사례를 출력으로 설명한다.
