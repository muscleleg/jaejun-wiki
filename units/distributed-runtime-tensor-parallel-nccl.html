Tensor Parallel과 NCCL Collective

Column·Row 분할과 AllReduce·AllGather의 역할을 설명하고, 두 GPU 실습으로 TP=1·2의 성능·메모리 변화를 해석하며 수치 차이와 검증 한계를 구분할 수 있다.

A40 두 장에서 TP=1·2를 비교하며 하나의 모델을 여러 GPU에 분담하는 계산·통신·메모리 구조를 이해한다. 작은 Collective·행렬·Attention 검증과 설치된 vLLM 소스 확인을 실제 응답 성능·모델 및 KV 메모리 관측에 연결한다. 실제 추론의 통신 횟수·총시간과 모델 출력 동등성을 별도 측정하지 않았다는 경계를 설명한다. TP=4, 정밀 프로파일링, 통제된 Worker 실패, Engine·Executor 전체 경로와 KV 스케줄링 구현 추적은 이 단원의 필수 완료 범위가 아닌 후속 심화 주제다.
