정규화 축과 학습 가능한 보정값 계산

미충족

작은 Batch·Feature Tensor에서 평균·분산·epsilon·gamma·beta를 사용해 BatchNorm1d 출력을 계산한다. 같은 Tensor의 LayerNorm과 비교해 어떤 원소끼리 통계를 공유하는지와 Shape을 설명하고 PyTorch Forward 결과로 검산한다.

○

훈련·평가 통계와 상태 관찰

미충족

서로 다른 작은 Batch를 train 모드에 통과시켜 running_mean·running_var 변화를 확인하고 eval에서 사용하는 통계를 구분한다. Forward 분산과 running_var 갱신에 쓰이는 분산 추정 규약을 실제 문서·출력으로 확인하며 BatchNorm의 momentum과 Optimizer Momentum을 구분한다.

○

MLP 적용·평가·저장 복원 비교

미충족

기존 MLP에 BatchNorm을 적용해 train·eval과 no_grad의 역할을 설명하고 같은 입력의 평가 출력을 확인한다. 학습 파라미터와 running statistics가 포함된 state_dict를 저장·복원해 출력을 재현하고 Batch 크기와 효과의 한계를 기록한다.
