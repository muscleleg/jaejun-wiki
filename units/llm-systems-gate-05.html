짧은 제목 · TP·NCCL

학습 후 할 수 있는 일Collective 연산을 검산하고 동일 계약의 PyTorch·vLLM·Multi-GPU 결과에서 계산·메모리·통신 병목과 Scaling 차이를 설명한다.

이 학습이 필요한 이유
GPU 수 증가가 처리량 증가를 보장하지 않으므로 단일 GPU 기준선과 Topology를 함께 비교해야 한다.
완료 후 이어지는 일
측정 근거로 Tensor Parallel의 이득과 한계를 판단하고 Prefill·Decode 분리 필요성을 검토할 수 있다.
학습 내용 자세히 보기

입력 단일 GPU에서 재현된 vLLM·Benchmark Baseline과 GPU Topology 정보를 사용한다. 작은 Tensor로 AllReduce·AllGather·ReduceScatter의 입출력 Shape·값·통신 Byte를 먼저 검산합니다. 이어 Tensor Parallel 1·2·4 GPU를 같은 조건에서 실행하고 GPU 수가 늘 때 연산과 통신이 어떻게 나뉘는지 확인하며, nvidia-smi topo -m·nccl-tests·NVLink·PCIe를 실제 Scaling 결과에 연결합니다. 이 Unit의 종합 활동에서는 조건을 고정한 PyTorch 추론 기준선과 vLLM 및 Multi-GPU 실행 결과의 Throughput·TTFT·TPOT·VRAM과 Scaling 차이를 비교하고, 계산·메모리·통신 병목을 측정 근거로 설명한다.
