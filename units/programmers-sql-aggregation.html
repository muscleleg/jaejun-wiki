집계 함수 선택과 결과 검증

부분 충족

COUNT, SUM, AVG, MAX/MIN을 요구사항에 맞게 사용하고 NULL·중복·데이터 없는 그룹이 결과에 주는 영향을 예제로 확인한다.

확인한 내용

  • COUNT(*)와 COUNT(표현식)의 NULL 처리, 중복 값의 개수와 종류 수, CASE 조건부 COUNT를 예제로 학습했다. 판매 기록 수와 판매량 합계를 구분해 SUM(SALES)로 수정했다.
  • 입양이 없는 시간에는 원본 GROUP BY의 그룹도 없다는 이유를 학습했다. LEFT JOIN의 NULL 채움 결과 행을 COUNT(*)는 세지만 COUNT(ANIMAL_ID)는 세지 않는 차이를 설명받은 뒤 자기 말로 정리했다. 먼저 집계한 뒤 JOIN하면 빈 시간의 CNT가 NULL이 되어 COALESCE가 필요하고, JOIN한 뒤 ID를 집계하면 0이 계산된다는 순서 차이를 스스로 짚었다.

남은 내용

  • AVG·MAX/MIN을 요구사항에 맞게 직접 사용하고 결과를 확인한다.
  • 설명 예제에서 학습한 NULL·중복·빈 그룹과 LEFT JOIN의 영향을 직접 작성·실행한 예제로 검증한다.
