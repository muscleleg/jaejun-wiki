    DL이 Deep Learning의 약자이며 Machine Learning 안에서 여러 층의 신경망으로 표현을 학습하는 접근이라는 기본 관계를 다시 확인했다. 단편적으로 공부해 온 내용을 남은 것이 없다고 보지 않고, 실행 결과·자기 설명·재구현을 기준으로 기록하는 방향도 점검했다. 현재 Attention 코드는 Q와 K의 실제 평균이나 분산을 측정하지 않고 마지막 차원 크기만 사용한다. 따라서 모든 입력에서 Score 표준편차를 정확히 1로 만드는 연산이 아니라, Q·K 원소가 중심 0 근처이고 비슷한 분산을 가지며 독립적이라는 일반적인 통계적 전제에서 차원이 커질 때 생기는 Score 규모 증가를 완화하는 고정 Scaling임을 바로잡았다. 여러 Tensor 연산 자체가 하나의 Loss 함수를 만들고, Tensor가 계산 그래프를 보존해 `backward()`가 변화율을 구한다는 관점을 정리했다. `Loss=(wx-y)²`에서 `2(wx-y)x`를 극한식으로 유도하고 PyTorch Gradient와 일치함을 확인했다. Gradient 누적·초기화, `no_grad` 안의 in-place 업데이트와 반복 학습에서 수정 전 Loss·수정 후 w의 시점 차이도 실행 결과로 확인했다. Python·NumPy·Pandas·SQL·시각화·scikit-learn·실험 엔지니어링의 최소 범위를 명시하고, 데이터·학습·Transformer·전달의 네 산출물 관문과 두 포트폴리오로 완료 기준을 재구성했다.
