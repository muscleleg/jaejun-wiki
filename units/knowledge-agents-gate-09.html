예상 근거와 답변 가능 여부를 가진 질문 집합으로 검색 성공과 답변의 근거 충실성을 따로 평가한다. 설정 하나를 바꾼 전후를 같은 조건에서 비교하고, 문서 추가·수정·삭제가 저장된 청크와 검색·답변에 반영되는지 검증한다. 이 학습 단원에서 RAG 전체 흐름의 종합 검증을 수행한다.

예상 근거·답변 가능 여부를 적은 질문 집합을 만들고 예상 근거의 검색 여부와 답변의 근거 충실성을 별도 기준으로 평가한다. 비율을 사용하면 대상 질문·성공 건수·분모와 실제 계산을 함께 제시하며 실패를 수집·검색·문맥·생성 단계로 구분한다.

○

동일 질문으로 설정 변경 비교

미충족

문서 집합·모델·질문·비교 조건을 고정하고 분할·검색 개수·검색 방식 중 한 가지를 바꿔 전후를 비교한다. 원문 근거, 검색 결과, 답변, 지연과 토큰 사용 또는 비용을 기록해 개선·악화·유지 판단의 이유를 설명한다.

○

추가·수정·삭제와 재평가 확인

미충족

문서를 추가·수정·삭제한 뒤 어떤 청크·인덱스를 갱신해야 하는지 설명하고 실제 갱신한다. 같은 질문으로 변경 반영, 삭제된 내용·중복 청크의 잔존 여부와 출처를 확인하며 원문부터 답변까지 종합 검증한다.
