학습 안내

이 학습이 필요한 이유
Runtime 내부 처리와 여러 Endpoint 사이의 요청 제어를 구분해야 Kubernetes 운영 계층에서도 같은 책임을 혼동하지 않는다.
완료 후 이어지는 일
Architecture별 Capacity와 Goodput을 비교하고 Single-node E2E 시스템을 재현할 수 있다.
