동일 GPU 예산의 Architecture 비교와 동일 Architecture의 GPU 수 확장을 구분하고 Workload별 SLO·Goodput·비용의 적용 범위를 설명한다.

이 학습이 필요한 이유
실제 Architecture 선택이나 자원 확장 판단이 필요할 때 광범위한 비교 실험으로 기준선·통합 실습의 결과를 심화한다.

Workload·GPU Budget·통신 경로에 따른 Architecture 선택과 비용 산정의 근거를 확보한다.
학습 내용 자세히 보기

선택 심화. 기존 A40 최대 4장 비교 계획을 보존한다. 동일 2 GPU Budget의 Replica·TP·1P1D, 3 GPU의 2P1D·1P2D, Replica 1·2·4개 확장을 각각 분리해 비교한다. 필수 분산 Runtime 로드맵과 Gateway·EPP 통합 실습의 완료·선수 조건에는 포함하지 않는다.
