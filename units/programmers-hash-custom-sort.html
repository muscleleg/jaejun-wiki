  • `a + b`와 `b + a`를 비교하는 사용자 정의 정렬을 구현하고, `sort()` 반환값 문제를 `sorted()`로 교정한 코드로 15개 테스트 중 14개를 통과해 93.3점을 받았다. 모든 숫자가 0인 경계 조건과 수정 방향도 확인했다.

남은 내용

  • 나중에 자료 없이 비교 함수, 정렬 API와 모든 숫자가 0인 예외처리를 포함해 다시 구현하고 프로그래머스 전체 테스트를 통과한다.

    풀이 횟수: 1회. 프로그래머스 「가장 큰 수」에서 숫자를 문자열로 바꾼 뒤 `a + b`와 `b + a`를 비교하는 사용자 정의 정렬을 `compare`와 `cmp_to_key`로 구현했다. 구현 중 `list.sort()`가 원본을 정렬하고 `None`을 반환한다는 점을 놓쳐 `join`에 바로 연결할 수 없었으며, 정렬된 새 리스트를 반환하는 `sorted()`로 교정했다. 제출에서는 15개 테스트 중 14개를 통과해 93.3점을 받았고, 모든 입력이 0일 때 `"000"`이 아니라 `"0"`을 반환해야 하는 경계 조건을 놓쳤다. 정렬 결과의 첫 문자가 0이면 모든 원소가 0이라는 성질을 이용한 수정 형태를 확인했지만, 수정 코드의 전체 재제출과 100점 통과는 아직 확인하지 않았다. 나중에 자료 없이 비교 함수, 정렬 API와 0 예외처리를 다시 구현할 필요가 있다.
