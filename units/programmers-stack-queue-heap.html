주식가격

부분 충족

프로그래머스 「주식가격」를 직접 구현해 전체 테스트를 통과한다.

확인한 내용

  • 초기 풀이의 시간 누적 조건 오류를 피드백으로 교정한 뒤 프로그래머스 정확성·효율성 전체 테스트를 통과했다.

남은 내용

  • 피드백 없이 문제 조건을 해석하고 한 번에 올바른 풀이를 구현해 전체 테스트를 통과한다.

관련 학습 기록

  • 프로그래머스 「주식가격」을 처음에는 직접 이중 반복문으로 작성했지만, 가격이 유지되거나 상승한 경우에만 시간을 세고 가격이 떨어지면 시간을 세지 않은 채 종료하는 조건 오류가 있…

    프로그래머스 「주식가격」을 처음에는 직접 이중 반복문으로 작성했지만, 가격이 유지되거나 상승한 경우에만 시간을 세고 가격이 떨어지면 시간을 세지 않은 채 종료하는 조건 오류가 있었다. 피드백을 통해 이 문제는 조건을 만족하는 가격 개수가 아니라 최초 하락 시점까지 실제로 흐른 시간을 구하며 하락한 순간의 1초도 포함해야 한다는 점을 확인했다. 이후 각 미래 시점마다 먼저 1초를 누적하고 가격이 처음 떨어지면 즉시 중단하도록 수정했다. 프로그래머스 정확성 테스트 10개와 효율성 테스트 5개를 모두 통과해 정확성 66.7, 효율성 33.3, 합계 100.0을 확인했다. 구현은 최악의 경우 이중 반복문으로 O(n²) 시간복잡도이며 결과 배열을 저장해 O(n) 추가 공간을 사용한다.

완료 근거 1개

  • 프로그래머스 「다리를 지나는 트럭」을 이전 코드 없이 직접 구현했다. `bridge_queue`를 다리 길이만큼의 큐로 두고 빈 칸을 0으로 채우며, 매 반복을 1초로 해석해 빠…

    프로그래머스 「다리를 지나는 트럭」을 이전 코드 없이 직접 구현했다. `bridge_queue`를 다리 길이만큼의 큐로 두고 빈 칸을 0으로 채우며, 매 반복을 1초로 해석해 빠져나가는 칸을 제거한 뒤 현재 다리 무게와 다음 트럭의 무게를 비교해 진입 또는 0을 추가했다. 대기 트럭이 없더라도 다리 위 트럭이 모두 빠질 때까지 반복해야 하며, 다음 트럭이 올라가지 못하면 입력 순서를 유지한 채 0으로 기다리게 한다는 종료·상태 규칙을 확인했다. 구현 과정에서 실행을 반복하며 조건을 우당탕 조정했지만 최종 코드로 프로그래머스 정확성 테스트 14개를 모두 통과했다. 현재 구현은 매초 `sum(bridge_queue)`를 다시 계산하므로 무게를 별도 변수로 유지하면 반복당 확인을 O(1)로 줄일 수 있다는 개선 방향을 확인했다. 전체 채점 요약과 개선 코드의 별도 제출 결과는 아직 확인하지 않았다.
