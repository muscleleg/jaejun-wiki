RunPod에서 첫 검증

실제 GPU 측정이 계산과 비교 가능한지 검증하고 예상값과 실측값의 차이를 재현 가능한 기록으로 남긴다.

이 학습이 필요한 이유
이론식의 오차를 분석하려면 다운로드·초기화·비동기 실행·측정 변동을 모델의 정상 실행 비용과 구분할 수 있어야 한다.

신뢰할 수 있는 기준 측정을 바탕으로 문맥·배치·모델·GPU 조건을 바꿀 수 있다.
학습 내용 자세히 보기

사전 계산을 마친 Qwen/Qwen3-4B를 RunPod의 GPU 한 장에서 BF16·동시 요청 하나의 고정 조건으로 실행한다. 모델·Tokenizer·라이브러리·GPU 형태·생성 설정을 기록한다. 모델 다운로드·초기화와 준비 실행 이후의 측정을 구분하고 GPU 비동기 실행에 맞는 시간 측정과 반복을 수행한다. 메모리 사용량과 Prefill·Decode 시간을 예측표와 비교한다.

고정 조건의 실행과 결과 재현

미충족

대여할 GPU 형태와 실제 장치를 확인하고 모델·환경 버전을 고정한다. 준비 실행 후 동일 조건을 반복하며 정상 생성과 실제 입력·출력 토큰 수를 확인하고 측정 원본과 재현 절차를 보존한다.

○

메모리와 구간별 시간 측정

미충족

모델 로드 전후와 Prefill·Decode의 메모리 사용량을 측정한다. Tensor 할당량·실행기 예약량·장치 전체 사용량을 구분하고 GPU 계산 완료를 반영해 Prefill과 Decode를 각각 측정한다. 반복값과 변동 범위를 제시한다.

○

예측값과 실측값의 차이 계산

미충족

사전에 남긴 메모리·시간·속도 예측과 같은 조건의 실측값을 나란히 제시하고 절대 차이와 상대 차이를 계산한다. 상한보다 낮은 속도를 곧바로 계산 오류로 단정하지 않고 확인된 사실과 추가 검증할 가설을 분리한다.
