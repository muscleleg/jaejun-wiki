미충족

프로그래머스 여행경로에서 동일 출발지와 중복 항공권을 구분해 사용 상태를 관리하고 완성 경로와 사전순 조건을 설명한다. 구현·전체 테스트 뒤 7~14일 사이 미풀이 경로 구성 변형을 독립 해결한다.

목표 문맥별 선택 이유

AI 엔지니어 역량에서 선택한 이유

핵심 종착점은 PyTorch로 이해한 추론 흐름을 vLLM과 Multi-GPU 환경까지 확장하고, 성능 차이를 재현 가능한 수치와 병목 근거로 설명하는 것입니다.

이 목표의 학습 경로에는 이 유닛이 선택되지 않았습니다.

코딩 테스트 문제 해결 역량에서 선택한 이유

핵심 종착점은 프로그래머스 문제를 많이 푼 상태가 아니라, 학습한 패턴을 간격을 두고 자료 없이 재구성하고 유형 이름을 숨긴 미풀이 문제에서 제약으로 전략을 선택·변형하며, 지원 기업과 유사한 제한 시간 세트에서 합격권 결과를 반복하고 실패를 복구할 수 있는 상태입니다.
