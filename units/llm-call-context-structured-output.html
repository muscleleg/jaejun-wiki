LLM(대규모 언어 모델) API 요청의 지시·사용자 입력·대화 이력과 응답을 구분한다. 이번 호출에 실제로 전달한 문맥을 확인하고, 정해진 항목의 출력과 프로그램의 검증을 연결한다. 특정 공급자나 프레임워크에 종속되지 않는 작은 호출 예제로 시작한다.

  • DB에 정보를 보관하는 일과 모델 요청에 정보를 전달하는 일의 차이를 자기 말로 설명했다.

남은 내용

  • 실제 요청·응답 예에서 지시, 사용자 입력, 대화 이력과 생성 결과를 각각 가리킨다.
  • 실제 요청에 포함한 정보와 앱에만 남아 있는 상태를 대조해 전달 경계를 확인한다.
