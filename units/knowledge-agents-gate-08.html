학습 내용 자세히 보기

도구의 시간 초과, 재시도 가능한 실패와 영구 오류, 대체 처리와 반복 상한을 구분한다. 쓰기 작업은 중복 실행 방지와 사람의 확인을 적용하고 권한은 실행 프로그램에서 검사한다. 문서나 도구 출력에 섞인 악의적 지시가 실행 권한을 넓히지 못하는지 통제된 예제로 확인한다.

시간 초과·일시 오류·영구 오류를 주입해 재시도 대상·횟수·대체 처리·종료를 정하고 실제 로그와 비교한다. 같은 잘못된 인자를 반복하는 경우 반복 상한이 작동하는지 확인한다.

○

중복 실행과 사람의 확인 검증

미충족

실제 외부 발송 대신 통제된 쓰기 도구를 사용한다. 응답 유실 뒤 재시도에서도 같은 작업이 중복 적용되지 않는지 확인하고, 확인이 필요한 작업은 사용자의 승인 전 실행되지 않는지 검증한다.

○

권한과 자료 속 지시의 경계 검증

미충족

권한 없는 자료 조회·쓰기 요청과 검색 문서 또는 도구 출력에 섞인 지시를 시험한다. 실행 계층에서 권한·허용 도구·인자를 검사해 자료 내용만으로 권한이 넓어지지 않음을 로그로 확인한다.
