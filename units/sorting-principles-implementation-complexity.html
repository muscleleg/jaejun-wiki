정렬 원리·구현·복잡도

주요 정렬 알고리즘의 동작을 추적하고 직접 구현하며, 입력 조건에 따른 시간·공간복잡도와 정렬 성질을 설명해 Python 문제 풀이의 정렬 비용을 판단할 수 있다.

학습 내용 자세히 보기

문제 풀이 진도와 분리한 선택 이론 학습이다. 정렬 기초 → 버블·선택·삽입 → 병합·퀵 → 힙 → Python 정렬 적용 순서로 배열 변화, 직접 구현, 시간·공간복잡도와 안정성을 학습한다. 계수·기수 정렬은 이후 심화 선택 주제이며 이 학습 단원의 완료 기준에 포함하지 않는다. 코테 목표의 필수 경로에는 추가하지 않으며 기존 프로그래머스 문제 달성 기준을 확장하지 않는다. 답·설명을 참고한 첫 구현은 부분 활동으로 보존하고 이후 자료 없는 구현·원리 설명을 확인한다. 회차별 복습은 같은 달성 기준의 증적으로 쌓고 매번 새 단계나 문제 통과 횟수로 만들지 않는다.

버블·선택·삽입 정렬

미충족

버블 → 선택 → 삽입 순서로 각 정렬의 배열 변화를 손으로 추적하고, 완성 코드를 보지 않고 Python으로 구현해 빈 배열·단일 원소·중복·이미 정렬된 배열·역순 배열에서 결과를 검증한다. 비교·교환·이동 횟수로 최악 O(n²)을 설명하고, 조기 종료 버블과 삽입 정렬의 최선 O(n) 및 각 구현의 안정성·추가 공간을 설명한다.

○

병합·퀵 정렬

미충족

병합 → 퀵 순서로 분할·병합과 피벗·파티션의 배열 변화를 추적하고 완성 코드를 보지 않고 구현해 경계 입력을 검증한다. 균형 분할의 깊이와 각 단계의 총 연산으로 O(n log n)을 설명하고, 퀵 정렬이 편향 분할에서 O(n²)이 되는 이유를 설명한다. 자신이 구현한 병합 배열과 재귀 스택의 추가 공간을 구분하며, 비교 기반 정렬의 최악 시간 하한 Ω(n log n)의 기본 의미를 설명한다.

힙 정렬

미충족

배열의 부모·자식 인덱스와 힙 성질을 이용해 힙 구성 및 최대 원소 추출 과정을 추적하고, 완성 코드를 보지 않고 제자리 힙 정렬을 구현해 경계 입력을 검증한다. 상향식 힙 구성 O(n), 반복 추출 O(n log n), 반복형 sift-down을 사용하는 제자리 구현의 추가 공간 O(1)과 불안정성을 설명한다.
