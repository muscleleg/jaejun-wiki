COUNT(*)가 컬럼 수가 아니라 WHERE를 통과한 행 수를 세며 COUNT(표현식)은 NULL이 아닌 값을 세는 규칙을 예제로 학습했다. 날짜·집계 문법의 도움을 받은 풀이이며 별도 제출·전체 채점 결과는 확인하지 않았다.

    프로그래머스 「입양 시각 구하기(1)」에서 HOUR(DATETIME)을 시간대 기준으로 사용하고 COUNT(*)로 그룹별 기록 수를 계산하는 쿼리를 직접 작성했다. 처음 GROUP BY 뒤에 AND WHERE를 둔 오류를 설명받은 뒤 WHERE에서 9시 이상·20시 미만 행을 먼저 남기고 GROUP BY HOUR(DATETIME), ORDER BY를 적용해 실행이 됐음을 확인했다. 같은 기준값의 원본 행들을 논리적인 그룹으로 나누고 그룹마다 공통 기준값과 원본 행 수를 출력한다는 흐름을 자기 말로 설명했다. COUNT가 먼저 출력한 시간 하나를 세는 것이 아니라 같은 그룹의 원본 행들을 세는 점, 일반 컬럼과 집계를 함께 출력할 때 결과 값이 하나로 결정돼야 하는 규칙, ORDER BY가 그룹별 요약 결과를 정렬하는 점을 학습했다. HOUR·그룹화와 문법 수정의 도움을 받았으며 전체 채점 점수나 테스트 개수는 명시하지 않았다.

    프로그래머스 「동명 동물 수 찾기」에서 SELECT NAME, COUNT(*)와 GROUP BY NAME을 직접 작성했다. 이름이 NULL인 행을 제외하는 WHERE와 이름별 개수가 2 이상인 그룹을 남기는 HAVING을 설명받았고, HAVING을 빠뜨린 쿼리의 수정 안내 뒤 됐음을 확인했다. 이름 있는 행을 남기고 이름별로 논리 분리한 다음 2행 이상인 그룹을 남긴다는 흐름을 자기 말로 정리했으며 SELECT 결과를 모은 뒤 ORDER BY가 이름순으로 정렬함을 이해했다. HAVING과 NULL 제외 조건은 도움받아 보완했으며 독립 재구현이나 상세 채점 결과는 확인하지 않았다.

확인한 내용

  • 조건에 맞는 회원수 구하기의 올바른 쿼리를 작성하고 입양 시각 구하기(1)의 수정 쿼리가 실행됐음을 확인했다. 날짜 조건과 시간대별 집계 흐름을 설명했다.

남은 내용

  • 두 문제의 전체 채점 통과 결과를 확인한다. 회원수 문제는 별도 제출 결과가 없고 입양 문제는 상세 채점 범위를 명시하지 않았다.
