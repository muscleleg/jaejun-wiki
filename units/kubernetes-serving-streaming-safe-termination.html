학습 내용 자세히 보기

핵심 질문: 취소·재시도·서버 축소 때 진행 중인 요청과 자원은 어떻게 정리되는가? 개념·실습 흐름 Queue 대기 취소와 Streaming 연결 종료 뒤 Backend 정리를 확인하고 첫 Token 전후 Retry 정책을 구분한다. 수동 Scale-in에서 진행 중인 Streaming 요청과 Endpoint Drain을 관찰한다. 자동 확장 정책은 뒤 단원에서 연결한다. Drain 없는 종료와 Graceful Shutdown을 비교해 신규 요청과 진행 중 요청의 처리 차이를 설명한다. 실험과 달성 기준 연결 Queue 취소·Streaming 연결 종료·Retry 비교는 달성 기준 1~3, 수동 Scale-in·Drain·Graceful Shutdown 대조는 4~6과 연결한다. 실행 조건과 검증 경계 자동 확장 정책을 먼저 구축할 필요는 없다. 수동 Replica 감소로 요청 종료 동작을 검증하고 단순 TCP 연결 종료만으로 Backend 정리를 완료 처리하지 않는다.
