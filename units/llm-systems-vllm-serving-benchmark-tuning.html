Serving Workload Matrix 구성

미충족

Prompt Length·Output Length·Cache 재사용 여부를 변화시켜 Short·Prefill-heavy·Long Prefill·Decode-heavy Workload를 구성한다. Max Concurrency로 제한하는 Closed-loop 실험과 Request Rate·Burstiness를 제어하는 Open-loop 요청 도착 실험을 구분한 Benchmark Matrix를 만들고 각 축의 목적을 설명하면 완료된다.

○

동일 Benchmark 계약으로 성능 비교

미충족

PyTorch와 vLLM에서 동일 Workload를 실행하고 공통 측정 경계의 TTFT·TPOT·ITL·E2E Latency·Throughput·Peak VRAM을 기록한다. vLLM Serving에서는 Queue Time과 Waiting Request를 함께 수집하고 TTFT·TPOT·E2E·Queue Time의 P50·P95·P99를 계산한다. Benchmark CSV·비교표·그래프·실행 환경과 Configuration을 남기면 완료된다.

○

Scheduler Parameter 영향 분석

미충족

max_num_seqs·max_num_batched_tokens·Prefix Caching·Chunked Prefill을 한 번에 하나씩 변경하고 각 Parameter의 Before·After TTFT·TPOT·Throughput·VRAM을 비교해 결과를 해석하면 완료된다.

○

Throughput·Latency Trade-off와 SLO 분석

미충족

Concurrency 또는 Request Rate 증가가 Throughput을 높이면서 Queue와 Tail Latency를 악화시킬 수 있는 이유를 설명한다. Request Rate와 Burstiness별 Throughput·Queue Time·TTFT·TPOT의 P50·P95·P99 그래프를 만들고, 미리 정한 TTFT·TPOT SLO를 만족하는 최대 지속 가능 Request Rate와 특정 Workload의 추천 설정 및 근거를 남기면 완료된다.
