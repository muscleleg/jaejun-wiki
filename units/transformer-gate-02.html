    Token ID `[[3,7,2]]`와 위치 ID `[[0,1,2]]`를 각각 `nn.Embedding`으로 조회했다. Token vector와 Position vector가 모두 `[1,3,2]`이고, 같은 위치·차원의 원소끼리 더한 Hidden State도 `[1,3,2]`임을 실행했다. 이 Shape을 Batch 1개 안의 Sequence 길이 3, Token 하나당 2차원으로 설명했다. 예전에 구현한 sin·cos Positional Encoding은 수식으로 고정 위치 벡터를 만들지만, 이번 `nn.Embedding(max_seq_len,d_model)` 방식은 위치별 벡터를 조회표에 저장하고 Loss의 Gradient로 함께 조정한다. 두 방식을 나중에 결합하는 것이 아니라 둘 중 한 방식을 선택할 수 있으며, 공통적으로 Token vector에 위치 vector를 더해 순서 정보를 제공한다는 경계를 확인했다. `nn.Embedding` 자체는 입력 index가 Token인지 위치인지 알지 못하고, 어떤 정수 ID를 넣어 어디에 사용하는지가 역할을 결정한다. `nn.Embedding(8,2)`에서 `num_embeddings=8`은 저장할 벡터 수이자 Weight 행 수, `embedding_dim=2`는 벡터 하나의 원소 수이자 열 수다. 초기 원소 값의 퍼짐인 `std`는 `embedding_dim`의 역할이 아니라 `nn.init.normal_` 같은 초기화에서 별도로 지정한다는 오해를 교정했다. 기존 Multi-Head Attention에 길이 3의 하삼각 Boolean Mask를 넣고 미래 Score를 `-inf`로 바꾼 뒤 Softmax했다. 입력과 Attention 출력은 `[1,3,2]`, Attention weight는 `[batch,head,query,key]=[1,2,3,3]`이었으며 첫 Head에서 미래 칸이 모두 0인 결과를 확인했다. Causal Mask는 참고 가능한 값을 제한할 뿐 Tensor 차원을 바꾸지 않는다고 예측했다. Head 출력 `[1,3,2,1]`을 `reshape(batch_size,token_count,d_model)`로 `[1,3,2]`에 합치며, 이는 `num_heads × head_dim = d_model`이기 때문에 가능하다고 설명했다. 이어 `output_projection`이 이어 붙인 Head 정보를 학습 가능한 Weight로 다시 섞는다. 최초 셀에서 Key를 Query Projection으로 잘못 계산한 `key=self.query_projections(x)`를 찾아 `key=self.key_projection(x)`로 고치고 재실행해 서로 다른 Q·K Projection을 사용하도록 수정했다. `Causal Multi-Head Attention → x+Attention Residual → LayerNorm → FFN(Linear 2→8 → GELU → Linear 8→2) → 첫 LayerNorm 결과+FFN Residual → LayerNorm` 순서로 최소 Block을 연결했다. 입력과 출력 Shape이 모두 `[1,3,2]`, Attention weight가 `[1,2,3,3]`임을 확인했으며 Block 출력은 `[[[1,-1],[-1,1],[1,-1]]]`이었다. 두 번째 Residual에는 처음의 `x`가 아니라 첫 Residual과 LayerNorm까지 마친 표현을 더한다는 점을 자기 말로 설명했다. 이번 최소 연결에서는 Dropout을 생략했다. `TinyDecoderLM` 전체 클래스의 구조와 코드는 제시됐지만 아직 저장된 실행 결과는 없다. 다음에는 `Token Embedding + Position Embedding → Causal TransformerBlock → LM Head`를 실제로 실행해 입력 `[1,3]`이 Logit `[1,3,10]`으로 바뀌는지 확인하고, Target `[1,3]`과 Cross Entropy Loss를 연결한다. 이후 작은 학습에서 Loss 감소를 확인하고 다음 Token 하나를 생성해야 Tiny Decoder LM 완료 조건을 충족한다. 같은 활동에 관해 기존 복습 기록에 남아 있던 검증 요약 (새 활동·추가 시간 아님) Head별 출력 [1,3,2,1]을 Token 기준으로 재정렬해 [1,3,2]로 합치고 Output Projection을 적용했습니다. torch.tril Boolean Mask와 masked_fill을 실행하고 미래 Attention Weight가 0임을 확인했습니다. Causal Attention부터 두 번째 Residual·LayerNorm까지 연결하고 입력·출력 [1,3,2]와 Token별 통계를 검증했습니다.
