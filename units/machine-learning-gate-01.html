    `attention_weights @ value`의 Shape을 예상하고, 가운데 Token 축이 곱의 합으로 처리되며 각 Query 출력이 Value의 가중합이라는 사실을 숫자로 확인했다. 현재 코드의 출력·Attention weight 반환과 Mask 동작도 검사했다. 동료와의 대화에서 발견한 질문을 Feature·Label·Loss·Threshold·Confusion Matrix·Precision·Recall·F1·데이터 분할·반복 실험의 흐름으로 정리했다. ROC/PR-AUC, Calibration과 불균형 처리는 이후 실습에서 검증할 항목으로 분리했다. Precision과 Recall 중 하나만 높고 다른 하나가 낮은 모델을 좋은 모델로 평가하지 않기 위해 F1 Score가 조화평균을 사용한다는 점을 확인했다. Threshold를 반복해서 조절하는 일은 예측 기준을 바꾸는 것이지 모델이 새로운 패턴을 학습하는 것은 아니므로, 데이터·Feature·학습 방식과 평가 기준을 함께 살펴야 한다는 흐름으로 연결했다. 별도 대화에서 Cross-Model KV Cache Transfer를 살펴본 흔적은 확인했지만 대화 본문을 다시 불러오지 못했다. 학습했다는 사실만 보존하고, 어떤 구조와 장단점을 이해했는지는 원문이나 대화를 찾은 뒤 보강할 미확인 항목으로 남긴다. GLM-5.2 GPU 최적화 글에서 Forward, Hidden State, Logits와 MTP를 읽었다. Draft 모델이 만든 미래 Token ID 후보를 큰 모델이 한 번의 Forward로 병렬 검증하는 흐름과 후보 일부만 승인될 수 있다는 점을 정리했다. 홈에서 모든 문서로 이동할 수 있게 연결하고, 긴 Transformer·수학 문서를 상위 인덱스와 주제별 하위 문서로 분리했다. 기존 내용은 생략하지 않고 문서 계층과 홈 이동 경로를 추가했다.
