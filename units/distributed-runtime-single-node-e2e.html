Gateway·EPP·실제 GPU Serving 적용 심화

실제 Runtime 신호가 EPP 선택과 응답 성능에 미치는 영향을 검증하고, 모의 Endpoint 검증과 실제 성능 검증의 차이를 설명한다.

학습 안내

짧은 제목 · 선택: Gateway·EPP 실GPU

선수 대기달성 기준 0 / 13
이 학습이 필요한 이유
요청 경로와 EPP 역할은 이미 학습했다. 특정 정책의 실제 GPU 성능 효과를 검증하려는 목적이 있을 때 Benchmark 기준선과 함께 수행한다.
완료 후 이어지는 일
실제 서비스에 Gateway·EPP 정책을 적용할 때 필요한 근거를 제공한다. Interconnect·Cross-node 및 최종 종합 실습의 선수 조건은 아니다.
학습 내용 자세히 보기

기존 Kubernetes·모의 Endpoint 실습을 실제 GPU Serving의 부하·Prefix·응답 성능으로 확장하는 선택 실습이다. 한 RunPod의 독립 TP=1 vLLM 두 서버와 Agentgateway·EPP를 연결하고 실제 정책 효과를 검증한다. 분산 Runtime의 필수 구성 요소로 EPP를 가정하지 않으며 최종 종합 실습과 분리한다.

○

EPP가 읽은 실제 메트릭과 정책의 판단 근거를 확인한다.

○

한쪽 서버에 부하를 집중하고 새 요청 분배를 관찰한다.

Prefix 재사용 이점과 부하 집중 비용을 비교한다.
