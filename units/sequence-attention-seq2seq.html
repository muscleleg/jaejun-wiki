Attention을 결합한 Seq2Seq

Decoder 시점마다 Encoder 위치를 참고하는 비율과 문맥 벡터를 계산해 Attention Seq2Seq를 학습·생성한다.

이 학습이 필요한 이유
하나의 상태로 입력 전체를 전달하는 방식에서 출력 시점마다 필요한 입력 위치를 다시 참고하는 방식으로 확장할 필요가 있다.
완료 후 이어지는 일
Transformer의 Self-Attention과 Encoder–Decoder Cross-Attention을 참고 대상과 Q·K·V의 출처로 비교할 수 있다.
학습 내용 자세히 보기

고정된 마지막 상태를 전달하는 Seq2Seq에 입력 위치별 Attention을 추가한다. 작은 Alignment 점수와 가중합을 계산하고 Padding 처리·학습·생성을 기존 기준 구현과 비교한다.

위치별 점수·참고 비율·문맥 벡터 계산

미충족

Decoder 상태와 Encoder의 시점별 출력으로 작은 Additive Attention 점수를 만들고 Softmax와 가중합을 직접 계산한다. 기존 Scaled Dot-Product Attention과 점수 계산 방식 및 참고 대상의 차이를 구분한다.

○

Attention의 입력 Padding 차단

미충족

길이가 다른 두 입력열에서 Padding 위치를 차단하기 전후의 비율과 문맥 벡터를 비교한다. Encoder Padding Mask와 출력 Target의 Loss 제외가 서로 다른 역할임을 설명한다.

○

Attention 유무의 학습·생성 비교

미충족

같은 작은 변환 데이터와 분할·학습 예산·평가 기준에서 Attention을 추가한 모델을 실행한다. 출력 시점별 Attention과 실제 생성 결과를 함께 보고 긴 입력·대표 오류를 비교하며 성능 향상을 미리 가정하지 않는다.
