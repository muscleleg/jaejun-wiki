학습 내용 자세히 보기

같은 모델과 GPU에서 문맥 길이와 배치를 각각 바꾸며 필요한 자원과 병목 변화를 예측한 뒤 측정한다. 문맥 변화 실험에서는 출력 길이와 배치를, 배치 실험에서는 요청별 문맥과 출력 길이를 고정한다. 가중치 재사용, KV 캐시 증가, Attention 비용을 연결하고 요청별 생성 시간과 전체 처리량을 함께 관찰한다.
