의류 이미지 분류

이미지 Tensor와 DataLoader를 이해하고 MLP·CNN을 같은 조건에서 비교해 오분류 분석과 이미지 한 장 추론을 재현한다.

이 학습이 필요한 이유
공통 PyTorch 학습·평가 기초를 새로운 Tensor 축과 공간 정보를 가진 이미지로 확장하기 위해 필요하다. 별도 표 데이터 프로젝트 전체를 먼저 완료하도록 강제하지 않는다.

이미 확인한 PyTorch 학습·평가 기초를 의류 이미지에 적용하고 다중 분류와 CNN을 배운다. 커널·stride·padding에 따른 공간 크기와 Pooling·Flatten·분류층 연결을 작은 계산과 실제 출력으로 검증한다.
