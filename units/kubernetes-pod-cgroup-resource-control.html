Pod cgroup과 자원 통제

짧은 제목 · Pod cgroup·자원 통제

완료달성 기준 3 / 3

학습 후 할 수 있는 일Kubernetes의 Pod·Container 자원 선언이 Linux 프로세스 소속과 계층적 cgroup 제한으로 변환되는 과정을 설명한다.

학습 안내

이 학습이 필요한 이유
Pod Sandbox와 Namespace가 프로세스에게 무엇이 보이는지를 정했다면, 같은 프로세스가 자원을 얼마나 사용할 수 있는지는 별도의 cgroup 계층으로 이해해야 한다.
완료 후 이어지는 일
Pod Scheduling의 요청량, Node 자원 압박, QoS 기반 축출과 GPU를 포함한 Kubernetes 자원 할당 문제를 프로세스 수준의 집행 구조와 연결한다.
학습 내용 자세히 보기

Linux cgroup이 프로세스들을 그룹으로 묶어 CPU·Memory·I/O를 통제하는 원리에서 출발해, Kubernetes가 Pod cgroup 아래 Container cgroup을 만들고 requests·limits와 QoS 정책을 커널 자원 경계로 연결하는 구조를 정리한다.
