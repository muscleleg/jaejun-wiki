학습 내용 자세히 보기

프로그램이 보관하는 작업 상태·도구 결과·대화 이력과 이번 모델 호출에 넣는 문맥을 구분한다. 후속 요청과 재개에서 필요한 정보만 전달하고, 문맥 축약·선택 과정에서 목표·제약·출처·미완료 작업을 보존한다. 장기 저장 자료가 모델의 자동 기억과 같지 않다는 점을 실제 요청으로 확인한다.
