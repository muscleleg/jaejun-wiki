How I work

문제를 기능으로 만들고, 결과를 검증합니다.

백엔드 API, 프론트엔드와 Kubernetes 운영 기능을 함께 구현해 왔습니다. 개인 AI 프로젝트에서도 모델 호출에 그치지 않고 데이터 준비, 서비스 연결, 평가와 오류 분석까지 직접 다룹니다.

운영을 아는 구현자배포·모니터링·로그·백업처럼 실제 운영에 필요한 기능을 개발했습니다.
경계를 넘나드는 개발자백엔드뿐 아니라 프론트엔드, Kubernetes와 데이터 흐름까지 연결합니다.
검증하는 AI 개발자모델 호출에 그치지 않고 데이터셋·평가·오류 분석·서빙까지 확인합니다.

vLLM 서버를 구성하고, 응답 품질에 맞는 수용량을 측정하며, 통제 실험으로 성능 저하의 원인을 분석할 수 있습니다.

  • 단일 GPU vLLM Baseline

    다른 로드맵의 완료나 Evidence를 요구하지 않고 단일 GPU vLLM Serving 기준선과 비교 계약을 자체적으로 확립한다.

  • 단일 GPU Scheduler·KV Cache

    단일 GPU vLLM이 여러 요청과 KV Cache를 Iteration별로 Scheduling하고 관리하는 과정을 설명하고 자원 부족과 과부하에 대한 보호 동작을 검증한다.

  • 단일 GPU Benchmark·Capacity

    단일 GPU의 Workload별 성능 분포를 측정하고 SLO를 만족하는 지속 가능한 Request Rate·Concurrency와 추천 Serving 설정을 결정한다.

  • 단일 GPU Observability

    단일 GPU Serving Metric과 GPU Metric을 연결해 Queue·Prefill·Decode·KV Cache·Compute·Memory 병목을 진단한다.

PyTorch 추론 기준선을 만들고, Cache·Batch·GPU 동기화의 영향을 분리해 측정하며 vLLM과 재현 가능하게 비교할 조건을 설계할 수 있습니다.

  • Cache·Batch·GPU 성능 측정

    동일 모델·Prompt에서 Cache·Batch·장치 이동·동기화와 현대 Decoder 연산을 분리해 PyTorch 추론 기준선을 만든다.

  • 벤치마크 테스트 기초

    같은 모델·입력·생성 조건과 같은 측정·검증 규칙으로 PyTorch와 vLLM 결과를 재현하고 비교할 수 있는 계약을 만든다.

Attention과 Tiny Decoder의 계산을 직접 구현·검산하고, 사전학습 Causal LM의 토큰화·생성·평가·복원을 연결해 동작을 설명할 수 있습니다.

  • Token Embedding

    Token ID가 Embedding 벡터를 조회하는 방식과 초기화·스케일·Shape을 설명한다.

  • Positional Encoding

    위치별 sin·cos 벡터와 차원별 변화 속도의 역할을 설명한다.

  • Single-head Attention

    QKᵀ·Scaling·Mask·Softmax·Value 가중합을 구현하고 검산한다.

  • Multi-Head Attention 본체

    Q·K·V의 Head 분할·Head별 Attention·병합을 구현하고 Shape을 설명한다.

  • Transformer Block

    Embedding·Attention·Projection·FFN·Residual·Norm·Dropout을 연결하고 숫자와 Shape을 검증한다.

  • Tiny Decoder LM

    Tiny Decoder를 조립하고 Target shift·Token Loss·Causal Mask로 학습과 순차 생성을 검증한다.

  • Tokenizer·Model 로컬 저장과 오프라인 복원

    Tokenizer·Config·Weight를 로컬에 저장하고 새 프로세스에서 오프라인 복원해 동일 입력 결과를 비교한다.

  • HF Causal LM

    Tokenizer·Padding·Forward·수동 생성·평가·복원을 연결하고 직접 구현한 Block·Tiny LM과 Shape 및 동작을 비교한다.

  • LayerNorm·RMSNorm 비교

    LayerNorm과 RMSNorm을 같은 Tensor에 직접 적용해 계산 과정, Shape, 출력 불변식과 차이를 설명한다.

Gradient와 Tensor Shape을 검산하고, 학습·평가 루프를 구현하며 저장한 모델을 복원해 단일 입력 추론을 재현할 수 있습니다.

  • Loss와 계산 그래프

    Loss 연산식과 Tensor 계산 그래프의 연결을 설명한다.

  • Autograd와 수동 SGD

    Gradient를 손계산과 비교하고 SGD 업데이트 및 Gradient 초기화를 반복한다.

  • Tensor Shape 실험실

    축 변환·Broadcasting·행렬곱의 Shape과 dtype·device를 예측한다.

  • nn.Module과 Optimizer

  • Dataset·DataLoader와 학습 루프
